# 《凡人修仙传》可交互世界：原著还原与剧本编写调研

## 调研日期与范围

2026-10-17。本文为研究参考，讨论如何把《凡人修仙传》的一个原著时间切片写成 Living World Engine 可执行世界，不是已经交付的世界包或引擎变更规格。

正式制作范围见[已批准规格](../specs/0192-canonical-world-and-participation-seeds.md)与[制作档案](../../worlds/fanren/authoring/README.md)：人界和灵界全域、开篇统一时点、八种原创出身及韩立身份。本文保留早期抽读与选点比较，黄枫谷快照和下文四个候选出身不作为最终范围或验收清单。

目标分为两个相互配合的部分：世界中的人物、地点、既有历史、修炼规则和社会关系尽可能符合选定版本；玩家可以通过新颖的出身成为这个世界里的自己。玩家不必扮演韩立，也不必加入原著主角选择的门派。进入后的未来由局势、人物与玩家行动发展，重大事件可以发生、改变或不发生。

本次抽读第 144—179 章范围内的 13 个正文章节，以及第 1 章、第 127 章，检查 3 份作品相关资料页，并对照当前脚本格式与 Direct runtime 的相关实现。没有逐章通读这些章节之间的全部正文，没有完成全书人物普查，也没有验证百人或数百人世界的运行稳定性。以下选点、出身示例、规模和工作流程是建议。

建议以小说原著为基准，分别设计世界进入时间与玩家出身。面向玩家优先研究原著开篇同期的自创凡人角色；“韩立出身”作为可选身份，从第 1 章的山村生活开始，允许拒绝后续入门机会。“第 160 章中，韩立听完吴风介绍血禁试炼、返回百药园的当天”保留为百人世界测试的候选快照，不是所有玩家的默认起点。该快照距离下次试炼约半年，精确日历、年月日与秒数仍需另外处理。本文黄枫谷细节属于对应时期，不能直接倒入开篇世界。

## 要点提炼

### 1. 还原对象是一段时间里的世界状态

“韩立”的全书百科把不同时期的境界、装备、身份、熟人和秘密放在一页；游戏需要的是指定时点的韩立。已有历史是进入时的事实，未来原著事件是一个可供研究的参考轨迹，两者不能混装进人物记忆。

还必须区分“事实何时成立”“读者何时得知”“某人物何时得知”。后面的章节可能揭示一个早已成立的秘密，这种秘密可以属于进入时的客观世界；它并不因此成为所有人物的知识。相反，一件后来才获得的宝物，即使百科早已写明，也不属于早期库存。

章节号不能单独充当世界时钟。S07 从做决定写到数月准备和外出，跨越明显的时间长度。进入锚点要定位到具体场景；没有证据的绝对日期保持未定，运行时采用的相对时间另记为实现约定。

### 2. 世界时间与玩家出身分别选择

开篇同期适合从家庭、生计、学艺和偶然接触修仙线索开始，让玩家逐步认识世界。S14 中的韩立尚未离开村庄，家庭和三叔带来的机会构成他的初始处境。若选择扮演韩立，应从这一早期处境开始，具体定位到机会尚未替玩家决定的场景；加入七玄门是一种选择，不是必须完成的教程。拒绝可能影响家人期待、收入和关系，但不会使玩家在叙事上失去继续生活的资格。

新人物无需复制韩立的家庭、三叔和入门经历。其村庄、家人、行当和人际关系可以填入原著未详写的部分，在不改变已有事实的前提下形成自己的生活。韩立继续按当时身份和认知独立行动；玩家是否与他相遇，取决于实际活动，而非所有出身必经的剧情节点。

黄枫谷准备期具有修炼瓶颈、药材生产、岗位、坊市和七派竞争，适合较快建立高密度关系与规模测试。黄枫谷弟子可以是该时点的一种出身，不是整个产品的唯一入口。一个角色从开篇生活到这个阶段，世界中其他人物也须经历相应的时间发展，不能仅把玩家位置切换到一份后期状态。

### 2.1 出身提供处境与机会，玩家决定人生方向

每种出身建议分别写清：过去身份、真实资源与能力、已有关系、眼前处境、可发现的独特机会，以及玩家可以自由设定的动机。默认目标只提供开始行动的理由，不锁定拜师、入门、复仇或修仙等唯一终点。拒绝某个机会后，已有世界和人物继续行动，也不会暗中保证同一机缘改换方式送到玩家手里。

下列是原创出身候选，不是原著已有的人物或宝物。其地理、行业、能力边界与资源供给仍需正文核对；展示阶段不宣称已可运行。

| 出身候选 | 初始生活与牵挂 | 独特机会 | 约束与不同选择 |
|---|---|---|---|
| 山村药童 | 跟随乡医采药，家人生计依赖自己的劳动。 | 一份残缺药谱或异常药材线索，可能把玩家带到修仙者的交易圈。 | 识药不等于会炼丹，也不产生灵根；可以继续行医、寻找师承或出售线索。 |
| 逃荒少年 | 缺少稳定住所，与同行者互相依靠。 | 意外持有一件残损器物，候选能力是有限地察觉某类灵气异动。 | 此能力属于待核验的新增物品设定，必须明确启动条件、消耗与误差；可以求鉴定、交易或保守秘密。 |
| 衰落修仙家族旁支 | 资质与资源不突出，亲属关系和家族债务同时存在。 | 残缺传承、专业手艺和一部分家族知识。 | 不能等同于完整高阶功法或无限供养；可以承担责任、离家谋生或寻找合作。 |
| 镖局学徒 | 有凡俗武艺和行路经验，需要履行护送职责。 | 曾救助一名修士，得到一项尚未兑现的承诺。 | 对方有自己的处境和利益；恩情不等于绝对服从，也不保证收徒。 |

不必让每种出身都持有神器。独特机缘可以来自器物、知识、擅长领域、特殊关系或一个别人没有的机会；价值在于打开新的行动可能。若采用更明显的特殊能力，要说明它来自什么、能做什么、不能做什么、付出什么、为何会带来利益与风险。

韩立的小瓶不自动复制给每位玩家，也不在人物出生时预支尚未得到的宝物。新角色可以得到自己的机缘，但其能力必须与世界资源、时间和修炼条件相容。如果确实采用更改灵根规则、凭空获取资源等超出已核对设定的能力，应明确为扩展规则，不能同时宣称这一部分严格复刻原著。

### 2.2 凡人出身、未知灵根与确实无灵根

S15 明确区分普通人的社会身份与是否拥有灵根：有人天生具有灵根，却始终没有被发现或走上修炼道路；该阶段的说明也把灵根作为感应灵气、修炼法力的必要条件。因此，推荐默认的凡人开局是“尚未检测、尚未接触修仙”，也可以提供资质较差的既有灵根，而不是将“村民”直接等同于“没有灵根”。

灵根是否存在属于客观初始状态，角色是否知道则属于认知。获得检测机会可以揭示已有状态；不能因为玩家决定拜师，才倒改其出生资质。若设计隐藏资质，应保存真实值并限制角色知识，而不是让剧情需要随时重写。

“确实没有灵根，后来获得灵根”需要单独研究原著是否存在适用的特殊途径、其时代、材料、施术者与代价。本次未核实这条完整路径，也没有据此断言全书绝不存在例外。它不能先被做成普通山村新手的常规任务奖励。若作为原创扩展保留，应与已经证实的原著机制区分。

### 3. 已核对的细节会直接影响玩法

| 原文细节 | 编写含义 | 来源 |
|---|---|---|
| 黄枫谷有一万多弟子，炼气期占九成以上，筑基期数百。 | 150 或 700 人只能是具象化模拟范围，不能成为门派总人口。普通修士占比也不能按名人名单重排。 | S02 |
| 承担杂务的执事弟子、统管他们的领事弟子、筑基后承担管理的管事并非同一级别。 | 不能凭常见仙侠游戏印象，把“执事弟子”自动写成权力很大的长老。 | S02 |
| 筑基后的待遇、洞府资格与宗门遇敌时的义务相联系。 | 突破会改变社会位置，但制度权利与实际获得待遇还需要人物执行。 | S02 |
| 百药园是马师伯的私人药地，韩立承担管理和交付义务。 | 有访问权限、劳动关系和资源所有权，玩家不能把整个药园当作公共采集点。 | S03 |
| 韩立在黄枫谷样本所涉阶段长春功达到十一层，原先常用的两种丹药已不再帮助其继续提升。 | 不能把所有丹药都写成无限通用经验值，也不能通过反复服用绕过药效限制。 | S04 |
| 马师伯给韩立的灵石奖励增长，是对其稳定完成工作的回应。 | 工资、额外奖励和现存余额分别记录，不能把月奖励直接当作全部收入或现金库存。 | S04 |
| 吴风未能筑基，却擅长低阶法术并认真传授。 | 境界、具体技能熟练度、教学能力与人格分开建模。 | S05 |
| 王师叔对韩立服用一粒筑基丹的成功可能性有极低估计。 | 这是人物判断，不能直接生成适用于所有时间和条件的固定突破概率。 | S01 |
| 低阶修士能够使用符宝；制作资格和发挥能力另有条件，使用还消耗存储威能。 | 持有、识别、使用、充分发挥、制作五种能力分开判断。 | S08 |
| 七派的筑基丹分配与各派上交的灵药贡献有关。 | 竞争应来自资源和分配制度，不需要给所有人写一个无差别杀戮目标。 | S06 |

这些细节说明，“还原”需要能影响行动结果的规则与关系。只有熟悉的名字和形容词，无法保证玩家能按原著逻辑生活。

### 4. 人物卡需要写到什么程度

每个人物至少需要身份与别名、进入时的状态、当下目标、可用资源与技能、已知信息、误解、保密事项、具体关系和行为依据。外貌、语气与性格用于表达，资源、权限与时间限制用于行动；不能用一段人物小传替代所有部分。

| 首批核对对象 | 已有依据 | 正式人物卡仍需补齐 |
|---|---|---|
| 韩立 | 管园经历、修炼瓶颈、与吴风等人的交往、对试炼风险的犹豫。 | 通读遗漏章节，清点实际库存、已掌握术法、借贷承诺及此前经历；不能混入备战期所得。 |
| 吴风 | 传功职责、炼气顶峰、低阶法术能力、对求教者的态度。 | 授课安排、实际资源、对其他人物的认识；不因其负责传功就赋予全门派秘密知识。 |
| 马师伯 | 药园主人，对工作质量有要求，能因满意而奖励韩立。 | 当日所在、修炼安排、药园准确存量；没有证据的细节不能由“脾气古怪”推导出来。 |
| 于执事 | 百机堂相关事务、韩立领灵石及后续申请外出的接触对象。 | 正式权限范围、当日活动、完整身份；不把职务称呼误作姓名。 |
| 叶姓管事 | 筑基丹交易、亲属利益、韩立对其履约表现的不满。 | 交易余额及后续变化、亲属状态、对不同人的不同态度。 |
| 钟灵道、王师叔、慕容师兄、吴姓老者 | 门内管理和丹药分配会议中的身份、发言与利益。 | 两年多之后的具体状态、职务延续和位置；不能把早期会议永远冻结成日常。 |
| 红拂及被提及的后人 | S01 提供关系与分配优待线索。 | 通过正文完成身份对应，避免仅凭百科把未点名人物合并。 |
| 李师祖、向之礼、田掌柜、丁老、霓裳仙子等 | 后续已读章节提供出场、职责或交互线索。 | 回查其在进入时点已成立的状态、公开身份与秘密；后续会面不变成初始相识。 |

这是一份查证队列，不是完整人物名册。南宫婉等关键人物也必须经过对应章节核对，尤其是当时状态、身份暴露范围和行动原因，不能直接使用全书百科卡。仅有“马师伯”“王师叔”等称呼时，内部用稳定 ID 管理，在没有正文证据前保留称呼，不补造姓名，也不按同姓合并人物。

黄枫谷测试快照中，韩立的资料卡可以先写清：已在百药园生活修行，长春功十一层，已经寻找更有效丹药与主药来源，刚得知试炼情况，对参与仍有顾虑；与吴风的关系有长期求教和交往依据。精确库存暂不宣称完成核对。其动力可以表达为求进阶与谨慎权衡风险，不能简化成永不冒险，也不能因为读者知道他将成功而给予必胜保护。依据见 S03—S07。这些是该时间切片中的人物状态，不是开篇“韩立出身”的初始能力。

关系必须有方向和语义。例如“马师伯满意韩立的履职”和“韩立认为马师伯值得更多好感”来自不同主体；教过法术不等于正式师徒；同门身份不等于互相信任。欠款、师承、亲属、雇用、敌意和秘密同盟都需要各自的事实与知情范围。

### 5. 地点和物品也需要时间与权限

首批地点查证覆盖太岳山脉中的黄枫谷、百药园、百机堂、传功阁、岳麓殿与关联坊市。后续扩展至各派集合地点和禁地。原文给出的包含关系、通行方式、方向和障碍优先于自行绘制的精确坐标；未核对的路程不能写成原著距离。

地点至少包含归属、出入条件、连接关系、在场人物、可见设施与私有资源。物品至少区分独立器物与可堆叠材料、实际持有者、存放位置、数量、功能、使用条件、耗损和谁能识别。丹方知识不等于拥有材料，持有灵药不等于能立刻完成炼丹。

## 对 chatgame 的启示

### 1. 长剧本应由可追溯资料组成

建议维护三个相连的成果：原作事实台账、进入时点的世界快照、可运行的脚本包。台账承载出处与争议，快照回答“这一刻到底是什么状态”，运行包只接收已经选定且适合执行的内容。无需把整本小说和所有人生经历放进每个人物的提示词。

每条重要事实的作者资料应包含：稳定事实 ID、主客体、关系或属性、内容、来源类型、作品版本、章号与定位短语、世界内成立区间、读者获知位置、具体发言者、客观事实或人物认知的类别、知情主体、核对状态。发生冲突时保留冲突与证据，不通过一次模型摘要悄悄覆盖。

| 类别 | 处理方式 |
|---|---|
| 正文明确事实 | 可进入对应时点的世界真相，但要检查是否已变化。 |
| 人物说法、推测或传闻 | 先作为对应主体的认知；核对后才提升为客观规则。 |
| 后文揭示的既有秘密 | 可以回溯世界状态，严格限制当时知情者。 |
| 读者手册、动画、电视剧、游戏设定 | 保存版本标签，仅作线索或独立改编层，不默默并入小说原著。 |
| 游玩必需的空白补充 | 标注补充依据，不能改变已有事实、人物核心关系或稀缺资源格局。 |
| 为执行而设的数值与时间标定 | 标注为实现选择，不伪称原著精确给定。 |

例如，S01 的低突破概率估计需要保留发言者、测试条件和时间。S08 的符宝规则虽然读者在黄枫谷候选锚点之后读到，仍可能在该锚点之前成立；但韩立此时是否知道全部规则必须另证。知识时间与事实时间分开，才能同时做到世界正确和人物不预知未来。

当前脚本是严格的 [schema v17](../../src/script/contract.ts)。来源字段、校勘备注和未决问题应放在运行世界目录之外的作者资料中，不能直接给实体 YAML 添加未声明字段。下列为建议组织方式，仓库没有据此实现自动编译器或原著检索系统：

```text
worlds/fanren/
  authoring/
    sources.md
    claims/
    characters/
    places/
    rules/
    snapshots/
  world/
    script.yaml
    laws.yaml
    mechanics.yaml
    participation.yaml
    entities/
```

先用可审查的文件完成一个小范围样本，再决定是否需要提取、校验或构建工具。资料增长时按章节和实体查缺补漏，避免多份人物表各自维护同一事实。

### 2. 规则需要区分物理、制度和认知

修炼条件、器物威能与材料耗损是一类；宗门俸禄、名额惯例、出谷许可和奖惩是另一类。违反制度通常意味着有人发现、判断和制裁，不能一概表现为物理上不可能。人物错误估计和社会传闻又是第三类。

运行模型应能分别判断是否具备施展能力、是否有资源、是否来得及、是否获准，以及他人如何应对。境界不是包办所有结果的单一战力值，强术法也不能忽略施法时间、打断和准备；S07 提供了这类行动约束的例子。

现有框架可以表达法律、数量、时间活动和随机过程，但一条标为 hard 的自然语言设定，不等于每个修仙语义已得到确定性程序验证。需要把真正易错的行为写成验收案例，通过实际持久化结果和认知变化检查，不能仅让模型回答“符合原著”。

### 3. 重大事件用因果条件组织

血禁试炼可以分为三层，不能把它们合成一个“到某天自动发生”的剧情按钮。

| 层次 | 来自正文的内容 | 运行中的处理建议 |
|---|---|---|
| 外部时机 | 古禁按周期出现衰弱窗口。 | 记录有依据的规律与相对时间；到时唤醒相关人物重新判断。 |
| 人物与组织的计划 | 七派需要药材，准备队伍、奖励与集结；开启需要修士协力。 | 写成目标、资源、承诺与行动。人员、能力或合作条件失效时允许取消、延误或失败。 |
| 具体结果 | 哪些人进入、谁合作或冲突、药材归谁、谁生还。 | 从实际行动产生。原著结果与历史死亡比例都不是必须实现的配额。 |

以上依据为 S06、S10、S11、S13。S09 中的后续封禁安排体现组织政策，不能与古禁自然规律混为一谈，也不能未经时间核对就在半年前让所有人知道。

代码核对结果：当前 `world_timers` 接受绝对到期时间、待唤醒 Agent 和依据 law；[加载器](../../src/script/world-loader.ts)将其载入世界，[DirectWorldAlgorithm](../../src/engine/direct/algorithm.ts)到期检查后唤醒相关意图。它不携带“让某角色死亡、战争胜利、剧情完成”等未来状态修改。当前还支持作者声明的随机过程，并由[行动裁决实现](../../src/engine/direct/world.ts)使用。

因此可以利用现有能力提醒角色处理重要时机，再让世界判断行为；本次没有发现可直接配置任意剧情条件网络的通用重大事件编辑器。也没有证据表明引擎会自动把局势转换成可靠的“事件发生概率”。用户不要求为此先改引擎，第一版用已有计划、行动和定时唤醒即可探索可行性。

“有概率发生”不必统一实现为每月掷一次硬币。更合适的做法是让事件依赖当前因果条件，在确有不确定性的环节使用有定义的随机机制。这样玩家改变药材供应、队伍构成或合作条件，才会真正改变重大事件的发展。

### 4. 自动补全与原著还原存在需要验证的接口

[现有世界补全](../game-design/narrative.md)能为尚未建立的局部场景提出内容，并检查与已存在世界的相容性；它没有本次制作所需的原著事实库检索与出处校验。没有写入的原著限制，不能假定模型必然记得。

首个忠实性样本建议暂设 `narrative.expansion: false`，先检验已写实的人物、地点与资源。该开关在[世界裁决路径](../../src/engine/direct/world.ts)控制局部补全入口，不等于禁止所有正常行动、学习或制作，也不保证所有生成内容自动忠于原著。是否重新开放补全，需要在有资料依据的边界内验证；不能把全局 `creationEnabled` 一并关掉来替代这项分析。

百人规模还要测上下文成本。[局部世界视图](../../src/engine/direct/views.ts)仍会带入世界法律；把全书资料全部写成全局法律会增加反复处理的负担。应先正确拆分事实、认知与规则，再依据实际请求记录判断需要何种检索或上下文优化，不以压缩人物性格和知识来预先宣称支持大规模。

### 5. 百人版与数百人版的规模口径

建议用同一套原作资料建立两个活动范围：约 100—200 名独立行动人物的黄枫谷与坊市范围，以及约 600—800 名人物、包含更多门派和交易关系的扩大范围。数字是试验目标，不是原著人数结论，也不是已经完成的人物分配表。

每版都分别记录原作具名人物、原作出现但未具名人物、为补齐社会活动而添加的居民。后两类的姓名、性格和具体关系若由作者补充，应在作者资料中明确标记。不能把数百个新编角色包装成已经逐一还原的原著人物，也不能把不同年代的人物全搬到同一坊市凑数。

S10 的各派低阶参试者名额惯例提供了一个天然的百人事件范围：七派各至多 25 人，按此惯例计算上限为 175。这不证明七派在任何一次都满员，不含带队者，也不证明正文给出了 175 张具名人物卡。

数百人实验要让计入数量的人实际拥有独立身份、状态、认知和可触发行为。其余门派人口可以保留为世界背景，但不能算入已运行的 Agent 数。当前资料方案也不意味着已有自动加载尚未编写原著人物的能力。

关系负载比名字数量更有意义：同一丹药名额被多人争取、商人连接多个供需圈、药园需要真实交付、师徒与宗门义务影响决策、秘密在不同主体之间传播。记录同时参与活动的人数、互相影响的范围、资源争用、错误与修复、调用量、token、延迟和持续运行时长，再评价稳定性。百人独自待着不构成数百人关系网络的验证。

### 6. 编写交付顺序与验收

| 工作单元 | 可审查产物 | 完成条件 |
|---|---|---|
| 正文基线与索引 | 版本说明、章节表、称呼与身份索引、时间锚点 | 正文、读者整理与改编来源能够区分；重复身份有明确处置。 |
| 第一批事实核对 | 连续阅读范围和跨章节回查记录、事实与问题台账 | 进入时的核心关系、库存和规则有来源；未知没有被当作事实发布。 |
| 深度样本 | 约 10—20 个关键人物、5—8 个地点及其关联规则 | 人物能解释自己为何行动，资源有所有者，认识与秘密没有越界。 |
| 可运行样本 | 符合当前格式的世界包及实际行动记录 | 格式验证通过，关键行为符合已核对设定，未来能够因行动改变。 |
| 扩大活动范围 | 100—200 人版本，再扩至数百人版本 | 人物来源构成与真实负载公开；关系行为与规模表现分别验收。 |

深度样本是制作方法的验收阶段，不是把最终目标缩小成十几人。扩展时继续复用事实台账，对新增人物、地点及跨区关系逐项补证；不能用批量生成简介替代查证。

建议首批行为验收覆盖以下问题：

- 玩家自称有足够灵石或某件法器，不能改变真实库存；交易失败不能凭空产出药材。
- 管园弟子的访问与履职权不等于药园所有权；偷取、赠送和交付引起不同后果。
- 韩立此阶段反复服用已经失效的旧丹药，不会无条件提高修为；服用新的丹药也不等于立即突破。
- 低阶修士可以按条件使用符宝，但不因此获得制作资格或无限威能。
- 吴风能指导擅长的法术，但不因为处于传功岗位就获得高境界实力、他人私密经历或无穷闲暇。
- 韩立的秘密不会因为存在于客观世界就被所有角色知晓；玩家说出秘密也需要经过听闻、理解和是否相信的过程。
- 后续章节的人物关系、装备和政策不提前出现在进入快照中；后揭示的既有秘密不被误删。
- 缺少到场修士或必要合作时，禁地不会因时间已到而自动成功开启；历史生还比例不会强行决定本局死亡人数。
- 玩家改变了资源与选择后，角色允许作出与原著未来不同的决定，同时保持与其当前性格、认知和约束相容。
- 玩家拒绝初始入门或拜师机会后仍能采取其他行动；默认出身目标不会被当成必须完成的剧情。
- 自创角色不会复制韩立本人或其独有资源；选择扮演既有人物时，同一世界仍只有一个该人物。
- 未知灵根的检测揭示已有客观状态，不因玩家愿望重写资质；确无灵根的角色不会无依据地获得修炼资格。

以上是待实现世界的验收建议，本次未制作世界包、运行模型或执行这些游玩案例。结果应检查持久化世界、主体认知及行动记录，而不是只检查叙述是否好听。

### 7. 现有出身能力与待补齐部分

[现有 Origin](../game-design/script-format.md#participationyaml)可以定义出身描述、出现地点、初始 persona、默认目标、关系钩子、风险与 Mechanics Profile，玩家可以填写名称、外观和自由动机。[创建路径](../../src/server/world-host.ts)用所选 profile 创建角色及初始 Meter、Quantity、Rating，因此“同一世界提供多种自创出身”有现成基础。

这不意味着任意出身文本都能自动生成完整家庭和实际人情债。关系钩子是描述字段，具体人物、双向认识、债务、秘密或独特器物仍须在世界事实与主体认知中落实，并检查出生流程是否能正确建立它们。需要怎样补齐作者表达或运行支持，应以具体出身样本为依据，本次未修改相关实现。

现有[控制权机制](../game-design/engine-runtime.md)支持接管已经存在的人物。设计上可以把“扮演韩立”呈现为可选身份，运行时应接管对应早期快照中的唯一韩立，而不能用普通 Origin 再创建一个韩立。多个世界进入时点也需要各自经过校对的快照，不能只改时钟而沿用后期人物状态。

## 未解决问题

1. 稳定正文版本与完整阅读范围尚未锁定。本次公开章节检索存在页面元数据差异，后续逐章校勘及较晚章节访问需要可靠正文来源，不能靠手册补齐。
2. 第 144—179 章尚有未读章节，进入时点之前的韩立完整资产、身份关系与技能也未完成追溯。还不能交付声称“一比一还原”的初始世界。
3. 需要沿正文回查隐藏身份、临时修为变化、特殊功法与禁制交互。尤其不能把普通人对准入条件的概括，直接实现为对所有特殊状态都成立的简单境界比较。
4. 原著没有规定的普通居民细节、精确地图、价格和数值标定，需要按“已知严格还原、空白明确补充”处理。它们的比例和重要性应出现在制作报告中。
5. 百人与数百人版本应包含多少原作具名人物，需要实际普查后确定；当前不能给出可信的完整名单或承诺同一时期恰好有数百位适用的具名角色。
6. 时间跨度、炼丹与修炼等待、规模成本和自动补全边界仍需真实游玩验证。当前机制存在，不等于本作所需的语义细节和长时间运行已通过验证。
7. 开篇同期的完整人物、地理和生计尚待连续阅读；各原创出身的具体机缘、初始家人关系与秘密初始化也未完成。首先需要确定若干可解释、可执行的样本，而非直接开放任意输入获得能力。
