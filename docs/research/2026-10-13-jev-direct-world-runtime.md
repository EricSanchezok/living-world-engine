## 当前状态

新默认路径已经实现；行为程序与 WorldProgram 生成链已删除，旧实现保存在 Git 历史中。模型语义与收益验收仍在进行，不能将完成运行或成功重放等同于完成玩家任务。接口与职责的唯一规范见[直接运行时](../game-design/direct-runtime.md)和[规格 0182](../specs/0182-jev-direct-world-runtime.md)。

## 首轮冻结试跑：8f4aba67

沿用完整 49 主体输入，分别运行三个 canary 的全 DeepSeek 决策 B 臂与 Jev 决策 C 臂，每个任务三个玩家输入；另通过持久化 WorldHost 运行空间站的六个交换、维修和测试输入，关闭创作能力。没有重跑高成本旧 A 臂，历史失败样本见[上一轮记录](2026-10-13-jev-engine-qualification.md)。

三组冷启动均未发生模型推理。以上状态均可重放；空间站重新打开数据库后状态相同。C 的这些请求全部由 Jev 执行，但任务未完成，因此不能据此宣布架构成功、有效反馈提速或成功任务降本。

主要问题是行动与上下文的表达：缺少收件人仍尝试说话；询问信息被压成请求物资；世界裁决把表达接受与完成交换混合；私人旧证据被游标过滤；普通交谈选中了等待检查点。对应根因与永久测试见[故障记录 0152](../postmortems/0152-direct-action-projections-lost-conversation-evidence.md)。后续修正不改写本轮结果。

本地原始证据保存在 `.livingworld-benchmarks/jev-engine/direct-qualification-v1/` 与 `.livingworld-benchmarks/jev-engine/direct-station-1791889690835/`。三臂生产者、输入、模型配置与世界语义哈希在冻结 manifest 中；模型网关证据和世界状态在每臂 SQLite 与 JSON 快照中。

## 第二轮冻结试跑：24be2908

空间站关闭创作后的 19 次 Jev 请求，实际完成了询价、明确接受、支付两个电池、收到一个密封组件，以及检查员向工程师送达 `ORBIT-7`。维修在第 37 秒实际消耗一个组件与两升冷却剂，并将密封状态改为 `sealed`。随后发生了错误的时钟推进；压力测试又错误选择重复消耗冷却剂，未通过整条任务。数据库重启与事件重放均一致。该轮费用约 0.075915 元。

Blackmarsh canary-1 的 14 次 Jev 请求约 0.068923 元。角色看到了一个陌生人，但仍选择继续观察，未发出询问；这属于任务失败，不算“信息不足下的合理等待”。原始证据分别在 `.livingworld-benchmarks/jev-engine/direct-station-1791891316685/` 和 `.livingworld-benchmarks/jev-engine/direct-qualification-v2/canary-1/C/`。
