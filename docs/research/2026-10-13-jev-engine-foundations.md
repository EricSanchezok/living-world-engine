# Jev 引擎重构：基础层实施记录

## 范围与结论

本记录对应 [Spec 0181](../specs/0181-jev-decision-event-engine.md) 的基础层实现。原生 Jev 接口、私有行为程序、世界规则程序、条件证据、原子事件提交和局部调度已有实现及定向测试。生产 SimulationEngine、WorldHost、认知传播、Inspector 和版本切换仍待接入；默认引擎尚未替换，三臂完整游戏验收尚未开始。

真实调用已让 Hamdir 的一个已编译程序产生首个内核事件：向父亲提出共同办理交接的请求。提交回执包含原始对白及送达对象；解释器推进了该动作，里程碑和长期目标仍未完成。该探针直接调用提交内核并保存诊断 JSON，尚未把送达应用到父亲的认知，也没有经过 WorldHost 的实例保存入口。它不能证明完整游戏任务成功。

## 实现

- 原生决策通过现有 ModelGateway 调度、超时、调用证据和用量记录，保留选项概率、授权视角及输入版本。上下文溢出显式转入 DeepSeek 决策配置。
- 私有程序保存参数、执行位置、等待订阅、已发出的动作及规范回执。程序结束、里程碑和长期目标分别取证；同一输入下无进展的循环停止。
- 世界规则与私有计划分库存储。DeepSeek 输出声明式模板；代码校验来源、引用、表达式和效果结构，最多一次定向修复。
- Jev 分别判断具体条件和绑定实际效果的授权问题。所有世界判断包含实际参与者、位置包含链和世界法则。
- 内核检查实际读集、来源、证据哈希、效果模板、数量及写集，并在隔离副本中提交。竞争中的后续操作失败时，整个组件回滚。事件不能越过更早的未结算边界。
- 调度器按主体订阅资源版本、回执和截止事件；恢复后不重复分发已完成事件。读写依赖和互动对象组成联合组件。
- 提交后的传播投影已有实现：只有匹配实际回执的话语才成为接收者的证词；未识别的说话者使用中性本地身份。Jev 根据角色自己的证据判断已有信念是否受到支持或反驳，提交与重放重新核对输入和答案。该链路尚未接入生产 WorldHost。
- 当前世界程序通过剧本时间配置计算耗时；明确时长、距离必须匹配行动原文。持续活动的检查点不能宣布整个活动完成。

实现参考：[私有程序运行时](../game-design/program-runtime.md)、[世界程序运行时](../game-design/world-program-runtime.md)。

## 真实探针发现

1. 私有程序生成暴露过未列入资源目录的角色条目、把文本参数当作实体目标、对白同时“已生成”和“待生成”等问题。修复方式是补齐实际目录、区分实体参数，以及使用互斥的对白结构。
2. 世界编译最初重复发送整份集合及其逐条展开，单次输入达 439,323 tokens，复杂模板也出现 JSON 括号错误。改为集合加地址引用、复用 Schema 定义，以及普通 JSON 配合动态叶子表达式；一次对照请求降至 222,835 tokens。这是请求布局的开发对照，不能外推运行期节省比例。
3. 一份规则错误地要求对方先回应，才能发送请求，同时没有读取位置来判断可达性。Jev 返回 unknown，未产生效果。随后明确动作完成边界，并由代码补齐每次世界判断必需的物理上下文。
4. 生成器引用了实际剧本事实作为规则来源。来源目录增加带原始 world_seed 来源的事实，并与运行期证词区分；源码来源变化使复用失效。
5. 一次 Jev 响应给出概率 `0.93、0.05、0.01`，总和为 0.99。[官方接口](https://docs.typesafe.ai/api) 描述的是总和为 1 的概率分布；实际响应存在两位小数舍入差异。网关保留原值，允许严格限定的舍入区间，并继续检查完整选项、范围及最高概率选项，不把概率作为世界随机数。

最后一次探针复用了已通过校验的世界规则，只重新调用 Jev。探针当时尚未绑定 temporal profiles，规则给出了 1 秒仿真时长，因此此探针不参与任何速度验收。后续代码已加入时间配置约束，尚未重跑该真实轨迹。

## 调用与预算快照

截至本记录，实施阶段追加了 24 次真实 HTTP 请求，所有响应均有已结算用量；其中包含失败生成、定向修复、上下文回退及被本地校验拒绝的响应。

| 模型 | 实际请求 | 输入 tokens | 输出 tokens | 输入缓存命中 |
|---|---:|---:|---:|---:|
| Jev | 6 | 48,267 | 809 | 0 |
| DeepSeek | 18 | 2,363,453 | 32,724 | 45,056 |

追加费用按峰时价格和预算换算系数 8 CNY/USD 估算为 5.8966836 元。此前规划探针的 89 次调用估算 US$0.035729814，同系数折算后，113 次调用累计约 6.182522112 元。换算系数用于保守预算控制，不是实时汇率，也不是账单核对结果。

预算日志采用独占写入租约、发出前预留和用量结算；未知用量阻止继续发送。原始证据位于 Git 忽略的 `.livingworld-benchmarks/jev-engine/`。本轮成功事件文件为 `world-smoke-hamdir-1791822803030.json`。

## 验收状态

当前数据属于开发探针，不能用来证明 80% Jev 请求占比、70% 费用下降、50% 等待下降或 90% 目标完成率。尚缺完整 49 主体游戏、空间站场景、随机承诺、截止事件、认知隔离的完整轨迹，以及 WorldHost 保存与重启验证。A 基线中未完成或预算耗尽的样本仍须按未完成或删失处理。
