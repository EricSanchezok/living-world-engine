新的 `src/server/narrative/` 边界为：

- `contracts.ts`：场景与叙述的持久化契约。
- `scene.ts`：授权视角内的已执行证据、对话上下文与发布任务。
- `publication.ts`：段落解析、送达原话引用、发布检查与失败接续。
- `outbox.ts`：事务内登记、合并、挑选待发布任务及暂停后的事实反馈。WorldHost 负责后台调度。

旧 `world-narrative.ts` 已删除，消费者直接使用职责模块，没有兼容包装或第二条默认运行路径。重复的队列对象构造合并到一处，纯转发包装移入测试辅助函数。发布检查共享一份任务说明与实际回执，各问题只携带序号和检查重点；六个检查维度仍保留，真实传输回归确认两段正文的 12 个问题仍在一个 HTTP 请求中发送。外部价格读取继续返回副本。

本次未继续拆分全部历史模块，也未改变保留作研究对照的算法定义；这里的整理范围是当前观察到的重复路径与叙述职责边界。最后的报告和本地数据忽略规则不会改变上述实测运行代码。

## 实测方法与范围

使用固定的 12 条确认流程，每条 6 轮。输入与检查项目来自[冻结案例](../../src/engine/benchmarks/conversation-continuity/cases.ts)，种子 `20261014`，题集哈希 `3ecc09d73544b07f85b1f8658e360c4441c94371cf9cc2261cffe37eb65c7744`。本次为已经使用过题集的确认回归，不是新的独立确认，也不能把相对旧报告的分数差直接归因于本轮重构。

调用经过真实 WorldHost、模型网关及 SQLite 持久化。逐轮读取完整正文、执行回执与状态变化，由执行任务的 Codex 评阅，没有独立人工复核，没有额外付费评分调用。八项标准为意图、动作归属、指代、回应、角色、连续性、表达和恢复；所有适用项通过才算该轮合格。正常拒绝、不知道和合理失败均可以合格。

实际模型为 Jev `jev-1.13.0` 与 DeepSeek `deepseek-flash`。沿用此前 [ADR 0236](../decisions/0236-reasoning-for-language-boundaries.md) 固定的配置：DeepSeek 理解、创作及发布判断启用 thinking、effort low；不是最早计划中的关闭 thinking。单请求配置中，DeepSeek decision 为 8192 输出 token，creation 为 32768。

本轮没有重新运行另一组 L01/L02 连续体验或第二种子。Blackmarsh 49 主体表示完整世界被载入，不表示所有 NPC 均在每轮行动。真实浏览器补测另列，不混入 72 轮分母。

### 15 轮未合格的具体原因

| 回合 | 观察到的问题 |
|---|---|
| C02-1 | 引入旅人并提问后，又重复一遍“你注意到……”的出场介绍 |
| C04-6 | 向旁边走两步时重述已经完成的起身与结束休息 |
| C05-5 | 玩家问自身能观察到什么，被转成向 NPC 提问，最终只获得证词 |
| C06-1 | 攀爬与观察已提交，最终反馈退回重复的内部摘要，缺少所见内容 |
| C06-2 | “太滑的话就别硬爬”被作为玩家实际说出的台词 |
| C06-4 | 抓云的失败只给出“没能做到”，没有具体表达失败条件与结果 |
| C07-6 | 物品清点正确，却又要求寻找此前已经得知的校验码 |
| C08-2 | 接续分工问题的“杜衡呢”被理解为询问杜衡的位置 |
| C08-5 | 实际回执只有观察，叙述却加入了没有移动回执的走向泵动作 |
| C10-1 | 已持久化的容器、布等物件没有在反馈中呈现，只说查看了周围 |
| C10-5 | 叙述加入没有结果依据的“看起来慢一点”，混淆临时尝试与实际作用 |
| C10-6 | 旁白替玩家断言再想办法也没用，超出实际反馈与玩家授权 |
| C12-3 | 一面断言只有玩家说话，一面又说不确定是否还有人说话 |
| C12-4 | 没有使用可知的 120 秒窗口，也没有区分它与尚未约定的检查 |
| C12-6 | 前轮已经实际告知校验码，随后又将其写成未知 |

这些问题分别位于行动理解、状态到叙述的信息选择和跨轮对话连续性；不应只靠替换个别措辞处理。机械提交检查通过，也不能证明旁白语义正确。以上问题保留为后续改进依据，本轮不再用追加调参掩盖原始失败。

## 状态、隔离与恢复核对

实际事件中核对 180 项操作、310 项断言、296 条观察来源链接，72 轮没有发现引用、数量守恒、因果来源或重放差异。每轮均从已提交事件恢复到同一状态；每条流程重启后状态及正文一致，重复查询没有触发新模型请求。

C09 额外查看原始 HTTP 输入：杜衡首次决策与创作上下文均不含 `ORBIT-7`；乔伊实际说出校验码后，杜衡在 revision 2 首次收到对应观察，之后才引用乔伊作为来源。四份实际上下文哈希保存在 `initial-code-isolation.json`。这证明该样本的信息传递边界，不能代替对所有情境的隔离证明。

Execution Ledger doctor 核对 214 次执行、9422 条事件、3265 份 artifact、531 次调用，索引缺失、孤立索引行与孤立 artifact 均为 0，warnings 为空。28 条 issue 记录原样保留；它们包含运行中的拒绝和恢复信息，不作为全部调用成功的证据。

本批真实场景没有构成随机机制压力测试；随机承诺及重复提交边界由自动化回归覆盖，不能把这些测试写成额外真实随机样本。
