## 实现与验证

候选 `executable-player-diagnostic@1` 在 `incremental-player-diagnostic@2` 上接入联合编译，提出普通行动编译结果与受限交互程序。只有源世界明确授权的通信、读既存事实和数量转移可以执行。原文分段、局部目标、世界版本、源事实、位置、到期时间和数量余额均须通过守卫；任一当前成员未覆盖时整个组件回退。程序绑定随准备结果与执行状态持久化，原提交内核和语义复核继续生效。[实现决定](../decisions/0226-guard-executable-interactions-with-authored-capabilities.md)、[规格](../specs/0180-executable-interaction-diagnostic.md)。

真实接口验证暴露并修复了三个接缝：派生机械调用与结果缺少因果断言；算法遥测事件未登记；新增程序状态误入原意图解析器。测试通过保存／恢复准备结果、真实原子提交、下一步执行和历史重放，重复提交不再产生效果。守卫反例覆盖中断、目标离场、位置变化、歧义身份、源能力变化、远程未到期、隐藏事实和余额不足。谎言只成为发言事件，不改变钥匙真值。数量转移调用既有守恒规则；不会直接写数量快照。[验证代码](../../src/engine/benchmarks/step-efficiency/executable-interaction.test.ts)。

2026-09-22 的实现工作单元通过 `npm run check:fast`：338 个测试文件、2,052 项测试，lint 为 0 错误／74 个既有警告，提示、算法、世界和治理检查通过。该证据只支持工程接通，不证明模型编译正确或玩家反馈合格。

限制：这个受限程序不是自然语言语义证明器。已关闭有序随机流的局部候选若被最终验证拒绝，普通修复不能追加新的随机承诺；需要新随机数时整步失败，不越过随机顺序。W0 不补写通信物理或世界知识；测试中的作者能力事实属于 W1 控制材料，不用于声称 W0 覆盖率提高。
