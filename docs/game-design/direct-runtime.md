# Direct world runtime

This reference owns the default `direct-world@12` execution contract, approved in [Spec 0182](../specs/0182-jev-direct-world-runtime.md). Its implementation lives in [`src/engine/direct/`](../../src/engine/direct/algorithm.ts). The script contract is v17, SimulationState is v21 and WorldInstanceDocument is v33.

## Model responsibilities

`DecisionBatchV2` binds one authorized perspective, concrete dependencies, question versions and the pinned model configuration. Choice selects typed actions and parameters, Noul evaluates a concrete relevance question, and Score orders urgency. Independent questions share a request. Answers for unused branches have no effects. Native probabilities and score legends remain diagnostic evidence; they never become game randomness. When native preflight cannot fit the request after memory recovery, or the provider rejects its actual context, the configured decision fallback receives the same complete state and all questions. Preflight fallback skips the native HTTP call; it does not split the batch, discard evidence or confuse estimated tokens with actual provider usage.

The language-model adapter returns bare criterion strings or numeric values under the question keys. Code restores the typed answer from the question definition; the model does not repeat type tags. Native Jev responses retain their provider format. Quantity candidates include complete Chinese numerals independently of classifiers. Each key encodes its numeric value, with semantic selection separating amounts from deadlines and other numbers. Current player text and settled steps are repeated beside the operation, target, recipient and amount questions. A malformed language-model batch gets one targeted repair of invalid fields; valid independent answers stay fixed, all attempts remain in the audit, and a second failure stays local.

Bound action readings select movement, observation, private reflection, speech, transfer, use, changes and waits. Autonomous readings use the actor’s pinned creation profile; [open player interpretation](narrative.md#creative-authority) uses the pinned language interpreter when creation is enabled. Observation distinguishes owned inventory, surroundings and a selected object. Code builds ActionFrames from existing local identities, resource definitions, literal quantities, quotations and learned capabilities. An unknown player attempt retains its original intent for local adjudication or capability extension. Missing recipients or locations can require a preliminary observation; public speech can address everyone within perception range. A compound player request keeps its original submission until the next authorized step is handled or it reaches a genuine wait. Input completion, an immediate action result and long-term goal completion are separate records.

An autonomous `AutonomousActionReadingV1` jointly binds purpose, goal, operation, target or listener, method, actual words and urgency from the actor’s private perspective. It shares catalog binding, executed-branch validation and one bounded repair with the player language reader. Speech needs its listener and words; a missing binding cannot silently turn into a wait. A valid wait remains available when there is no useful next act or a real condition is pending. Goals and commitments motivate actions without an action quota or mandatory observation limit; recent receipts and retained goal progress support continuity, and goal completion requires received evidence. See [decision 0247](../decisions/0247-coherent-autonomous-action-reading.md).

The same response supplies `ActionExpression`, separating the attempt, actual utterance and observable manner. There is no subsequent NPC expression call. An open `use` or `change` action requires a concrete method; missing methods enter bounded validation repair. Known capabilities retain their executable methods. Literal player quotations keep their exact words. World adjudication still owns delivery and outcomes, while private synthesis remains private.

Physical receipts state the admitted result, including an operation that completed without lasting change. They do not repeat the action or expose an internal capability definition as narrative. The full method remains in the action, capability and Ledger evidence. Perception combines the receipt with admitted findings and preserves unconfirmed speech delivery.

A capability extension is a concise qualitative effect declaration with applicability, existing condition profiles or a constructed object. Either action selection or world adjudication can identify a missing effect concept. Code supplies references, existing public property vocabulary for the bound roles and execution structure, with one targeted structural repair. Capability knowledge propagates to actual observers of its use. [Open creation and narration](narrative.md) owns new actors, perceptible scene details and participant prose.

World adjudication receives local entities, placement, relevant facts, resources, effects and explicit laws. Its shared state holds each action and question rule once; individual questions reference the action ID and rule key while retaining their complete criteria and branch data. Script rules take precedence. Uncovered ordinary behavior permits common-sense adjudication. The decision binds immediate outcome, duration, material consumption or production under an authorized law, qualitative fact effects, numeric impact profiles, condition effects, shared capacity and actual perception. Sources provide traceability; ordinary effects do not require a pre-authored rule proof. Numeric effects are selected separately for each existing meter on the actor, target and tool, using only matching authored profiles and magnitudes. This permits an actor cost and a target effect in one batch without charging the tool or silently discarding the cost. Coincident roles share one meter selection; code computes and clamps the resulting delta.

Every player candidate entering world adjudication, including a continuation, receives one authorization choice in that same complete batch. Its current immutable input is `originalSubmission.rawText`, with the submission's goal, means and explicit targets. The full attached discourse is projected separately as `referenceDiscourse`: its earlier requests and published speech can resolve the current input's references but cannot replace that input. This projection preserves every input field without mutating the retained submission. Generated attempts, completed receipts and delivered speech retain their separate sources. NPC questions or consent can satisfy an already selected condition but cannot authorize a new player quote, promise or voluntary act. Only an authorized candidate reaches effects, expansion, timing and delivery. An out-of-scope or unresolved candidate stops with a recoverable interpretation failure; it creates no attempted world action, in-world obstruction or speech. Independent same-batch NPC actions still settle. While external control retains a failed submission, observations, changed dependencies, timers and deadlines cannot retry it; a new participant submission can replace it. This adds one choice per player candidate and no model round trip. Private reflection retains its private interpretation path, without world effects or external delivery. This admission implements the player-agency boundary in [Spec 0191](../specs/0191-natural-action-time-and-world-initiative.md).

Unspecified timing enters preparation without a deadline; it cannot enter the timeline until adjudicated. Every physical action kind uses the existing adjudication call to select a plausible duration from authored scales and temporal calibrations. Action-bound explicit durations and calculated rate/staged procedures retain their durations. Private reflection chooses its scale in its existing private interpretation call. The minimum authored scale is never a default for missing timing.

Ordinary actions supply their immediate neighborhood and affected place as perceptual candidates. Access decisions, not candidate membership, admit knowledge; an unentered interior or hidden identity remains undisclosed. Incidental context belongs to the actor's observation rather than every witness of that actor. Narration selects salient admitted consequences and surroundings without requiring a separate look or reciting every fact. Local creation runs only on an admitted opportunity; an unchanged scene requires no creation call.

Movement, physical use and changes can update existing properties of the actor, target and tool in their ordinary world decision batch. A changed posture or relation uses the same fact identity rather than retaining a contradictory old state alongside a synonym. Entity-valued relations can retain their target, end, or bind an actual actor, target or tool from the current action component. Their perceived descriptions retain the predicate and authorized local referent; a cleared relation retains its predicate with an empty value. Perceptual admission is separate from success: a failed attempt may reveal an existing condition through its actual channel, while an uncommitted new effect supplies no fact. Fact access rules still govern every recipient.

A finite physical use or change with no admitted effect records a partial attempt with no confirmed state change. Its receipt cannot claim the requested result occurred. A distinct remaining authorized step may continue under the same request; repeated work remains subject to the no-progress wait. An admitted ongoing activity records its start and retains its activity lease. Action selection receives prior receipts for the same submission to distinguish completed prerequisites from remaining work. Target identifies the affected object; a separate instrument belongs in the tool field. Actual owned resource consumption and production enter the actor's observation alongside visible facts.

The private action context also highlights recent owned actions and current claims with their evidence kinds and observation steps. Conditional instructions resolve against those records before selecting the concrete branch; incidental appearance traces do not introduce extra prerequisites. Recipient discovery retains the selected known search location, and exploration may expand that location before a recipient exists. This context does not import another character's hidden cognition or canonical identity bindings.

A performed reusable capability names its executed method in the receipt. Actual observers receive that method and the actor's local label with its visible results, including silent physical work; the source does not expose private reasoning or misattribute witnessed work to the observer. A capability answer on an unselected physical branch has no effect or knowledge propagation.

## Persistent activities and the timeline

Bootstrap saves the world and every Agent's initial intention without model inference. Initial NPC decisions are durable ready tasks and execute when the host advances the world. A fresh player request is interpreted first. When it produces an actual activity, ready NPCs with nearby contact or a goal/commitment association receive an independent choice in parallel with each other. Their choices still use only their own private perspective and may choose to wait. Clarification and already-completed requests launch no NPC activity. While a player activity is pending, later boundaries settle it and its direct replies without falling through to the global ready roster. Received observations and deadlines wake relevant NPCs.

Control transfer at a committed boundary admits the new participant's next action when that actor has no pending activity. Reactions queued for a released actor remain model work and do not prevent that input. Direct responses to the active participant submission and their explicit follow-through settle before its next decision window. Subsequent NPC conversation retains its observations and ready tasks as background work; it does not prolong the participant's immediate turn. Concurrent outcomes share a recipient-local alias namespace, introducing each subject once per boundary. Contact candidates include adjacent interior/exterior places, with actual sight and hearing still decided from available channels and barriers. Opportunity selection does not promote a specific target to its parent city. Native observation binds self-inventory through the self target so an independent scope choice cannot replace an explicit external target.

A model-controlled intention retains its selected cause and an ordered, deduplicated queue of delivered causes. A busy activity keeps its own cause while later requests remain pending; settlement and further observations cannot overwrite them. A ready intention prioritizes a queued participant cause before background work, preserving the displaced cause for later. An explicit continuation retains its cause; a completed action or deliberate wait handles that cause and allows the next one to proceed. Current and queued participant causes both hold the foreground window. An active direct response keeps selection scoped to participant work even after the participant action completes; an empty ready response set settles admitted activities without selecting unrelated ready Agents. Engine priority and host completion use the same causal classification under [decision 0232](../decisions/0232-participant-replies-and-background-conversation.md).

External control receives observations as private evidence without accumulating autonomous response causes. The next canonical step clears that actor's queued causes while preserving an already admitted activity's cause; a new participant submission takes over the intention and clears its previous causes. Returning the actor to model control preserves admitted physical work and its original authorization through any necessary re-adjudication. Once no activity remains, the next canonical step clears the human submission and its failure, then resumes autonomous choice from retained evidence and goals. Model-controlled choice never receives that submission as a new instruction or replays an unconsumed queue from the human-controlled interval. Control transfer itself does not mutate canonical state.

Intention state retains the current goal, an active submission, wake causes, owned dependency hashes, activity identity, waits, progress evidence, recent receipts and recoverable failure. Observations append actual events or delivered testimony directly to private evidence. Perceptible public names update local aliases; merely seeing a person does not reveal a hidden identity. Code enforces fact access independently of semantic visibility decisions. Existing claims and goal progress are evaluated with the next relevant action decision. Testimony does not itself become a canonical fact. Private reflection records inference for its owner without world adjudication or external delivery; new synthesis uses the creation capability.

Adjudication is saved as prepared effects. Finite activities retain their absolute due time through earlier world timers. Continuous activities start at an ordinary action boundary and retain their active lease and elapsed progress without asking a model at every checkpoint. Starting an open-ended activity does not consume its future checkpoint interval; an explicitly selected duration still applies. Shared resource claims are allocated together in stable admission order; queueing postpones the start until capacity is available. Interruption removes the superseded pending effects. Changed actual dependencies invalidate the affected preparation.

The earliest activity, timer, condition expiry, recurring effect or explicit wait deadline is a barrier on the canonical timeline. Control-only records may keep the same world time. Physical commits advance by a positive number of seconds. A repeated input or repeated action without meaningful progress enters a recoverable wait. One failed model task retains its failure locally while independent admitted work and clock events can continue.

Under [Spec 0184](../specs/0184-conversational-continuity-and-recovery.md), automatic interactive runs without a new participant request have an absolute horizon: the run's saved starting world time plus `maxAutonomousSpanSeconds`. Each continuation shares that horizon. Unrelated distant timers do not authorize a time jump after a reply-window timeout. An idle policy clears the participant's unfinished submission and wake cause. Explicitly requested waits and observer advances keep their chosen temporal scope.

Shared request, currency and token caps and unresolved usage are typed service pauses. Their causes survive provider wrappers, appear separately from world outcomes, suspend reply clocks and stop automatic work. Saved effects and published paragraphs remain available through reads and restart. A deliberate new request can resume when service capacity is restored. A cap during narrative generation preserves the accepted prefix and adds available factual feedback without another model retry.

## Mechanical commit and replay

`DirectStepPreparation` freezes the source, producer, roster, request and native event under a content hash. `completeStep` verifies this binding and returns `DirectStepCandidate` without applying world operations. The canonical owner validates the frozen event and applies it once; explicit replay and persistence integrity verification use the same mechanical function. Direct does not construct reference resolution plans, reaction windows or AgentMind receipts.

Model input rejection before transport is recorded as `model.context.rejected`, with the planned invocation identity in its payload. It does not create an outstanding model invocation. Recorded replay and sealed debug checkpoints reproduce that rejection before consuming the fallback response, preserving the original decision path without another model call.

The current `DirectRuntimeState` version 4 is owned by `SimulationState.executionState`. Bootstrap retains its initial control state; each `DirectStepRecord` retains a lossless `controlDelta` with base and result hashes. Prepared text replacements retain original and proposed value hashes with their separate visibility decisions; settlement chooses perception for the actual value, including after a cancelled effect. Committed records contain shared effects and Direct metadata once, with no per-step execution-state snapshot. Inspector and narration reconstruct historical control in order. Decision cache entries retain answers and diagnostics; model audits belong to the event evidence rather than every cached answer.

Direct debug stages are input binding, action selection, local adjudication, settlement, canonical validation and atomic commit. Reference pipelines expose their own stages and receipts only when explicitly selected.

Code computes references, quantities, clamped numeric changes, resource conservation, time and IDs. A shortage becomes a blocked local result with no partial debit. The canonical transaction checks actual read hashes, ordered due events, producer identity, owned random commitments and replay identity, then saves the whole event atomically.

Random distribution and effect bindings are persisted in a control commit before a draw. Settlement consumes that commitment using the seeded stream. The committed event retains requests, results and RNG state. Replay applies recorded semantics and checks deterministic mechanical consistency without a provider call or a new semantic choice.

The trusted Inspector exposes intentions, actions, saved activities, wake reasons, local failures, typed decisions, dependencies, capability declarations, model usage and cost provenance. Normal participant views retain private cognitive isolation. WorldHost, the Execution Ledger, generation fencing and instance transactions remain the persistence boundary.

## Qualification

The direct runtime and the all-DeepSeek decision variant share the same execution code. [The qualification contract](../specs/0182-jev-direct-world-runtime.md#verification) owns outcomes, comparison arms and the cumulative paid budget. Deterministic transport replacement proves owned mechanics and persistence; it does not establish real model success rates or cost and latency gains.

For real browser qualification, start the workbench with `LIVINGWORLD_JEV_BUDGET_ROOT=.livingworld-benchmarks/jev-engine`. Its provider transport shares the CLI experiment ledger, retained unknown reservations and the ledger's explicitly authorized cumulative ceiling. Only the priced Jev and DeepSeek accounts are admitted in this mode. One live writer owns the ledger; stop the workbench before starting another paid qualification process. Ordinary startup without this option uses the configured provider transport.

The generated-program engine is available in [frozen source](https://github.com/EricSanchezok/living-world-engine/tree/05d273f7/src/engine/events). Its failed trials remain historical evidence. Explicitly registered reference and benchmark algorithms remain research infrastructure; new instances use the direct runtime.

An applicable authored random procedure queues its draw independently of whether a fact receives the sampled value. A missing result binding can receive one dependent question; an unresolved binding preserves the original facts and records a partial result with the actual draw. Ordinary property or capability effects cannot overwrite a bound random result. Capability declarations ignore extra non-executable annotations while retaining typed effects and reference checks.

## Coherent player interpretation

Open player language produces a `PlayerActionReadingV4`: a semantic summary, authorized/settled/remaining request components, interaction mode, one bound action with its expression, a continuation and cognitive updates. Dynamic catalogs constrain references and quantities; the language model binds dependent fields together. The expression has one authoritative utterance, with exact-source restoration only for explicit quoted speech. A redundant whole-input selection cannot overwrite the correctly interpreted words. Code discards unused branch parameters before validating the selected operation; invalid references on an executed branch still fail. The language reading does not offer arbitrary sentence spans that may include stage directions. This single response supplies the player expression without a second creation call. Settled receipts identify completed parts of the current submission. Native independent decisions bind outgoing amounts to named resource branches. The reading has its own pinned prompt identity and durable model audit. Autonomous readings distinguish an actual inspection, a response, an honest unknown answer and motivated silence. Action readings receive chronological interactions from the Agent’s retained delivered observations, with local speaker, addressee, words and executed results kept distinct. See [decision 0231](../decisions/0231-joint-language-interpretation-and-current-receipts.md).

A present physical instruction retains its operation during conversation; a reference to another person's words does not make that instruction spoken dialogue. An authorized search can follow known leads through ordinary accessible space. It stops at actual obstacles, covered scope or a meaningful new choice without adding payment, acceptance or restricted entry.

Only parameters used by the selected operation require a bound catalog value. Quantity is active only when the operation selects a quantified resource. Unused branches may be omitted or null and receive inert defaults; malformed auxiliary cognitive judgments preserve the existing belief or goal rather than cancelling an otherwise valid action. The raw response remains in the model audit. Target catalogs distinguish the character, their current perceived location and other known entities. Timing catalogs include durations and selection semantics. Approaching the current location preserves containment within it.

Quantity candidates include numbers in the acting Agent's retained private evidence, the current submission and active goals. Advancing the observation cursor does not erase an earlier quoted amount from that catalog. These numbers are candidates, not authorization or current canonical prices; the decision still selects the applicable terms and resource. A transfer recipient is the intended payee, while a spoken reply addresses the actual interlocutor.

Each interpretation field carries its operation-specific meaning in the output schema. An absent timing or duration selects ordinary timing; an absent quantity stays unknown. The actor's body does not bind a separate tool role. Capability creation receives the equality and availability of actor, target and tool roles, and an impossible self-placement enters its existing single repair allowance before world admission. A movement observation records the actual departure and arrival or continued presence within the same place.

A continuation may close an already executed submission through `request_complete`. It requires existing receipts from that same submission and produces a control update with no additional action, speech, narrative explanation or elapsed time. A new input cannot use old receipts to skip its requested attempt. The previous step's continuation prediction does not require a fabricated follow-up when actual receipts establish completion.

The immediate-response progress question includes the actual triggering action and delivered words. An inspection requested together with a report can continue into that report; the original participant cause remains attached through the follow-through even when another nearby character speaks. When an NPC's response to a participant request fails or is blocked and world adjudication requests continuation, the same cause remains available under the existing two-attempt no-progress bound. The NPC can explain the observed failure, decline or wait; the engine neither invents that explanation nor makes the failed operation succeed. A completed report releases the participant turn while unrelated background conversation remains queued. Failed player actions and rejected player authorization do not gain this NPC continuation.

## Open qualitative values and conversational continuation

Movement binds a concrete known destination, including the current place for local movement. An omitted movement target receives the player interpreter's single binding repair; execution does not silently convert it to discovery. An approach to a target inside another place uses that surrounding place; when the target already encloses the actor, it cannot place the actor outside the target in its parent. Posture and support remain qualitative conditions distinct from enclosing placement. Discovery before speaking or transferring requires the explicit discover selection.

A local world judgment can select a missing qualitative value for an existing text property. An action-bound creation request receives the exact properties, current values, action and author's private evidence. It returns complete candidate replacements; documents contain their actual text. The existing supplemental world batch admits each value against access, evidence and the intended edit, preserving old content for an append while allowing requested corrections or deletions. Rejected values block the action. These values never enter reusable capability definitions and take precedence over a cached literal effect on the same property. A mixed request for a new concept shares the same creation call but returns its reusable declaration separately. Unaffected properties and numeric mechanisms retain their own owners. [Decision 0251](../decisions/0251-action-bound-values-outside-reusable-capabilities.md) records this boundary.

An NPC's private view derives its own directed speech since each recipient's latest reply from retained delivered observations. An unrelated overheard conversation does not cause exact repeated speech to an unanswered recipient; a new direct reply or physical observation remains eligible. A creator can choose silence. A participant-caused inspection retains one follow-up decision to report, decline or wait, even when a physical change triggered the inspection or the inspection learned no new property. It cannot recursively extend the same inspection cause.

## Long-term memory

Private action interpretation and actor evidence in adjudication use the [Agent memory reader](agent-memory.md). Model request pressure starts instance-owned background work; world commits and original cognition retain their existing owners.
