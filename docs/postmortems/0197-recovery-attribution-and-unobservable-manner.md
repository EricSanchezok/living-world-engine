# Recovery attribution and unobservable manner

Artifact-Version: 1

## Executive summary

A complete-world playtest finished the requested stock count and delivered the report, but presentation assigned an unrelated helper's failed response to the successful manager. A repeated recovery with no new visible information then exhausted narration repair. A separate return paragraph asserted the manager's private thought as an observed action. Canonical completion, replay equality and a successful publication verdict did not establish correct prose.

## Root cause

The failure focus existed in the reply source but lacked an explicit role in the shared generation and publication task. The original request's addressee therefore competed with the actual interrupted actor. The six publication axes could all accept that mistaken association. The speech axis also treated surrounding unsupported actions as a defect in otherwise exact, correctly attributed dialogue, making repair less specific.

Recovery creation keyed distinct internal attempts rather than the complete participant-visible recovery. Internal failures at different revisions could therefore spend two narration allowances on the same information. Suppressing only an already published duplicate would miss the observed queue race.

The generic response-failure explanation also assumed an outstanding question. A related actor's processing failure does not establish an unmet participant goal or partly spoken dialogue. Likewise, an action's elapsed duration does not establish the entire off-screen interval. Both assumptions were more specific than the available receipts.

Published discourse retained the text of earlier paragraphs but omitted their world-time boundaries. The model therefore received a precise action duration beside unanchored story history. Instructions to distinguish those intervals could not supply the missing endpoints. The repair projects each paragraph's existing frozen boundary and derives the previous-publication interval separately from action receipts; it does not reinterpret earlier text as authoritative world evidence.

The manner question addressed unsupported material changes but did not explicitly distinguish observable movement from private planning. The narrative projection retained the admitted manner, so an additional publication boundary must not treat every clause of that string as direct access to another mind. Movement completion and perceptibility of its proposed manner are independent judgments.

## Guardrails

[Narrative regression cases](../../src/server/__tests__/world-narrative.test.ts) bind recovery to the already known local actor, retain the manager's preceding successful report, preserve exact dialogue independently of adjacent agency defects, and cover observable versus private components of manner. The shared narrative task and publication criteria retain all six axes and one continuation allowance; no extra model review stage is introduced.

[The recovery outbox](../../src/server/narrative/outbox.ts) coalesces only equivalent recovery information for the same participant, submission, known failure focus, cause and failure class. The complete visible source must match apart from its boundary. The first durable beat remains responsible for publication, and every underlying runtime failure remains recorded. Changed focus, observed results, cause or error remains eligible for a distinct recovery.

[The persistent-host regression](../../src/server/__tests__/direct-world-host.test.ts) exercises repeated queued feedback through canonical failure receipts, preserving replay and the original Ledger. The recorded duplicate spent four requests and 45,725 input plus 9,582 output tokens; the regression prevents that duplicate work without estimating whole-session savings. Narrative checks distinguish a processing interruption from partial speech, condition continuation advice on an actual unmet goal, and bind elapsed duration to its own action rather than an unsupported scene-to-scene interval.

[World adjudication](../../src/engine/direct/world.ts) judges observability within the existing manner question. An unsupported manner does not cancel an otherwise valid movement or speech outcome. [The narrative contract](../game-design/narrative.md) owns the public attribution, evidence and recovery behavior; [Spec 0204](../specs/0204-narrative-evidence-and-useful-memory-admission.md) owns the approved repair boundary. Frozen requalification preserves the original database and canonical state and records its own model usage; it does not rewrite the failed historical verdicts.

Two later isolated drafts still invented dialogue or repeated old context. The publication gate correctly rejected those clauses, but an already published recap prevented the terminal fallback from explaining the failed processing boundary. That recap also introduced a lamp without current local evidence. Historical prefixes remain immutable and are not qualified by repairing a later clause. The narrow direct processing-status path in [Spec 0206](../specs/0206-direct-known-response-failure-feedback.md) publishes the known boundary without creative generation; terminal fallback appends a missing notice while retaining the original failed evidence.
