# Onset routing broadcast private intentions

Artifact-Version: 1

## Executive summary

The onset scheduler treated shared placement or an accessible relationship as sufficient perception and embedded the source action's complete text in the observer's reaction stimulus. Silent thoughts and future intentions could therefore reach AgentMind without a perception adjudication. A structural basis was mistaken for an observer-specific local view.

## Summary

An actual SimulationEngine preparation reproduced the defect with only model boundaries replaced. Changing an unspoken secret changed the keeper's reaction context at a shared placement. An isolated keeper also received the secret when the two actors had a public friendship Fact; deleting that relation routed the same candidate through perception and produced no reaction. The source snapshot remained unchanged and no world commit was needed to expose the bad information flow. Conservative conflict and audience metadata identified possible interactions, not sensory access.

## Timeline

- The causal Activity preparation implementation introduced direct onset admission and a stimulus template containing source rawText in commit 5086a890 on 2026-08-28.
- Full-player efficiency investigation exposed invalid onset evidence and prompted a read of the actual producer, reaction context and committer rather than relying on model explanations.
- A paired silent-secret control and isolated-friend control reproduced input disclosure before AgentMind reasoning. The separate Truth routing materializer was not used by eager preparation.
- The receipt boundary was extracted and exercised, then integrated into perception completion, frozen preparation, reaction production and canonical validation. Direct admission and the separate component reaction-routing execution path were removed.

## Root cause

The private-stimulus requirement and the structural basis list were not a complete perceptual admission contract. Co-location can support seeing a gesture while revealing nothing about its intention. The implementation additionally widened a communication or perception Fact into any accessible entity relation connecting the actors. The committer repeated the same structural rule, so matching validations confirmed the defect instead of detecting it.

The engine synthesized the private stimulus from unfiltered source text rather than using the existing observer-local renderer. One test returned a routing response through a fixture adapter, while the production eager branch could bypass both perception and routing. Passing that test did not demonstrate what the receiving Agent actually saw. Small output and reference tests also did not establish complete-player semantic correctness or latency.

## Guardrails

[Decision 0181](../decisions/0181-project-onsets-before-agent-reactions.md) and [specification 0128](../specs/0128-observer-bound-onset-receipts.md) require complete per-target reports and a private stimulus before a reaction. The [receipt validator](../../src/engine/mechanics/onset-receipts.ts) binds source state and action, observer, world evidence and committed checks; a positive report cannot drop an already committed perception uncertainty or depend on a failed check. Valid references and hashes remain mechanical evidence, not proof of natural-language observability.

The [actual-entry regressions](../../src/engine/algorithms/eager-reference/__tests__/onset-isolation.test.ts) cover private-only changes, co-located occlusion, isolated friendship, legitimate visible and remote onsets, missing reports, external preparation restoration and coordinated candidate/preparation tampering. They inspect the real AgentMind request and keep semantic fixture oracles explicit. The [receipt tests](../../src/engine/mechanics/__tests__/onset-receipts.test.ts) cover source binding, local identities, check provenance and rejection without canonical or RNG mutation. The [existing preparation safeguards](../../src/engine/algorithms/eager-reference/__tests__/eager-reference.test.ts) retain positive-boundary replacement and check/RNG coverage.

Runtime acceptance uses execution contract 9, preparation schema 6, candidate schema 7, eager-reference 23 and onset-perception 6. All-direct scenes require an explicit perception response; deterministic tests establish neither that added latency nor live model semantics. Fresh full-player qualification remains required by the [efficiency contract](../specs/0122-player-action-efficiency.md).
