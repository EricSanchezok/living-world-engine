# Explicit Compilation Access Sets

Artifact-Version: 1
Status: Approved

## Intent

Test whether explicit read/write set terminology reduces unnecessarily broad initial conflict declarations in the complete-player experiment. A source-level audit found a location inquiry declaring the harbor Entity and placement as potentially affected; those declarations survive materialization and connect the player to a large component. This does not establish that any edge is safe to remove.

## Contract

The benchmark renames the two existing compilation dependency fields to `readCandidateKeys` and `writeCandidateKeys` on the wire. Decoding restores the original fields exactly before the existing symbol, schema, scope and dependency validators. Every original candidate, action, temporal contract, context field and legal dependency remains available. Read/write overlap remains legal. The adapter does not infer membership, delete references, narrow the current interval, certify independence or alter a world transition.

Instructions explain the existing distinction: required source information is a read; a write is conservative coverage of an existing record that the action could affect or conflict with. Mere mention, location or observation is not by itself a reason to declare a write. Keep genuinely possible effects, shared resources and justified broad scope. New records remain the later Truth Engine's responsibility. Actual dependency expansion and global readjudication remain authoritative.

The screen accepts only initial, unadapted compilation requests with no repair candidate or issues. Both physical fields are required, mixed or original-only syntax is rejected, and source/schema changes after binding fail closed. This is a benchmark adapter; no registered Composition or persisted contract changes.

## Plan

Bind the original initial request, rename only the two schema fields and their trusted instruction references, then restore the original response before existing preprocessing. Keep this adapter outside registered runtime Compositions. Freeze the complete compiler inputs and standard retrieval configuration for the live comparison.

## Verification

Exercise the actual gateway preprocessing boundary, preserving the complete original request context, canonical dependency sets and temporal fields. Verify overlapping and empty sets, complete schema domains, wrong wire shape and source drift. Compare fresh B/C compilations over all 49 original actions, retaining batch cardinality, provider, thinking setting, context and recovery policy. Freeze call ceilings and requests before HTTP. Record initial mechanical rejection, source-semantic footprint review, graph changes, token and latency costs separately. A smaller graph is not an independence certificate or complete-player success. Run relevant checks and check:fast before the local commit.
