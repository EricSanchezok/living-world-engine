# Observer-bound onset receipts

Artifact-Version: 1
Status: Approved

## Intent

Restore the boundary between a global action proposal and an observer's private perception at action onset. The continuing player-efficiency work requires correct information flow before a faster reaction can qualify as an improvement. Conservative conflicts and audiences identify questions for adjudication, not proof of sensory access.

## Contract

Every scheduled observer/source-action pair receives an explicit onset perception result grounded in the current world and authored rules. The engine owns the pair identity and complete assignment. A terminal result covers each assigned pair exactly once, distinguishing a perceived onset with a private stimulus from an onset that supplies no reaction stimulus. Unresolved or unsupported required evidence cannot be silently treated as a successful perception or repaired by inventing a channel.

Shared placement, accessible entity relations and successful checks are evidence to interpret in context. None automatically broadcasts action text. Friendship, kinship and authority do not create communication channels; distinct placements do not rule out authored remote perception. A visible onset can produce a reaction without an unnecessary roll. A required uncertain check still uses the original engine-owned numbers, commitments and RNG; its result cannot be rerolled or reinterpreted to disclose unsupported information.

The perceived stimulus is an observer-specific projection. It contains only what is perceptible at the current onset, using existing observer-local identities or validated introductions. Private intentions, silent thoughts, conditional future plans and eventual deliveries are not copied from the source proposal as already observed facts. The trusted adjudicator retains complete canonical evidence; that access does not transfer to AgentMind. The engine never repairs this boundary by redacting arbitrary words or weakening player freedom.

Private stimuli are carried by source-bound perception receipts, then materialized into the exact frozen reaction preparation. AgentMind and external Participants receive only those validated stimuli. The producer and CanonicalCommitter check assignment, source state, original intent, observer ownership, evidence references, successful check dependencies and receipt consistency. Preparation does not advance canonical time or commit beliefs. Replacement still precedes the independent next positive temporal boundary, preserving the [causal Activity contract](0005-causal-activity-interactions.md).

For assigned onset tasks, check admission verifies the receipt's necessary world-basis condition before fixing a check or consuming RNG: causes include an existing Fact or authored Law as well as an assigned source Action. A difficulty's numeric source alone does not substitute for this explicit causal basis. Missing evidence is repairable at proposal admission; it cannot be added by a later report to an immutable check. Existing reference validation still verifies the selected cause, and semantic adjudication remains responsible for whether it actually supports perception.

## Plan

Carry the observer reports in the existing perception completion response, reusing the current observation schema, local-identity materialization and source projection. Route all conservative onset candidates through that semantic boundary; remove the automatic placement/relational-Fact admission and raw-action stimulus template. Reuse existing routing functionality instead of maintaining a second interpretation. Pin the changed model, algorithm and preparation contracts and remove superseded runtime paths when the replacement is installed.

There is no new model request per observer and no higher repair allowance. Scenes already requiring perception reuse that loop's terminal response. Scenes using only automatic reactions acquire an explicit perception response; report that call and its latency as the cost of restoring missing semantics. Reassess any lost overlap separately. This contract makes no claim that a semantic projection is free or that a previous failed assessment/selection experiment qualifies for production.

## Verification

Exercise the actual SimulationEngine preparation and AgentMind entry with paired silent-secret actions whose observable behavior is identical, same-placement occlusion, isolated friends versus unrelated subjects, legitimate visible gestures, authored remote communication, and successful or failed required perception checks. The secret pair must not change the receiving Agent's stimulus merely because the private secret changed. Use deterministic model replacements only for engineering evidence and fresh model controls for semantic qualification.

Verify complete assignment and source binding, local introductions, no invented event provenance, tampered receipts rejected by the committer, no RNG or canonical mutation on rejection, external preparation/restart and replacement boundary selection. The existing check, observation and replay suites remain required. Run check:fast before local commits. Full 49-Agent initial, repair and continuation evidence, source semantic review and actual player action completion remain necessary for performance qualification; small controls and engineering tests do not prove the sixty-second goal.
