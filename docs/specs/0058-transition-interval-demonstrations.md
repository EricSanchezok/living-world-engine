# Transition Interval Demonstrations

Artifact-Version: 1
Status: Approved

## Intent

Within the delegated [non-thinking gameplay experiment](0029-nonthinking-gameplay-efficiency-experiment.md), test whether generic input/output demonstrations clarify the [source-selection interval contract](0057-transition-source-selections.md) without adding output fields or online calls. The method draws on text-only task demonstrations in [Language Models are Few-Shot Learners](https://arxiv.org/abs/2005.14165). That paper's GPT-3 results do not establish effectiveness for this engine or smaller local models.

## Contract

The prompt contains three authored, synthetic demonstrations: an unmet ordered prerequisite; local review before remote contact; and supported ongoing inspection with personal and delegated responsibilities. The examples contain no bundled-world identities, coordinates, lore or frozen diagnostic outputs. They distinguish attempted, ongoing and completed work and retain conditional branches in pending source ranges. They are development instructions, not independent evaluation data or game state.

Only prompt demonstrations and their version binding change. Keep the same source-selection schema, complete original context, twelve logical slots and forty-three actions, candidate domains, canonical validation and recovery limit. Use the same Flash model, disabled thinking, generation parameters, tokenizer admission and append-only budget. Do not copy example entities into a real result, infer completion from an example, replace source state with demonstration facts or default every action to waiting.

## Plan

After focused checks and check:fast, freeze one fresh source-matched diagnostic with at most two HTTP calls. Compare with the closed source-selection diagnostic while retaining all its failures. Review every source action, relevant state, current summary and expanded pending range. Formal coverage alone cannot qualify gameplay; failure or uncertainty retains the stage stop. No adjustment to this trial after its first send is permitted.

## Verification

Validate every demonstration's segment table against its full original text and its output through the actual interval validator. Ensure source pointers resolve and pending ranges preserve complete unfinished intent, while both supported work and waiting examples remain present. Exercise the existing gateway regressions and complete-message token admission. These checks validate example consistency, not model performance.
