# Action-local fact evidence

Artifact-Version: 1
Status: Approved

## Intent

Test whether placing the exact existing fact beside each eligible means source reduces incorrect source descriptions. Continuing autonomous experimentation authorization covers this optional layout change; it grants no additional budget or semantic approval.

## Contract

For the indexed reviewed planner, the optional planFactEvidence configuration annotates each eligible fact source in the existing complete action-owned inventory with its full projected fact record, source path and record hash. The task binds the annotation to the hash of the same visible canonical fact snapshot. It reads only the facts already projected into that request, never server-only or other-subject cognition. Other source kinds and the complete original context remain unchanged.

The instruction distinguishes an eligibility menu from required output. A means description must be supported by the selected record and original action; a related entity or location is insufficient. This neither mandates more means nor deletes a means or picks a source. Output fields, indices, decoder, materializer and semantic review remain unchanged. Missing or malformed eligible fact evidence fails preparation instead of inventing content. Repair uses its current bound snapshot and unchanged action-owned inventory.
