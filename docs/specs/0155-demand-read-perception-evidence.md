# Demand-Read Perception Evidence

Artifact-Version: 1
Status: Approved

## Intent

Test an explicit read interface after complete-context, assignment, source-index, decision-branch and sampling screens retain semantic failures. The experiment changes evidence access and its call graph; it does not qualify a smaller world or replace the [complete-player goal](0122-player-action-efficiency.md).

## Contract

Keep the complete original perception snapshot immutable and retrievable. The initial wire view includes all actions, actor records, dependencies, laws, checks, a losslessly factored complete reference catalog, and an exact observer/source index. Canonical tables expose complete key directories and explicitly marked loaded records. Preload mechanics, each assigned observer/source placement chain and observer-owned Ratings, and existing records cited by fixed checks. No semantic ranking, inferred visibility, invented record or world mutation occurs.

The model may return read_evidence with a batch of table names and exact keys. An empty key list reads the complete table; source_context with an empty key list reads the entire original context. Every successful read returns complete records and a source-bound digest and makes them available to later inference. Unknown tables or keys, duplicate selectors, source drift and exhausted read rounds fail explicitly. A failed read batch changes no loaded records. Terminal output cannot cite a deferred canonical record whose value has not been loaded. This check proves access to cited values, not semantic completeness or absence of omitted causes.

The gateway retains the complete logical source for existing reference validation; the experiment records the actual transformed HTTP bodies and read transcript separately. The reader uses a distinct evidence-directive schema identity, adds one output branch and omits the synthetic example while preserving the original check/report branches, source system/task instructions, canonical validators, model and inference settings. Its discriminator follows that expanded schema rather than forbidding the read branch. This is a composite access strategy, not an isolated test of catalog layout or prompt wording. The default full-context contract in [Spec 0105](0105-complete-onset-perception-context.md) remains unchanged.

## Plan

Freeze the complete initial perception request from the latest forty-nine-subject player source, before its first random commitment. Compare B/C/C/B sequentially. B must match the recorded initial HTTP body exactly and receives one call. Each C receives at most two read rounds and one final generation, for at most eight new HTTP requests overall. Preserve all eighteen assigned pairs and every source record. Stop before repair or executing proposed checks; a supported request_checks result is an initial decision, not completed gameplay. Record requested reads, loaded coverage, every response, raw usage, total arm latency and source-semantic counterexamples. Any integration needs required-check continuation, full canonical receipt and complete player qualification.

## Verification

Capture a real TruthEngine request with a fact outside its action footprint. Verify complete key coverage, exact individual/table/full-context reads, immutable source and returned copies, atomic rejection, read limits and rejection of unread citations. Confirm the actual wire transformation leaves non-context HTTP fields unchanged and the gateway still owns the full canonical catalog. Run relevant checks and check:fast before the local commit and paid dispatch. Measure all retrieval calls and repeated input; a smaller first prompt is not a speed result.
