# Perception Check Relation Domains

Artifact-Version: 1
Status: Approved

## Intent

Measure whether compiling known observer, Rating and assigned-action relations into the existing generation schema reduces first-response errors on complete player sources.

## Contract

The experimental adapter adds Draft-07 constraints to the canonical check branch. Each check selects an active assigned observer, an owned aptitude or explicit null, and cites at least one action assigned to that observer. All additional causes remain expressible. Opposed difficulty selects a displayed target, its Rating, and that same Rating as the source. The independently perceived entity remains independent of the opponent. The adapter preserves every legal combination, complete source context, canonical fields, report branch, random commitments and model settings. It does not decode or repair model output, infer a Rating, select null, eliminate justified checks or decide sensory access. Runtime validators remain authoritative.

## Plan

Retain the failed full-player source and prior negative Rating-choice experiments. Freeze the complete initial perception request with all 49 Agents and every assigned pair. Compare two first responses per arm in B/C/C/B order, with no repair or continuation dispatch. Reconstruct the baseline HTTP exactly before new calls. Freeze source, request, model, code and runner identities. Keep this candidate off the default runtime while measuring it.

## Verification

Capture the actual TruthEngine perception entry and verify canonical schema plus the additional generation constraints against valid null/owned/opposed checks and wrong-owner, wrong-source, unassigned and invented-reference neighbors. Preserve source hashes and independent observed versus opposed identities. Report initial schema/reference acceptance, relation acceptance, selected check semantics, tokens and transport time separately. Imported upstream work and blocked continuation are not full-player latency or successful completion. Only a subsequent complete player execution can evaluate the original gameplay goal in [Spec 0122](0122-player-action-efficiency.md).

This experiment retains canonical output and additionally constrains assigned source-action relationships in the field schema. It inherits no empirical qualification from the earlier candidate.
