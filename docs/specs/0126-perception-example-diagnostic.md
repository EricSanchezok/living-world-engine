# Perception example diagnostic

Artifact-Version: 1
Status: Approved

## Intent

Under the delegated player-efficiency work, isolate the existing JSON-example omission capability at the canonical perception entry. The generated example selects request_checks and invented string references, while a recorded no-route control incorrectly requests a check. This motivates a test, not a causal attribution.

## Contract

Both arms use the original canonical directive, full source context, schemas, inference settings and validation. The treatment only selects jsonExamplePolicy=omit and identifies that choice in its prompt version. The complete physical request must otherwise be identical. No task-context postlude, output codec, reference repair, outcome substitution or increased repair allowance is added. A mechanically accepted check can still violate world semantics.

## Plan

Freeze two repetitions of four existing visibility controls with alternating B/C order, followed only after all eight treatment controls pass by three alternating pairs of the latest complete 49-Agent perception source. The maximum is twenty-two new first-response HTTP calls. Block and report repair and continuation HTTP separately, retain every result, and never restart terminal trials. Keep the old task-context and transition-example failures intact. Verify source/observer assignments, profile, disabled thinking, complete request hashes and code revision before sending.

All three full treatment batches must pass original validation and source review before considering an integration. Done is not a semantic oracle. Record all token usage, cache and latency, including failures, without treating small controls or imported upstream work as player-action timing. This screen cannot establish general near-zero repair or the sixty-second goal.

## Verification

Use the actual gateway and Truth Engine to verify that omission removes exactly the generated example block, preserves canonical outputs, checks and RNG, and continues rejecting invalid references and owner assignments. Check empty and check-bearing results and preserve complete source state. Run relevant tests and check:fast before committing and paid dispatch.

## Evidence

The [adapter and wire check](../../src/engine/benchmarks/step-efficiency/perception-example-policy.ts) reuse the existing gateway capability. [Entry tests](../../src/engine/benchmarks/step-efficiency/__tests__/perception-example-policy.test.ts) own engineering evidence. The [earlier transition diagnostic](0061-transition-example-diagnostic.md) is a different failed workload, not evidence of perception efficacy. [Calibrate Before Use](https://proceedings.mlr.press/v139/zhao21c.html) motivates sensitivity to demonstration choices; this experiment neither implements its answer-probability calibration nor transfers its reported gains to the game.
