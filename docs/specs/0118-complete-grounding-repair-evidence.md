Artifact-Version: 1
Status: Approved

## Intent

Preserve independently detectable reference failures and rejected outputs in interaction grounding under the [authorized non-thinking gameplay experiment](0029-nonthinking-gameplay-efficiency-experiment.md).

## Contract

The grounding materializer collects all independent dependency, audience and resource-pool reference failures before dependent world and resource validation. Issues bind the exact output path, selected value, required use and complete legal reference domain. Unexpected implementation errors propagate. Invalid selections remain rejected; the engine does not convert identities, remove dependencies, or widen scope to make an output pass.

Every semantic repair receives the latest rejected output when available and its field-level evidence in the unchanged request-local namespace. Missing output is explicitly unavailable. State, source action, catalog, repair limit, model settings and canonical validation remain unchanged. Reference validity alone does not establish an adequate conflict footprint or correct action meaning.

## Plan

Reproduce evidence loss through the real model gateway with substituted HTTP responses, implement the complete diagnostics and existing semantic-loop output handoff, then run focused checks and check:fast before committing. Preserve failed trials and account for prospective paid tests separately.

## Verification

Exercise simultaneous disallowed dependency, audience and resource references and a gateway-rejected unknown reference. The next actual request must contain each exact path and value in its preserved candidate and only legal field candidates. A valid response must materialize identically to the control without mutating source state or increasing the recovery ceiling.
