# Perception Semantic Draft Screen

Artifact-Version: 1
Status: Approved

## Intent

Test whether separating semantic interpretation from canonical report construction resolves the source and verdict contradictions surviving [the grouped source index](0150-grouped-perception-source-index.md). This is a necessary-condition screen for a possible staged algorithm, not an executable perception replacement.

## Contract

Both arms retain all 49 subjects, 49 actions, world records, laws, reference permissions and assigned observer/source pairs. The control is the exact previous source-index request. The candidate replaces the role's generation task with a semantic draft: identify the observer and source actor, describe the current onset, establish the sensory/informational route, distinguish available information from future or private information, and report present access, no present access or unresolved uncertainty. Existing entity/fact/law evidence remains explicit. Unknown or wrong source bindings fail mechanically. Unresolved uncertainty is not terminal gameplay success.

The candidate preserves the original role-independent system instructions and source law postlude, replaces only the role task and its roleContract, supplies the same complete source index, uses its own strict draft schema and omits the synthetic output example. It does not ask for checks, local identity introductions or canonical stimulus claims. This intentionally changes the whole output task; the trial cannot identify a separate causal effect of schema size, examples, wording or delayed materialization. It cannot certify a canonical report by validating a simpler draft.

## Plan

Freeze B/C/C/B waves of five groups each, twenty actual HTTP calls, with the same complete source and disabled-thinking model. Before dispatch, reconstruct every B body from the preceding candidate archive and save all actual prospective bodies and producer hashes. No repair, second phase, RNG or world commit is dispatched. Retain failed calls. Compare the shared semantic questions independently of each arm's different format acceptance, input/output/cache tokens and complete-wave latency.

## Verification

Capture a real TruthEngine request and exercise the actual gateway with a scripted expensive boundary. Verify complete context restoration, exact source joins, original world-law delivery and immutability. Reject duplicate or missing assignments, swapped identities, invented evidence, canonical outputs masquerading as drafts and changed sources. Preserve unresolved values as unresolved. Require focused checks, complete preflight and check:fast before paid dispatch. Review all candidate assignments for present onset versus future intent, actual observer, access route and leaked private information. Only a consistently correct draft could justify designing and costing a second materialization phase; the final [player goal](0122-player-action-efficiency.md) remains unchanged.

## Evidence

The [assessment probe](0104-evidence-bound-perception-assessment-probe.md) already tests an explicit verdict plus check/evidence protocol and remains unqualified. This probe removes check construction and canonical receipt construction entirely to test a relaxed task on the new grouped source. [Decision](../decisions/0198-screen-semantic-drafts-before-report-materialization.md) records its limited purpose.
