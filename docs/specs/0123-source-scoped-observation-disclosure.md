# Source-scoped observation disclosure

Artifact-Version: 1
Status: Approved

## Intent

Remove demonstrated observation repair caused by unrelated private scalar values and private record keys becoming global vocabulary bans. Preserve cognitive isolation through source-owned identifiers, explicit fact relations, and the existing independent semantic review. This work follows the user's authorization to redesign algorithms for correct, efficient full-world play.

## Contract

A private scalar value alone is not an information identity. An observer's ordinary text or local claim must not become invalid merely because an unrelated private record stores the same scalar. Do not add common-word exceptions, infer missing references, rewrite output, reduce batch size, or add model calls.

Private cognition keys are checked in their actual typed reference namespace, retaining owner-qualified local-entity references. Complete private descriptions and foreign qualified references retain literal checks. Existing canonical-identity checks remain intact. An exact private fact assertion uses the observation's materialized local subject binding, predicate and value; nonpublic facts explicitly authorized to the observer and propositions already present in that observer's belief are permitted. Ambiguous bindings are not guessed. Scalar equality about another subject or predicate does not establish disclosure.

The deterministic boundary does not claim to understand arbitrary paraphrases or establish full narrative correctness. Existing source-bound causal review remains required before canonical admission, including unsupported replies, event attribution and preservation of uncertainty. The fixed kernel and all original observation materialization checks remain active. Validation changes receive a new execution producer version; saved historical failures remain immutable.

## Plan

Build positive and negative source-relation fixtures at the existing public-information entry point before changing the guard. Replace bare cognition-key and private-scalar matching with typed identities and explicit private fact relationships. Retain copied-description and canonical-identity regressions and exercise the complete renderer through deterministic model outputs. Record the escaped-failure mechanism and the original full-cohort counterexamples.

## Verification

Demonstrate unchanged admission of an ordinary observer output when only an unrelated hidden scalar or private cognition key changes. Reject actual foreign qualified references, copied private descriptions and exact unauthorized fact relationships, including different scalar types. Verify correct subject and predicate discrimination, already-known and explicitly authorized facts, newly introduced bindings and ambiguous bindings. Run the unchanged historical observation response through current materialization to distinguish removed collisions from remaining canonical identifiers and independent semantic errors. Run focused tests and check:fast before committing. No offline replay or reduction in false positives establishes a live model improvement or complete player-action acceptance.
