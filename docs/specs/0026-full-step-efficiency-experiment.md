## Intent

Make complete open-world steps work at a measured, controllable cost. Identify necessary successful work and remove avoidable rejected, redundant and invalidated work. Preserve full action batches, natural-language freedom, rules, cognitive isolation, canonical references, deterministic random commitments and atomic state transitions. The STEP-E1 report owns the causal evidence matrix, research, frozen experiments, operational results and budget index.

The work stays on the current experiment branch. Existing local acceptance results and historical ledgers remain immutable. Active STEP-E2 evidence and its separate journal belong to `.livingworld-benchmarks/experiments/step-efficiency/v2`; historical STEP-E1 evidence remains in `v1`. Local candidate instances may pin verified improvements; promotion requires real trajectory evidence rather than compiler-only scores.

## Contract

### Causal measurement

Bind actual HTTP requests to logical stages, physical batches, first attempts, repairs, continuations and discarded speculative work. Record raw body/response evidence, provider cache-hit/miss usage, latency, queueing, active requests, cancellation and price snapshots. Distinguish request start from completion after a terminal failure. Byte common prefixes and repeated JSON sections are layout diagnostics, never tokenizer or billing facts. Overlapping cost categories are not additive.

### Permitted interventions

Stop issuing expensive work after an atomic attempt becomes irrecoverably invalid. Drain or cancel pending work with explicit billing status, preserve the first causal failure and emit a partial report. A stopped attempt cannot commit partial world changes. Recoverable per-slot model errors retain bounded repair.

Represent existing typed references and exact shared context without inventing facts or deleting action constraints. A factored batch must reconstruct each original logical envelope exactly, including null and absent values, array order, slot assignments, catalog identity, repairs and state version. References remain scoped to the correct logical slot. Compatible independent tasks may share physical calls; different model settings, authority boundaries and cancellation lifetimes cannot be merged silently.

Repair reuses each original action’s candidate selection within its physical root and immutable execution snapshot. Slot renumbering changes only scope indices, never candidate identity or meaning. The root catalog preserves its original state evidence even when relevance projection for the smaller batch would replace details with null; omitted private slots remain nonselectable. Reuse does not query the encoder, broaden legal membership or recompute the root candidate budget from a smaller repair batch; audit records distinguish the root allowance from the displayed repair pool. A missing or changed selected candidate fails before a model call.

Stable context layout may move unchanged information to a reusable prefix while preserving message authority and all data. Report actual provider cache behavior rather than assuming that a second similar request hits. Any resolution continuation change preserves legal outcome-dependent random requests and the prohibition on rewriting committed plans. Random scheduling preserves the single canonical stream, ordered draws and replay, without resampling successful model decisions merely to recover RNG order.

Information-boundary corrections preserve the distinction between private content and identifiers whose meaning requires an owner namespace. Another Agent's local alias alone cannot ban ordinary vocabulary; qualified foreign references, canonical identifiers and private descriptions retain their checks. The [namespace decision](../decisions/0114-owner-scoped-local-information-identifiers.md) and its regression tests own this boundary. A corrected literal screen does not replace source-bound semantic review or authorize cross-Agent cognition.

Finite work with an open natural-language objective and no verified duration may use a script-authored `goal` temporal profile. Its checkpoints request progress adjudication without asserting completion; a supported successful outcome closes the Activity. Explicit continuation prerequisites remain optional and, when present, must hold at onset and subsequent boundaries. The compiler cannot invent an always-true prerequisite to satisfy representation requirements. Conditional waiting retains its required nonempty condition, and ongoing activity retains its open-ended contract. Source action, resource claims, interruption, causal validation and atomic replay remain authoritative. This bounded temporal extension requires real loader/compiler/committer tests and source-bound gameplay review before a world candidate uses it in paid execution.

A prospectively selected compilation representation may bind Activity description to the exact original action text. It omits this redundant field from required model output and restores it only from the request slot’s immutable source action. An optional supplied description must match exactly; contradictory text is rejected, never overwritten and counted as successful recovery. Profile choice, dependencies and effects remain model decisions subject to their existing checks. This is a field-ownership intervention, not evidence that earlier paraphrases were semantically equivalent.

An opt-in temporal choice layout may repeat each already visible profile's exact label and authored details beside its schema selector. It preserves all legal values and the entire original context, distinguishes scheduled completion from a progress checkpoint, and fails if the required visible evidence is absent. Eligibility establishes evidence availability rather than semantic fitness. The Composition pins this choice separately from source description ownership; annotation does not authorize deterministic profile selection or establish gameplay success.

### Budget and experiments

A prospectively pinned physical batch request may bind its existing output slot count and ordinal range to the actual submitted batch and omit generated output examples that cannot express the task's real coverage. This adds no semantic choice, does not alter original logical schemas or context, and preserves identity validation and localized recovery. Repair and split requests recompute only their physical cardinality from the unchanged logical requests. Keep this rendering treatment opt-in and report its new prompt/Composition binding separately from proven gameplay effects.

An explicitly configured account may resolve its provider hostname with HTTPS DNS to avoid a failing local synthetic DNS route. Preserve the configured provider origin, TLS hostname verification and request bytes; send only DNS names to the resolver, honor answer and alias TTLs, reject unusable answers, and never silently fall back to the failing route or retry paid work. This is a transport intervention, separate from algorithm or model efficacy.

A prospectively recorded trajectory may attempt socket establishment twice for an allowlisted transient connection failure, only before the connector yields a socket to the HTTP client. It never retries an upgraded existing socket, a certificate failure, or an error after handoff. Model transport attempts remain one and request bytes remain unchanged; record socket attempts separately from HTTP dispatches and model usage. Final unresolved sends still retain their full budget reservation. The default account transport remains one socket attempt unless this explicit option is selected; [decision 0111](../decisions/0111-bounded-socket-establishment.md) owns the rationale.

Use DeepSeek Flash with thinking disabled and existing generation limits. Experiments cannot enable thinking or increase model capability to compensate for algorithm failures. Verify official model/pricing behavior before paid work. Record a conservative price ceiling and time-specific estimates separately from unknown actual billing. All new paid requests, failures, evaluator probes and bootstrap calls count toward CNY 1000. Concurrent reservations count against exposure; an active request is distinct from an abandoned request with unknown usage. Unknown requests retain their reservation and cannot be silently rerun.

After all active requests drain, an explicitly reviewed unknown request may be quarantined with its evidence hash and reason. Quarantine permanently closes the source trial and retains its full monetary and token reservation in every budget limit. It does not create usage, refund money or claim that the provider waived a charge. Distinct prospectively recorded trials may proceed within the remaining exposure; unreviewed unknown requests still block all sends. The default experiment runners never quarantine automatically.

If a saved provider response establishes valid usage beyond a reservation estimate, the trial still stops. After all requests drain, explicit evidence review may reconcile that usage through an append-only entry with a reason and evidence hash, charging all incurred tokens at the original price binding. Reconciliation permanently closes the source trial and does not repeat the request. Actual cost, including any exceeded limit, remains in every subsequent admission check; missing or inconsistent usage remains unresolved. Runners never reconcile overruns automatically.

First reproduce deterministic defects with recorded evidence and simulated expensive boundaries. Freeze each paired experiment's inputs, treatment, repetition count, ordering, cost cap and stop rule before its first paid call. Do not retrofit winners or thresholds. Exploratory changes get new experiment identifiers. Do not repeat expensive failed full steps merely to observe an already proven defect.

Between closed experiments, prospective phase reserves may be reallocated within the user's unchanged total authorization. An append-only allocation entry binds the new limits to an evidence hash and reason; every originally covered phase remains covered exactly once, the combined allocation cannot exceed the original total, and each group must still contain all incurred and reserved costs. Active requests and unreviewed unknown usage block reallocation. Prices, request counts, token limits, quarantined trials and historical entries remain unchanged. Reports identify both the base policy and the effective phase allocation. A new allocation is not permission to repeat a stopped trial or relax an experimental gate; [decision 0113](../decisions/0113-append-only-experiment-phase-allocation.md) owns the accounting rationale.

Final gameplay acceptance requires at least three successive real full-world commits through WorldHost, validated increasing step/revision/time, durable replay and correct observable consequences. Include all failed attempts in total cost. Use a fresh confirmation trajectory for any frozen winning composition; report scenario limits and do not infer general semantic correctness from model self-evaluation. Continue until acceptance; a budget or unresolved billing boundary stops paid dispatch with a complete partial report if acceptance remains unmet. A per-request timeout or per-step watchdog bounds one attempt and does not define an overall task deadline.
