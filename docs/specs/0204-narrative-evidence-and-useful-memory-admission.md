## Contract

- A delivered utterance establishes its delivery and speaker, not the truth of its premises, requested movement or reported completion. Narrative inputs distinguish the spoken record from nonverbal execution and independently observed surroundings. Actual accompanying manner remains available. A first mention, invitation or request cannot establish absence, arrival or departure.
- Elapsed time is interpreted using the source boundary's authored local units. Deterministic equivalent durations make the scale explicit before generation and publication. The source also records an exact already-observed public phase boundary only when its own subject, predicate, value and observation time match the authored transition at that instant. A nearer public property, including constant illumination, shadows an ancestral schedule; an old observation or mere daytime value cannot establish dawn. The same derivation runs for ordinary and recovered historical sources. The required source field is stored in instance format 35. A long interval does not itself prove any sunrise, sunset or repeated calendar phase. Only supplied phase observations and applicable public schedules support those assertions. Locations with constant illumination or no solar cycle remain valid.
- Earlier published prose supplies reference continuity, not proof of its own claims. New receipts and subject-specific observed properties retain their time and attribution. Recovery and normal publication use the same projection, without importing later world state, another actor's private knowledge or hidden schedule values.
- Publication retains its existing six simultaneous semantic checks and configured reasoning profile. This change adds no per-paragraph verification stage and does not reduce batch cardinality. Generation may express a quiet interval briefly and naturally without an exhaustive conversion table in the displayed story.
- Memory admission requires a useful eligible prefix even under full-request pressure. Recent evidence, mandatory exact records and already protected records remain outside disposable headroom. The existing minimum new-history and rewrite-amortization thresholds apply at both background and hard-capacity boundaries. A request that cannot fit after available useful compaction fails explicitly or follows its existing configured model fallback; it never deletes records to appear successful. This replaces the unconditional hard-capacity bypass in [Spec 0193](0193-memory-pressure-efficiency.md).
- Small new evidence and unrelated context changes do not authorize repeated ineffective compactions. Exact failed-source suppression remains in force. A newer successful checkpoint permits the ordinary request rebuild. This scope introduces no fixed compression ratio, forced forgetting, retrieval or world-specific inference branch.
