# Perception Report Field Domains

Artifact-Version: 1
Status: Approved

## Intent

Under the [player-action efficiency experiment](0122-player-action-efficiency.md), test whether field-local reference domains and an explicit identity-denotation description reduce malformed provenance and part/whole binding mistakes. A global catalog's assertion permission does not authorize every output field. This experiment preserves the existing evidence boundary rather than accepting source actions as established world evidence.

## Contract

The benchmark adapter specializes only the generation schema for terminal perception reports. For evidence, check references, existing local claim identities and canonical introduction bindings, enumerate every catalog handle of the required kind with the permission used by the existing materializer. Identical domains share one schema definition referenced from each field, avoiding repeated long catalogs. Empty domains permit no existing value while preserving empty arrays, nullable bindings and proposal references wherever the original schema allows them. Keep all candidate data and ordering, all report fields, target cardinality and source context. No semantic relevance selection or observer inference is performed; observer ownership and target coverage remain canonical checks.

The canonical introduction reference describes identity, not ownership, containment or a part/whole relationship. A local entity naming a distinct part cannot bind to its carrier solely because that carrier exists. Unbound local identities and evidence-supported new appearances remain possible; no rule bans introductions or forces existing identity reuse. This description clarifies the existing identity contract, but cannot mechanically prove a natural-language denotation.

The canonical request schema, preprocessing, check branch, generated example, model settings and all validators remain unchanged. The adapter changes only the terminal report generation schema and pins that transformation in the prompt version. It neither rewrites outputs nor filters invalid fields. Reject incomplete, duplicate or mismatched catalog membership and pre-existing wire adaptations rather than silently composing incompatible experiments. This is prompt-visible schema specialization in hosted JSON mode, not constrained token decoding.

## Plan

Freeze a comparison on the ten complete onset sources with alternating order. Both arms retain the complete law index and explicitly select the independently verified terminal-root-closer parser. The treatment alone adds field domains and the identity description. Preserve required check continuations, block repair requests before network dispatch and count their demand. Permit at most twenty primary calls and four required continuations. Quantify small-source and historical complete 49-Agent request size before paid dispatch. Any default integration requires separate source-semantic and full-player qualification; older failed prompt combinations remain evidence.

## Verification

Verify each domain equals the entire applicable source-catalog set and preserves literal opaque handles. Verify the source, canonical schema, check branch, example and every other physical request field remain identical. Exercise real gateway-to-Truth materialization for valid reports, invalid references, cross-observer identities, missing targets, justified fixed checks and ordinary repair. Preserve null bindings and new local proposals. Review every reason, stimulus, introduction and claim against complete sources after live trials. Run focused checks and check:fast before committing or paid dispatch.
