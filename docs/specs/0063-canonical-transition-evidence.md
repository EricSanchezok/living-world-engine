# Canonical Transition Evidence

Artifact-Version: 1
Status: Approved

## Intent

Within the user-delegated [gameplay optimization](0029-nonthinking-gameplay-efficiency-experiment.md), preserve the existing action-to-evidence view when a transition uses the canonical single-request path. A logical component can contain many actions; one physical request is not one action.

## Contract

The indexed-reviewed candidate advances to version 3. Canonical transitions retain their original output representation and full source envelope while receiving the same exact per-action plans, receipts, activities, participant placements and visible facts used by the physical worklist. The helper is shared, so a repair cannot silently lose these evidence relationships. Copies add no permission, knowledge, effect or inferred event. Source actions and every existing reference remain available.

The wire schema exposes the already-required outcome count and source action-reference domain. Repeated assertion definitions use the existing reversible local schema references. The automatically invented empty example is omitted. The canonical schema, coverage/reference validation, causal review, observer checks, atomic commit and repair limits remain authoritative. No model-produced field is filled, inferred, corrected or dropped. The experimental logical feedback tail is not selected by this change.

Original canonical candidate feedback and binding hashes retain the same representation as the response; no synthetic batch, new physical call, resampling, hidden retry or extra critic is added. Multi-component indexed wire behavior remains unchanged. The registered identity and fresh-instance manifest bind the changed canonical request policy; old saved instances are not reassigned.

## Plan

Share evidence extraction, add canonical request framing, and verify through the actual gateway, coordinator and real step. Freeze complete request/state/schema hashes and tokenizer admission before any paid use. A fresh integrated diagnostic follows the retained [full-world acceptance contract](0060-integrated-transition-gameplay-diagnostic.md); raw formal success cannot certify semantics or gameplay. Preserve all prior failures, costs and unknown reservations.

## Verification

Prove exact restoration of the source by deleting only the derived worklist. Compare canonical and physical evidence rows for the same action. Expand local schema references and prove equality apart from the explicit count/domain constraints. Test an original request and logical repair through the coordinator, retaining the bound rejected candidate, model settings and one HTTP per logical request. Reject missing source evidence or conflicting adapters. Run relevant tests and check:fast before committing.
