# Action Phase Graph Screen

Artifact-Version: 1
Status: Approved

## Intent

Test whether explicit partial ordering preserves compound action semantics better than direct current-onset summaries. The [source-frame screen](0159-source-onset-frame-screen.md) supplies the control. This is a prerequisite diagnostic for the [complete-player objective](0122-player-action-efficiency.md), not a production scheduler or a claim that extracted plans are true.

## Contract

Retain the complete original world, all source actions, laws, assignments and exact source index. Generate one graph for each distinct assigned source. Each step has a source-bound description, exact excerpts from that action's rawText or means, a performer, directly addressed parties, completion predecessors and explicit external prerequisites. Steps remain open natural-language attempts; no primitive game action catalog is imposed. Private strategic intent is separate from attempted work. Conditions on quoted speech are not automatically conditions on speaking that quotation.

The decoder binds source identity, quotations and selected entity references, rejects duplicate or missing sources, invalid edges, duplicate edges and cycles, and preserves unresolved performer identities. A deterministic initial frontier labels steps with predecessors as waiting for predecessors, otherwise steps with external prerequisites as waiting for external evidence, otherwise steps performed by another or unidentified entity as external performance, and the remaining source-actor roots as candidates. This is readiness under an untrusted graph, never proof that a step has started, completed, been perceived or passed a check. No graph or frontier is materialized into canonical state.

Explicit parallel attempts may have several roots. An independent question is not deferred until an unrelated administrative task completes. A messenger's arrival or another person's response is not established by the sender's request. Preconditions remain prose requiring later adjudication; the diagnostic never treats arbitrary model text as an executable predicate or silently declares uncertainty false. The complete original actions remain available to identify omitted work, invented ordering and privacy leakage during semantic review.

## Plan

Freeze four first-response B/C/C/B HTTP calls using the complete forty-nine-subject player snapshot and official non-thinking model. B generates source frames; C generates graphs for the same fifteen distinct sources. Preserve raw responses, source hashes, actual physical requests, usage, cache and elapsed time. Permit zero repairs, continuation, new RNG or world commits. Review every candidate graph and derived frontier against the full source, including concurrent speech, delegated delivery, absent participants and quoted conditions. Different output tasks and a small sample cannot establish a deployment speedup.

## Verification

Capture an actual TruthEngine request and exercise the real gateway while replacing only external HTTP. Verify independent root attempts, completion dependencies, external prerequisites, unnamed performers, private intent and raw quote binding. Reject cycles, invalid references, source omissions and stale context while retaining failed audit evidence. Check input/RNG immutability and absence of canonical reports. Run focused checks and check:fast before a local commit and paid freeze. Any integration requires source-semantic qualification and a separate contract for adjudication, lifecycle, privacy and world persistence.
