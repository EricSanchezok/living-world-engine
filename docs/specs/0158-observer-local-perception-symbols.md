# Observer Local Perception Symbols

Artifact-Version: 1
Status: Approved

## Intent

Within the authorized [player-action efficiency experiment](0122-player-action-efficiency.md), test a request-bound symbol table for existing identities in private perception claims. Hosted generation must select a local referent without constructing another observer's qualified handle. Semantic identity selection remains model-owned.

## Contract

The benchmark codec composes only with the exact [temporal route request](0157-temporal-route-perception-screen.md). For each assigned target, preserve the observer's entire ordered existing local-entity inventory, original catalog records and canonical bindings in an additive table. Each existing claim subject or local-entity value selects an integer from that target's table. The decoder restores exactly that row's opaque local handle. Proposal references and explicit introductions retain their original forms, including null canonical bindings. Empty, ambiguous and multiple canonical bindings do not trigger inference or automatic identity merging. No new entity, claim or introduction is supplied by the codec.

All original context, source index, evidence, semantic fields, checks and route cases remain intact. Only the two existing-local-reference fields change representation. The wire schema advertises each target's complete index domain; the decoder rejects literal handles, unknown targets, invalid indices, stale source bindings and incompatible adaptations. The temporal decoder then validates assignment and case constraints; the original canonical schema and receipt materializer validate the reconstructed result. All rejected attempts retain their raw audit. Invalid references are not repaired, translated by name or silently dropped. Production defaults and persisted contracts remain unchanged.

## Plan

Freeze a complete-source B/C/C/B comparison with four first-response HTTP calls, no repair, continuation, new RNG or world commit. B uses the temporal route representation; C adds observer-local symbols. Keep all forty-nine subjects and actions, eighteen assignments, official non-thinking model settings and exact source evidence. Confirm identical same-arm physical bodies and source bindings before dispatch. Report request size, token usage, latency, reference failures and source-semantic review separately; a private-identity error disappearing does not establish correct perception or a successful complete player action.

## Verification

Use real TruthEngine and gateway entry paths with only external HTTP replaced. Compare existing-identity and explicit-introduction receipts against canonical temporal drafts. Exercise two observers sharing a numeric index, unrelated and unbound identities, invalid raw foreign handles, out-of-range indices, undeclared proposals, check continuation, failed checks and ordinary repair. Verify unchanged input, RNG, check branch and every unencoded semantic field; reject stale, duplicate or inconsistent inventories. Run focused tests and check:fast before committing and freezing paid requests.
