# Observed Activity Interruptions

Artifact-Version: 1
Status: Approved

## Intent

Prevent a possible interaction audience from pausing an Activity when the observer received no external stimulus or event. This applies the observer-bound knowledge contract to post-boundary policy eligibility and supports the [complete-player objective](0122-player-action-efficiency.md).

## Contract

Onset interruption uses the frozen, validated reaction stimulus and its decision before the temporal boundary. That stimulus does not trigger the same decision again after the boundary. Automatic post-boundary interruption requires a current observed event causally attributable to another actor's adjudicated action. Event provenance follows the current action, event, check, random and mechanic graph. An observer's own action progress, clock-only outcome, an unobserved external event and conservative audience membership alone do not supply this evidence. Explicit keep-and-continue decisions retain their existing effect. Completion, failure, blocked continuation assertions, Timer and Condition decision points remain independently authoritative.

The producer renders the complete authorized boundary observations, then settles observation interruptions from those packets and the immutable temporal base before final causal review and cognition. This uses the existing observation stage and schema. It neither removes context nor adds a relevance-classifier call. If settlement expands observer coverage, only newly uncovered observers require additional rendering. If final review replaces transition evidence or observations, settlement is recomputed from the immutable base; an earlier rejected packet cannot leave a pause behind. A candidate's event references and onset transcript must pass the existing source, causal and information-flow validators.

CanonicalCommitter independently derives the same interruption evidence from the validated candidate and frozen preparation. A forged pause, altered stimulus or changed retained footprint cannot become authoritative through matching model prose. The changed execution contract and producer identities reject obsolete compositions directly; source experiment evidence is retained without migrating saves or introducing a second runtime path.

## Plan

Own provenance-based interruption selection in a deterministic mechanics function shared by producer and committer. Move observer-triggered settlement after observation generation while keeping continuation validation before it. Preserve the full conflict closure, original actions, batch limits, repair limits and canonical transaction. Pin the changed execution identity and update owning reference material.

## Verification

Reproduce no-stimulus pauses at the real SimulationEngine and CanonicalCommitter boundary with both equal and unequal Activity checkpoints. Verify a witnessed external event can interrupt, an unobserved event cannot, own progress cannot, and a repaired observation cannot retain a rejected interruption. Reject forged pause and missing-interruption candidates atomically. Retain actual onset, keep/replace, Timer, invalidated-premise and replay checks. Run focused tests and check:fast before a local commit; a fresh full forty-nine-subject player run and independent semantic review remain required before claiming the latency objective.
