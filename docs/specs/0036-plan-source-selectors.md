# Source-Bound Plan Selectors Experiment

Artifact-Version: 1
Status: Approved

## Intent

Within the authorized nonthinking optimization scope of [0029](0029-nonthinking-gameplay-efficiency-experiment.md), test an exact selectable representation of plan targets and means sources. Preserve complete actions, visible evidence, batch cardinality and all legal selections.

## Contract

An opt-in physical provider adapter annotates existing target-eligible entity catalog entries and each assigned action's existing allowed-means inventory with stable, collision-checked selectors. Target selectors identify an exact visible entity; means selectors bind both the selected source kind/ref and the owning action. Selectors remain stable when a repair batch shrinks or changes order. Shared context expansion verifies source hashes before annotation, and annotated contexts receive fresh shared-codec bindings. Removing annotations restores the complete initial source context; repair examples additionally use the reversible output representation. No prose, world fact or candidate is removed or interpreted by the codec.

The model explicitly selects these values in plan targetRefs and means.source. The decoder restores only exact current-slot and current-action matches, retaining array order and duplicates for existing validation. Unknown selectors and cross-action sources remain invalid; the codec does not choose substitute evidence, change an action, add causes or construct outcomes. Other fields keep their canonical meaning. Independent valid slots remain recoverable when another slot contains an invalid selection. Recorded repair examples use the same representation; raw HTTP evidence remains intact. The canonical materializer, grounding checks and semantic review retain authority after expansion.

The adapter composes beneath batching and after dependent-field encoding without changing runtime defaults. Its request identity binds the codec instructions and wire schema. No native constraint guarantee is claimed. Existing canonical references in unsupported wire positions are rejected rather than silently accepted as an alternate representation.

## Plan

Validate the codec offline, then freeze a bounded paired probe using both complete captured planning roots and the existing budget journal. Report selector overhead, first-call and final admissions, HTTP, tokens, cache hits, latency and failure classes. Promotion requires measured benefit and source review before a fresh gameplay run.

## Verification

Exercise exact round trips over every visible choice, malformed selections, action and slot isolation, shrinking repairs, source hash corruption and unchanged free text. Exercise the real physical coordinator with dependent-field decoding, including valid-slot salvage and canonical rejection of invalid selectors. Run relevant tests and check:fast before committing.
