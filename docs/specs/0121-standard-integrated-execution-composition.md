# Standard integrated execution composition

Artifact-Version: 1
Status: Implemented

## Intent

New ordinary world instances use the integrated execution composition selected for rollout: reversible action compilation, relational candidate retrieval, source-indexed reviewed planning, shared batch transport and source-bound observations. Promotion establishes the maintained default, not a claim that open semantic correctness or continuous-play latency has passed experimental acceptance.

## Contract

The default composition is built from existing registered Role implementations. It pins AT compilation with original-action descriptions and visible profile evidence, relational RRF, indexed reviewed planning with source causes, means, facts and boundary-clock evidence, shared catalog encoding, declared random completion, scoped plan repair, post-Promise batching and source-bound observation evidence. Existing batch sizes, complete context, canonical validation and atomic commits remain in force. Unqualified optional representations and perception probes remain opt-in.

Small worlds must preserve mandatory action, actor, target and eligible temporal-profile references even when their union exceeds the proportional retrieval budget. Relational RRF v2 with runtime v6 pins `mandatory-floor-v1`: the effective root budget is the larger of the existing proportional budget and the mandatory union. Only this necessary floor may enlarge the shortlist; ranking, slot visibility and repair membership stay fixed. Diagnostics distinguish nominal and effective budgets, and historical strict-ratio compression claims do not apply to floor-expanded batches.

The bundled DeepSeek profiles select the tested deepseek-flash identity with thinking disabled and native SSE. Complete local metadata supports exact resolution if the remote metadata directory has not indexed the identity. Account dispatch uses the tested four-request concurrency and bounded connection establishment; no unknown request is automatically resent. Provider selection remains catalog-owned, independent of algorithm identity.

WorldHost selects this composition only for newly created ordinary instances. Stored instances and replay retain their exact producer hashes; there is no silent save migration. Explicit research/control compositions remain available through their existing factories and are not rewritten by changing the host default. A missing retrieval asset or invalid model profile fails before bootstrap.

## Plan

Define the integrated composition in the production algorithm layer and select it at the WorldHost default boundary. Keep the research runner's control construction explicit. Update the catalog, owning runtime documentation and bundled model configuration. Verify default instance persistence, restart and actual provider requests before publishing the branch and merging after CI succeeds.

## Verification

Exercise the real WorldHost creation path without a default override and verify the complete persisted composition and its Inspector projection. Run the integrated provider path with a deterministic model boundary, preserving strict validation. Check model profile resolution, thinking-disabled SSE requests and resource preflight. Run check:fast and the production browser/accessibility/visual workflow; merge only the checked revision.
