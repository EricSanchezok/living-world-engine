# Player action efficiency

Artifact-Version: 1
Status: Approved

## Intent

Make complete player actions in the bundled world finish within 60 seconds with near-zero semantic repair, preserving the original action freedom, world activity and grounded consequences. The user authorizes algorithm and architecture experiments, local implementation and commits, research records and real-player testing in the current worktree.

## Contract

Use all 48 autonomous Agents plus one external player and the configured DeepSeek Flash model with thinking disabled. Measure from player submission through completed Activity, atomic world persistence and player-visible feedback. First feedback, a checkpoint, a mechanically valid candidate and an offline replay are separate observations, never substitutes for complete action latency. Keep the complete source actions and world semantics; do not suppress NPC activity, convert uncertain checks to automatic success, fabricate effects or remove semantic validation to meet the target.

Experiments retain immutable source identities, complete requests and responses, model settings, code revision, initial rejection, repair recovery, terminal failure, input/output/cache usage and timing. Each prospective comparison fixes its arms and call ceiling before network access. The new approximate CNY 1,000 authorization is tracked separately from historical research expenditure. Existing evidence may establish a negative baseline without repeating initialization; model-visible candidates need fresh source-bound comparisons before adoption.

The initial candidate clarifies that check effects are conditional stakes committed before randomness, not assertions that success has already happened. It changes instruction wording and schema descriptions only, retaining every field, value domain, action, context and validator. It cannot infer effects or resolution modes in code. An unchanged baseline and this candidate run on the same complete source request; full source-semantic review follows mechanical admission.

The profile-domain candidate specializes effect profile fields from the complete source catalogs and their authored mechanic collections. Its physical union includes every eligible duration, condition and impact profile, retains null for open conditions, and preserves the original field predicates and per-slot validators. It adds no output rewriting. The control carries the conditional-stakes wording; the treatment adds finite profile choices and explains the existing risk-owned threatened magnitude. Neither arm may fabricate a profile or accept an unknown namespace.

The action-frame candidate joins each assigned action to its exact actor Entity and existing Activity at the current temporal boundary, placing this complete source evidence beside the action assignment. This additive projection preserves the original context and output schema, rejects ambiguous ownership and changed source bindings, and supplies no interpreted progress or outcome. Its first comparison uses the profile-domain candidate as control and adds only the bound frames and their interpretation instructions. Source-semantic review must distinguish another Agent's similar intent and a future Activity objective from the current actor's work in the current interval.
