# Grouped Perception Source Index

Artifact-Version: 1
Status: Approved

## Intent

Test source adjacency within the existing five-group perception diagnostic. The preceding candidate reduces first-response wave duration but still reverses observer/source identities, invents absent aptitudes and misreads current placements. The earlier intact-batch task-context experiment remains unqualified.

## Contract

Both arms use the same complete world and observer assignments from [Spec 0149](0149-observer-group-perception-screen.md). Candidate requests append a deterministic join of each assigned pair with the exact observer record, source actor record, complete source action, complete current placement chains and existing observer-owned Ratings. Catalog statePath identities join canonical Entity and Placement records without matching names or manufacturing handles. Missing, duplicate or inconsistent bindings fail before inference. The index supplies evidence, not access verdicts, ability selection, future outcomes or checks.

## Plan

Run B/C/C/B complete-task waves, each containing five concurrent requests. Twenty new HTTP calls cover the same 35 relationships twice per arm. Reconstruct every B body exactly from the corresponding saved candidate request of the preceding group trial. Preserve original prompts, schema, catalog, laws, complete context and disabled-thinking model; C only appends the declared index and its interpretation instruction. Freeze source, parent baseline requests, producer patch and actual physical bodies before dispatch. No repair, continuation or world commit is dispatched.

## Verification

Capture the real TruthEngine request. Verify exact raw action and identity joins, owned Rating records, full placement chains including roots, source immutability and unchanged canonical schema. Reject wrong ownership, cycles, missing edges and changed source during decoding. Runtime reference, assignment and relation validation remain authoritative; review direct communication, remote intended communication, observer identity and onset versus eventual outcome independently. Compare complete-wave latency, initial failures, output volume, input/cache tokens and all rejected responses. A source index that can be reconstructed does not prove that the model uses it correctly.

## Evidence

[The prior task-context screen](0125-perception-task-context-probe.md) studies adjacency in an intact batch using runtime input. This screen tests its interaction with the new observer grouping and builds the index directly from the complete rendered source. Neither prior negative experiment grants qualification. [Player efficiency](0122-player-action-efficiency.md) remains the final acceptance contract.
