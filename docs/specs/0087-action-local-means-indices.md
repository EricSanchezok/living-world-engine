# Action-local means indices

Artifact-Version: 1
Status: Approved

## Intent

Avoid long selector transcription errors while preserving every action-owned means source. The continuing autonomous optimization authorization covers this opt-in experiment without additional model budget or semantic approval.

## Contract

The indexed reviewed planner can explicitly select action-local means indices. Each complete worklist action retains every original allowedMeansSources entry and adds its zero-based sourcePosition. The model emits means.sourcePosition instead of the hashed means.source selector. The decoder restores exactly that action's selected selector, then the existing selector codec restores kind/ref. Descriptions, order, repeated choices and all other plan fields remain model-owned and unchanged.

The projection is bound to the complete original request and action identity. No choice is ranked, omitted, guessed or supplied by default. Unknown positions, mixed fields and malformed values remain invalid; an independent valid slot remains available. Current repair scopes receive current positions and rejected index domains remain traceable. An invalid historical selector cannot be encoded into a valid position. Original grounding, semantic review and materialization are unchanged.

The optional contract is pinned in the Composition, separate from cause indices. Defaults and closed experiment snapshots are unchanged. Exact source reconstruction does not establish semantic correctness of the selected means or fluent gameplay.

## Plan

Extend the existing indexed planning projection and inverse rather than introducing a second planning path. Register the optional selection, reproduce the observed invalid selector, verify exact round trips and game-entry routing, then freeze a complete recorded-input diagnostic on checked and committed code.

## Verification

Check canonical round trips, order and repeated means, complete inventory retention, source drift, invalid positions, mixed representations and independent neighboring slots. Retain rejection of the recorded misspelled selector rather than correcting it. Verify optional registry routing, run focused tests and check:fast before committing, and report source-choice validity separately from semantics, cost and gameplay.
