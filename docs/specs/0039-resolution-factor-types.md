# Resolution Factor Type Experiment

Artifact-Version: 1
Status: Approved

## Intent

Within [0029](0029-nonthinking-gameplay-efficiency-experiment.md), test a reversible factor representation that removes repeated choices already fixed by the selected factor contract. Preserve source evidence, semantic freedom, full batches and non-thinking inference.

## Contract

An opt-in physical request codec replaces each factor's authority and role with one explicit factorType literal. Only direction and steps fixed to a single value by that selected canonical type are omitted and restored mechanically. Variable direction, authored magnitude steps, channels, source references, explanations and all other plan fields remain explicit. Every valid canonical factor has an exact round trip. Risk, permission and secondary factors remain nonnumeric notes; numeric control, potency and protection remain distinct choices.

The codec never repairs a contradictory canonical factor into a different meaning. Unknown types, missing choices, conflicting redundant values and invalid source authority remain invalid. Valid factors in rejected candidates use the same reversible encoding; invalid candidates and feedback retain their evidence. Original source context, identities, permissions, candidate sets and acceptance rules remain unchanged. The codec composes with existing physical representations without splitting requests or changing runtime defaults. Promotion requires a separately frozen prospective trial and source-bound semantic review.

## Plan

Implement exact factor transforms and derive the wire alternatives from the canonical schema. Verify all legal type combinations, independent choices, malformed output isolation, physical batching and repair ownership. Measure source-preserved request/schema size offline before freezing a paid comparison. Preserve failed trials and charge all new requests to the existing ledger.

## Verification

Exercise canonical schema validation before and after round trips, including authored and semantic sources, numeric directions, channel values and both authored magnitude steps. Reject translated or missing types, wrong roles, conflicting constants and malformed source references without changing neighboring factors or slots. Test composition with dependent fields and target/source selectors through the real batch and admission paths. Run relevant tests and check:fast before committing. An observed mechanical benefit does not establish open-action semantic correctness or continuous gameplay.
