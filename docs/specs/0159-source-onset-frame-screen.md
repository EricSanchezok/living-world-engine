# Source Onset Frame Screen

Artifact-Version: 1
Status: Approved

## Intent

Test whether interpreting each source action once produces a coherent reusable account of its current onset before observer-specific perception. The [semantic draft screen](0151-perception-semantic-draft-screen.md) still asks each observer/action pair to reconstruct its own onset; this diagnostic factors that shared interpretation by source action. It is a necessary-condition screen for a staged algorithm, not a substitute for the [complete-player objective](0122-player-action-efficiency.md).

## Contract

Retain the complete canonical source, all actors and actions, original assignments, authored laws, fixed checks and exact source index. Each distinct source action in the assigned pairs has one frame with its exact actor binding, an attempted current onset, the first directly addressed or receiving parties, later or conditional steps, uncommunicated private intent, and explicit uncertainty. First recipients can have a selected existing canonical identity or an unbound description; naming the sender's agent, witness or relative does not identify that party with its principal. The frame does not declare which assigned observers perceive the onset or settle any attempted result.

Each frame cites exact excerpts from that action's rawText or means and permitted existing entity/fact/law evidence. Excerpts must occur verbatim in their specified original field. This is source binding, not proof that an excerpt supports a temporal or identity inference. The decoder rejects missing or duplicate source frames, swapped actors, unknown recipients, fabricated excerpts and invalid evidence. It preserves uncertainty rather than making an executable negative. No output becomes a canonical Fact, event, stimulus, check or world commit.

The benchmark replaces only the role task, roleContract, generation schema and output example policy, while retaining all role-independent instructions and full source evidence. A source-group index joins existing assignment rows without selecting a cue, recipient or temporal interpretation. The original observer-level draft remains the control. A source-level answer can still be wrong and requires full-source semantic review before designing a second projection phase.

## Plan

Freeze B/C/C/B with four first-response HTTP calls, the official non-thinking model, zero repair, continuation, new random draws or world commit. B uses the existing complete-source observer semantic draft; C uses source frames. Retain all forty-nine subjects and actions. The eighteen assigned pairs have fifteen distinct sources in the current player snapshot. Compare their common source questions, explicit roles, current versus deferred communication and private information. Record the changed output scope, every raw response, usage, cache and elapsed time; these are not directly comparable canonical receipt success rates.

## Verification

Capture a real TruthEngine request and run frames through the actual gateway with only external HTTP replaced. Verify that repeated observer assignments produce one source frame, source context and input/RNG are unchanged, missing recipients remain unbound, explicit uncertainty survives, and invalid source/quote/evidence selections retain rejected audits. Reject canonical outputs masquerading as frames and incompatible or stale requests. Run focused tests and check:fast before a local commit and paid freeze. Any later integration must preserve observer privacy, required checks, reaction timing and atomic full-player execution.
