# Dependent Resolution Fields Experiment

Artifact-Version: 1
Status: Approved

## Intent

Use the user's autonomous continuation authorization under the [non-thinking gameplay experiment](0029-nonthinking-gameplay-efficiency-experiment.md) to remove redundant resolution choices and expose existing execution requirements in the candidate wire schema. This grants no additional budget, changes no default Composition and does not itself authorize a gameplay-success claim.

## Contract

The explicitly selected `dependent-fields-truth-resolution` candidate replaces the single-magnitude experimental implementation. A plan expresses base magnitude in `primaryEffect.magnitude`, or null for no receipt effect. An opposed difficulty expresses its selected rating in `ratingRef`; its canonical source is exactly that rating. The model continues to choose the target, rating, effects, factors, means and all other semantic fields. Environment difficulty retains its independent source. The encoder refuses inconsistent canonical input; the decoder restores only these uniquely determined copies. Optional redundant copies are accepted only when exactly equal, including source kind and reference. Conflicts are rejected without choosing either interpretation.

The wire schema omits these copies from required fields. It also exposes existing kernel restrictions: blocked plans have null effects, and check plans require grounded means, a non-null primary effect and a non-null failure threat. Canonical schemas and execution validators remain authoritative and unchanged. Schema instructions do not establish native provider constraint enforcement. Invalid targets, ownership, evidence roles, effects and action semantics remain failures.

The physical adapter remains beneath existing batching and covers initial, batch and repair plan requests. It omits generated illustrative output examples that could conflict with required effects or cardinality. Full context, action cardinality, reference catalogs, generation settings, repair limits and identity bindings are preserved. Raw wire output and canonical expansion retain separate evidence hashes. Historical trial manifests and stopped results remain immutable; removed candidate identities are not silently substituted in saved instances.

## Plan

Verify exact round trips and rejection of conflicting copies, physical batching, adapter evidence, and actual opposed-check effects and replay. Freeze any paid comparison independently with complete source and code hashes, fixed ordering, model settings, actual-materializer scoring and semantic review criteria before sending requests. A result that passes only schema or references is insufficient for admitting a complete-world trajectory. The encompassing experiment owns budget and gameplay acceptance.
