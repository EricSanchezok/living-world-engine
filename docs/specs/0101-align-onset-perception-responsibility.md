# Align onset perception responsibility

Artifact-Version: 1
Status: Approved

## Intent

Repair contradictory model instructions within the continuing autonomous gameplay optimization authorization. The [engine stage contract](../game-design/engine-runtime.md#truth-与随机承诺) assigns perception to consequential visibility before reactions; it does not assign action outcome adjudication to that response. Preserve complete world evidence and open action meaning while making that responsibility explicit.

## Contract

The perception system prompt asks whether an observer needs a check to notice an assigned action's onset in time to react. An assigned action is evidence to inspect, not an output slot requiring a check or a success ruling. The observer may differ from the action actor. Check stakes describe what can be noticed, with supported observer, target and causal evidence; they do not settle task completion, work quality or intended effects. Already established visibility and impossible sensory access are distinct from uncertain visibility. An authored requirement for a perception check remains binding.

Canonical truth does not imply observer knowledge. Perception neither invents facts nor generates observations or private cognition. The existing schema, legal reference catalog, validation, random commitments and repair policy remain authoritative. The model may still request every justified check, or finish when no further check is needed; the implementation does not force completion or substitute reference values.

Only the perception system asset binding changes. User instructions, complete runtime context, other role bundles, model settings, action cardinality and the public game API remain unchanged. Check requests retain their existing mechanical acceptance rules. Prompt text alone is not a semantic verifier.

## Plan

Bind perception to its own system responsibility while reusing the shared language and semantic protocol. Exercise actual perception requests, repairs and committed-check continuations. Freeze a comparison against the typed-reference baseline before paid calls.

## Verification

Verify the deployed request uses the perception system instructions instead of the outcome-adjudication system, preserves observer/source distinction and full evidence, accepts a valid requested check through the real materializer and RNG, and retains that responsibility during repair and subsequent rounds. Compare prompt manifests to establish that only perception changes. Run focused regressions and check:fast before committing. Report done-only responses separately and require source evidence before treating them as semantic success.
