# Observer Group Perception Screen

Artifact-Version: 1
Status: Approved

## Intent

Test whether independent assignment groups reduce observed batch-wide perception errors after relation schemas, branch clarification and complete catalog factoring failed to qualify. This is a diagnostic of task partitioning, not an automatic emergency production fallback.

## Contract

Partition all assigned observer/source pairs into groups with an explicitly frozen maximum observer count. Keep every pair for an observer together. Each request retains the complete world, all available actions and dependencies, all private canonical evidence, original catalog, laws, examples and inference settings. Both arms use the same complete field-domain transformation; its per-target constraints compile only the assigned group, retaining the original global target indices. The assignment-alignment treatment additionally restricts targetHandles, actionSet.assigned and dependencySet.assigned to the group's existing source actions. It preserves complete available evidence and makes no relevance, visibility or semantic decision. Reject missing or inconsistent action joins rather than repairing them. Groups retain original targetIndex values. Complete waves cover every original pair exactly once; explicitly selected diagnostic subsets cannot qualify complete-task performance.

## Plan

The assignment-alignment screen uses the recorded forty-nine-subject continuation, with all three recorded commitments fixed. Select the three original target indices 0, 4 and 17 before generating responses because their preceding singleton outputs answered a different observer or source action. Run B/C/C/B waves of those three singleton requests, at most three concurrent calls and twelve new HTTP requests. Each B body must match its preceding singleton request exactly. C changes only the three assigned-source fields; its generation schema, perception targets and complete available evidence must match B. Block repair, new check execution and world commits. Record original responses, input/cache/output usage, gateway failures and complete-source semantic counterexamples. Success in these selected cases establishes neither a population success rate nor full-player latency. A qualified subset requires a subsequent complete wave and player testing before integration.

This is a measured escalation after intact-batch and grouped failures. Observer partitioning multiplies calls and repeated input; assignment alignment adds no calls relative to its matching singleton control. Preserve the earlier thirty-five-observer grouped screen and eighteen-observer complete singleton wave as historical evidence. Keep all results out of default execution until independently qualified.

## Verification

Prove union coverage, preserved observer groups, no source mutation and exact restoration after replacing changed assignment fields with their original values. The source-alignment projection must preserve complete available action/dependency records, catalog, canonical truth and fixed checks, including shared checks for multiple source actions of one observer. Canonical validation remains full; additionally reject out-of-group reports or checks and missing/duplicate reports. Mechanical acceptance does not establish access, source actor identity or adequate observer stimuli. The screen stops at first responses. Mixed done/check groups do not establish a merged executable transcript: future integration must preserve committed checks, proposal identities and global RNG ordering before any world commit or player-latency claim.
