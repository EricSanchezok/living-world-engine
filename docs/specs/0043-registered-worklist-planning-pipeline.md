# Registered Worklist Planning Pipeline

Artifact-Version: 1
Status: Approved

## Intent

Within [0029](0029-nonthinking-gameplay-efficiency-experiment.md), make the source-bound planning pipeline available to real WorldHost trajectories through a distinct immutable candidate Composition.

## Contract

The candidate pins the source inventory, dependent plan fields, temporal execution evidence, factor types, exact source selectors, flat physical plan output, source-bound choice schema and explicit physical worklist. The physical wrapper order and static instruction bundle are part of its configuration. The existing registered shared-state-first batching child retains full slot cardinality, shared-json-v3, tail repair and restricted syntax recovery. Canonical validation, semantic verification, randomness and atomic commit remain authoritative.

The new candidate does not change existing Composition definitions or defaults, migrate saves, alter model generation settings, infer missing output semantics or filter rejected plans. Temporal evidence reaches planning, verification and transition through the same TruthEngine option. Physical planning wrappers leave other model stages unchanged. Source-worklist trials retain their first-call failures and recovery costs separately.

The gameplay runner requires both complete frozen source reviews before preparing a fresh candidate instance. Review acceptance is limited same-family evidence; actual committed trajectories still require per-action source review, positive time, durable replay and the independent confirmation run defined by the parent protocol. Known temporal phrasing concerns remain explicit review targets.

## Plan

Register the candidate, bind its complete prompt bundle and fixed codec order, and expose it only through the reviewed experimental runner. Reuse the existing compiler foundation, world source, budget journal, WorldHost path and per-commit review gate.

## Verification

Exercise a real registered SimulationEngine step through the new physical planning contract, verify exact source projection and selector restoration, confirm temporal evidence at subsequent semantic stages and check durable replay. Reject incomplete or incompatible runner configuration and prompt-version drift. Preserve existing default Composition identity. Run relevant tests and check:fast before committing and freezing the fresh full-world trial.
