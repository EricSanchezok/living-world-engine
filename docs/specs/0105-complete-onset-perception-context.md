# Complete onset perception source context

Artifact-Version: 1
Status: Approved

## Intent

Honor the registered onset-perception contract's full context mode under the user's continuing authorization to correct non-thinking gameplay within the existing experiment budget. A complete reference catalog must not advertise canonical evidence whose values are missing from the adjudicator's source context.

## Contract

The perception entry constructs a full canonical-truth workset for the initial request, repairs and committed-check continuation. It retains all source actions, groundings, assigned observer/action pairs, legal references and authored rules. The complete source truth is available to the trusted adjudicator; no Agent belief, ordinary client view or observation permission changes. A selected fact is evidence for adjudication, not knowledge granted to an observer.

The source state remains immutable through the perception stage. Check materialization, numeric authority, RNG, repair limits and subsequent world commit validation are unchanged. Other truth stages retain their existing scoped/full workset selection. The onset-perception algorithm is registered as model-onset-perception@3 and the default Composition pins it; old immutable Compositions are not silently rebound or migrated.

Context completion is a shared correctness foundation. Subsequent baseline and selection comparisons receive the same complete canonical state and keep separate request fingerprints. Historical scoped-request outcomes remain unchanged; supplying missing evidence is not reported as a gain from the selection representation. Preflight counts the actual complete request against the model window and existing budget before any paid diagnostic; it must not truncate evidence or silently lower output capacity.

## Plan

Select full mode at the real onset perception entry, pin the revised algorithm, and regenerate its catalog. Preserve the captured incomplete-context evidence in local experiment records. Compare newly frozen complete-context requests before resuming representation experiments.

## Verification

Exercise the real perception entry with nonglobal groundings and evidence outside the action footprint. Verify exact full canonical projection, catalog Fact coverage and typed values in the initial request, repair and post-check continuation; source truth and cognition remain unchanged. Retain the scoped builder for other stages and compare source context separately from model semantics. Run focused tests and check:fast before committing.
