# Resolution Plan Evidence Contract Alignment

Artifact-Version: 1
Status: Approved

## Intent

Correct a model-facing contract mismatch discovered under the [non-thinking gameplay experiment](0029-nonthinking-gameplay-efficiency-experiment.md). The plan materializer already requires existing causal evidence and excludes post-plan checks, randomness and mechanics; its schema must not offer those invalid choices.

## Contract

Only the resolution plan's causes use the stage-specific existing action/event/fact/law reference schema. A proposed record cannot be a prior cause. Other stages retain their existing proposal capabilities. The plan still explicitly selects all causes and must cite its assigned existing action; no decoder adds a cause, rewrites a reference or chooses evidence. Catalog membership, causal availability, grounding, action coverage and semantic verification remain mandatory.

Schema descriptions identify the existing per-action means inventory as exact source choices when supplied. Visibility in another action's grounding or the complete catalog does not grant means permission. This exposes an existing validator rule without narrowing natural-language action content or expanding accepted source types. Inputs, batch cardinality and model settings remain intact.

## Plan

Exercise the real schema, dependent wire schema, gateway and runtime repair path. Show that prior invalid proposals fail at the precise cause reference instead of a misleading plan-level error, while valid existing causes and actual world effects remain unchanged. Freeze any paid comparison independently. Historical source results retain their original schema and status; this repair grants no gameplay acceptance or runtime promotion.

## Verification

Accept existing action/event/fact/law references, reject their proposed substitutes and check/random/mechanic or participant/resource kinds as plan causes, preserve proposal support in other output stages, and verify the real next repair context. Run relevant tests and `npm run check:fast` before committing.
