# Temporal Route Perception Screen

Artifact-Version: 1
Status: Approved

## Intent

Within the authorized autonomous player-efficiency experiments, test a conditional output representation for the recurring confusion between a possible later information relay and an observer's current perception. Preserve the complete world and executable perception contract while making pending transmission incompatible with a current stimulus.

## Contract

The benchmark adapter replaces the terminal report discriminator with four route cases: direct current perception, perception through an established current channel, awaiting a later transfer, and no current stimulus. Only the two current cases carry the original private stimulus. The awaiting case names the first recipient and necessary later transfer; it cannot carry a stimulus. A current channel selects existing Fact or Law evidence also present in the report's original evidence list. The decoder constructs the canonical perceived/no_stimulus tag from the selected case, retaining every original reason, evidence, check dependency and stimulus without editing their meaning. Route details remain in the raw model audit. This is a conditional representation, not a proof that the model classified a route correctly.

The initial check branch, complete canonical context, all actions and observer assignments, authored remote channels, source freedom, check commitments and canonical validators remain intact. Supported uncertainty still requests the original checks. A failed required check cannot be bypassed through a different terminal case. The adapter binds its source and exact assigned source index, rejects invalid or repeated assignments and stale inputs, and uses the existing engine and gateway entry paths. It changes neither default Composition nor persisted contracts.

The complete source index is reused from [the source-index experiment](0150-grouped-perception-source-index.md). It does not classify distance, sensory access, a message's receipt or an action's temporal phase. The no-current-stimulus case also covers a failed required check or an unobservable onset; it does not assert that all communication is impossible. Current-channel evidence still requires independent semantic review, including whether the cited evidence establishes a live route rather than merely a relationship or general locality law.

## Plan

Freeze a full-source B/C/C/B screen with four first-response HTTP calls. Both arms retain all eighteen assigned tasks and the same exact source index; B uses the canonical indexed directive, and C uses the conditional route directive. This compares a joint prompt/schema/codec representation, not an isolated word or a formal causality algorithm. Keep the official non-thinking model, zero repair and no continuation, new RNG or world commit. Record every request, response, rejected output, usage, cache and elapsed time. Review all current stimuli against original source roles, current placement, onset timing, information content and authored channels before considering a complete player test.

## Verification

Exercise the real TruthEngine and HTTP gateway for direct perception, an authored channel, pending relay, no stimulus, check continuation and invalid pending stimuli. Verify that invalid outputs reach rejection rather than silent normalization, preserve fixed check outcomes, and confirm input/RNG immutability. Reject stale context, unbound channel evidence and duplicate/missing target reports. Run focused tests and check:fast before a gated local commit and paid dispatch. Mechanical acceptance alone cannot establish the [complete-player goal](0122-player-action-efficiency.md).
