# Bound perception rating choices

Artifact-Version: 1
Status: Approved

## Intent

Test an explicit owner-and-rating representation through the real perception entry under the continuing non-thinking gameplay authorization. Treat the observed ownership and invented-reference failures as a relational selection problem, without assigning abilities or perception outcomes in code.

## Contract

The optional representation replaces an observer reference plus optional aptitude reference with one explicit choice of an active entity and one of its displayed Ratings, or that entity with no aptitude. An opposed-difficulty choice selects an existing entity with its own displayed Rating and the same Rating as the difficulty source. Every mechanically legal combination remains selectable. No name inference, nearest-reference substitution, automatic null, or synthetic Rating is permitted.

All other output choices, complete canonical evidence, action text, target, stakes, visibility, mode, causes, check order and completion protocol remain intact. The adapter decodes before canonical schema validation and the existing materializer; rejected selections consume no RNG. Source/context and choice bindings are checked. Repair keeps the same state-bound identities; canonical rejected output remains complete and is explicitly labelled as canonical evidence rather than an output template. The provider retains raw wire output, canonical output, usage and lineage.

The candidate is an optional fingerprinted onset-perception configuration. The default stays on the shared full-context foundation until independent semantic and real-trajectory evidence supports adoption. A codec test or valid choice establishes representation validity, not justified perception, freedom preservation or 60-second feedback.

## Plan

Build the reversible request adapter and pin it in the existing experiment variant. Freeze four existing rule controls and three paired complete-scene comparisons, at most ten first-response HTTP calls without repair. Both arms share complete source context and generation settings. Candidate control failure stops complete-scene dispatch. Report completion-only, materialized checks, semantic control results and costs separately. Only an eligible candidate proceeds to a new real trajectory with per-commit source review and subsequent player-path verification; terminal trials are never restarted.

## Verification

Exercise the actual perception materializer and model gateway with owner-bound aptitude, explicit null, different observed and opposing entities, inactive observers, missing source rows, forged keys, state drift, repair and committed-check continuation. Verify complete context restoration and all valid combinations, canonical requests and RNG equality, unmodified source state and zero draws on rejection. Run focused tests and check:fast before committing; record paid outcomes separately from this engineering contract.
