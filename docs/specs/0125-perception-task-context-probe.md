# Perception task context probe

Artifact-Version: 1
Status: Approved

## Intent

Isolate an input-layout hypothesis under the authorized player-action efficiency research. Reuse the existing assessment work-item index with the canonical perception directive and its full validation, rather than coupling spatial context to a replacement output protocol.

## Contract

The benchmark-only adapter appends exact assigned observer/source-action work items after the original JSON context. Each item retains the complete source action, current onset question, both complete placement chains and every observer-owned Rating. All original context, field domains, schema, prompt responsibilities, check order, null aptitude choices, additional causes, repair limits and generation settings remain available. Assignment and shared placement ancestry establish no sensory route. The model still decides whether any check is justified and supplies its complete canonical draft.

The work-item builder is shared with the assessment experiment. The adapter verifies complete canonical truth and the existing action/assignment/revision bindings before dispatch, binds the source input and request context through response decoding, and refuses duplicate postludes. It does not modify returned values, substitute references, select abilities, infer access, create checks or draw randomness. The original gateway and materializer retain rejection authority. The default Composition is unchanged.

## Plan

Freeze the complete latest player diagnostic source and reconstruct its actual perception entry without network access. Require exact original context and unchanged source state. Compare the original directive request with the task-context postlude at the same entry, using disabled-thinking Flash and unchanged world scale. First run four existing controlled visibility cases; only a fully correct candidate may dispatch three alternating full-scene pairs, at most ten new first-response HTTP calls, with repair and continuation HTTP blocked and reported separately. Keep all failed outputs and stop terminal trials without replacement sampling.

The paired screen requires all three candidate batches to pass the unchanged mechanical validation and subsequent source review of justified checks, task membership, temporal scope and sensory access. A done result does not independently prove correct completion. Report input/output tokens, cache, call counts and latency separately, including rejected outputs. Prior assessment layout failures remain negative evidence; this narrower test is not a fresh generalization sample or a 60-second gameplay result.

## Verification

Exercise the real perception entry and HTTP gateway with explicit null and owned aptitude, repair, committed-check continuation and unchanged RNG. Verify full source restoration, complete chains and Rating ownership, original output/usage preservation, stale truth/input rejection, empty/unfocused assignments and duplicate adapter rejection. Run focused tests and check:fast before paid dispatch. Only independently qualified results can motivate another full player trajectory.
