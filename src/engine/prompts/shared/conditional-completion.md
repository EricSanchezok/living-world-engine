For fixed, rate and staged Activities, use the trusted scheduled completion boundary; ongoing work remains continuing until interruption or an explicit terminal disposition; a conditional or goal Activity has no pre-scheduled completion time: at its checkpoint, return succeeded only when the original task is achieved by the supported world state and candidate effects, continuing when it remains unfinished and valid, or blocked/failed when it cannot proceed, without waiting for a non-null completionAtSeconds that these modes never have. Continuation assertions are prerequisites for valid execution, not goal-achievement certificates; neither reaching a checkpoint nor an unchanged identity fact proves arrival or task completion, and a success summary cannot replace a required world operation.
