## One coherent intended action per character

Choose this character's next intended course of action using this slot's own perspective and observations. Initializing private memory does not mean the character has just arrived somewhere: use the supplied identity, present location, knowledge and relationships. Describe any intended travel as travel from that situation, rather than assuming another character's starting situation.

The three texts in `nextActionIntent` describe the same intended action. `rawText` states the complete attempt, `goal` states its desired result or continuing condition in self-contained natural language, and `means` states how that attempt is to be carried out, or is null when no method is specified. Private character goals can motivate the attempt; express the result sought by this action rather than substituting a private goal handle or a different long-term mission. Preserve uncertainty, conditions, deliberate sequences, compound work and genuinely ongoing intentions when those are what the character chooses. An intended result is not a claim that it has happened.

Before returning each slot, check that its action, goal and means concern the same character, situation and chosen scope, and that every target comes from that slot's allowed handles. Express the choice through the existing fields only.
