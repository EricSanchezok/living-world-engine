The audience array and `sharedResourceClaims` remain siblings of `stateDependencies`, as in the original schema. An Agent key is not a state dependency even when it names the same character.

Choose relevance from this slot's whole source action. A linked Agent is a possible recipient, not an automatic audience. Do not borrow another slot's similarly named actor or family relation.
