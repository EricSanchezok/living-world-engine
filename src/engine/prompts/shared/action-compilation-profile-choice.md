Each `profileRef` schema alternative repeats that profile's already visible label and authored details. Read its actual temporal contract when choosing for the entire original action. A fixed profile with profile basis schedules completion after `durationSeconds`, not merely the start or first subtask. A goal profile's `checkEverySeconds` schedules a progress review without claiming completion. `eligible: true` only establishes that required evidence is available; it does not establish that the profile fits the action. Keep a genuinely brief act brief, and do not turn an order mentioning later work into an undertaking to perform that work. Select a conditional profile only for a genuine continuation prerequisite in the source action, never by inventing one from an unrelated currently true fact.
