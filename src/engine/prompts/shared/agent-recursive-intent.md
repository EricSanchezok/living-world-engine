## Choose an intention as a nested program

Choose the next course of action from this character's own perspective, present situation, observations and private goals. In nextActionIntent return program, containing the root node itself. Keep beliefChanges and characterChanges under their existing evidence rules.

An attempt node contains unrestricted natural-language text and targetHandles for that attempt. Speak, investigate, negotiate, travel, build, fight, wait or attempt something novel as the situation calls for; there is no fixed game-action vocabulary. Write self-contained Chinese text. Retain the intended result, means and limits that belong to that attempt. Another person's compliance, delivery or answer remains uncertain rather than work you have already performed. Express your request as your attempt and any later dependency as a condition or later attempt.

Use sequence for work whose earlier child must finish before the next; use parallel for intended concurrent work. Their children arrays contain complete child node objects in the chosen order. Use if with a condition, targetHandles, thenNode and elseNode (a node or null); use while with condition, targetHandles and body (a node); use await with condition and targetHandles to wait before later sequence children. Conditions describe what must be evaluated, not something already established. A condition quoted inside a spoken question belongs in that attempt's text, not a guard preventing the question. Use one attempt when no separate control structure is needed. Preserve deliberate complex intentions rather than shrinking the chosen undertaking to fit the format.

Each attempt or condition selects only this slot's allowed targetable local-entity handles. An empty list is allowed when no selected target is needed. Put each target directly on the node that concerns it. The engine derives the complete action target list. A target does not establish that a person is present, hears you or complies. Do not generate nodeId, root, nodes, targetIndices, or an action-level targetHandles field.

For example, requesting courier delivery and later inspecting a reply can be a sequence containing an attempt to request delivery, an await node for an observed reply, and an attempt to inspect it. Organizing supplies while asking a guard a question can have two parallel attempt children. These are structure examples, not tasks to copy into this character's situation.

Return the supplied JSON shape without separate rawText, goal or means fields. Every branch and condition remains an intention. Private motives not meant to be communicated stay in private character state. Check that chosen ordering matches the meaning of the text and that a desired result was not used as a condition for starting the attempt meant to cause it.
