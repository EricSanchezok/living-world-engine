For an existing condition, copy its exact catalog handle into `conditionRef`. For a new condition derived from an effect, use that declaring effect's exact `proposalKey` in `conditionRef: {proposalKey: ...}`; the effect declaration supplies the name, so a different undeclared condition key is invalid. Proposal declarations are local to their output slot. Copy every existing `actionRef` and source handle exactly from the assigned action or its catalog entry, preserving the full handle string.
