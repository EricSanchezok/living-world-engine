## Choose an intention with explicit control flow

Choose the next course of action from this character's own perspective, present situation, observations and private goals. In nextActionIntent return targetHandles and program. Keep beliefChanges and characterChanges under their existing evidence rules.

An attempt node contains unrestricted natural-language work you intend to undertake. Speak, investigate, negotiate, travel, build, fight, wait or attempt something novel as the situation calls for; there is no fixed game-action vocabulary. Write self-contained Chinese text. Retain the intended result, means and limits that belong to that attempt. Another person's compliance, delivery or answer remains uncertain rather than an action you have already performed. Express your request as your attempt and any later dependency as a condition or later attempt.

Use sequence for work whose earlier child must finish before the next; use parallel for intended concurrent work. Use if with a condition, thenNode and elseNode (null when there is no alternative branch); use while for work repeated while its condition holds; use await to wait for a condition before later sequence children. Conditions describe what must be evaluated, not something already established. A condition quoted inside your spoken question belongs in that attempt's text, not in a guard that prevents you asking it. Use one attempt when no separate control structure is needed. Preserve deliberate complex intentions rather than shrinking the chosen undertaking to fit the format.

program contains root and nodes. Every node has a unique nonnegative nodeId and belongs exactly once to the rooted tree. Sequence and parallel nodes list child nodeIds in children. The order of nodes in the array does not imply execution order. Conditional and repeating nodes reference their children by ID. Every node must be reachable; there are no cycles or shared children. while expresses repetition without a graph cycle.

targetHandles keeps its existing meaning: choose only this slot's allowed targetable local-entity handles. Each attempt or condition lists targetIndices into that same ordered targetHandles array; an empty list is allowed when no selected target is needed. Every selected target must be used somewhere in the program. A target identifies what the intention concerns, not proof that the person is present, hears you or complies.

For example, an intention to ask a courier for delivery and later inspect a reply can be a sequence of an attempt to request delivery, an await node for an observed reply, and an attempt to inspect it. Organizing supplies while asking a guard a question can have two parallel attempt children. These are structure examples, not tasks to copy into a character's situation.

Return the supplied JSON shape. Do not also author rawText, goal or means action fields. All branches and conditions remain intentions; private motives that are not meant to be communicated stay in private character state. Before answering, check node ownership, target indices and whether a desired result was accidentally used as a condition for starting the very attempt meant to cause it.
