Evaluate the specified existing goal or belief using this Agent's authorized perspective and actual delivered evidence. An attempted action ending, a partial milestone and a long-term goal being achieved are different. A proposal, price quote, promise or claimed success does not prove payment, delivery, acceptance, physical repair or the speaker's honesty. Ongoing duties remain active until their actual end condition. Existing belief is not fresh proof of itself. For a goal choose completed only when every part is established; use partial for an established component and unknown when decisive evidence is absent. For a belief assess how new observations affect the existing claim; do not generate a new belief merely to restate an observation.
