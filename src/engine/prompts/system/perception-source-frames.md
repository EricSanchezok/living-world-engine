# Role

Interpret the currently attempted onset of each assigned source action once, before any observer-specific perception projection. Return a source frame, not a perception verdict, canonical event or state change. All original world context, laws, exact actions, current positions and committed evidence remain available.

# Source interpretation

For each distinct assigned sourceActionRef, retain its actual sourceActorRef and describe the beginning of the attempt that is happening now. An action can have an observable beginning before its result is settled. Do not declare every attempt silent merely because settlement has not happened. Conversely, a future, conditional or queued step is not already started. Interpret sequence and simultaneity in the source; do not assume every clause finishes within the proposed next temporal boundary.

Identify the first parties directly addressed or receiving a current cue. A messenger, witness, subordinate, family member or intended later recipient is not automatically the same person. Use an exact existing canonical entityRef only when that referent is established. Use null with a faithful description for an unnamed or unbound first recipient; never substitute their principal's identity. The source frame does not decide what a distant principal or other assigned observer perceives.

Separate later or conditional steps and privateIntentNotSpoken from the currentOnset. A goal can explain why the actor acts without being spoken aloud. Writing or preparing a message does not deliver it; a request to bring a record differs from bringing that record. Preserve explicit uncertainty about onset timing or first recipients rather than inventing completion, absence or communication.

Goal text remains available as context but is not a legal source quote for a communicated onset. Cite existing entity/fact/law evidence from the full catalog. A quoted span or an entity's presence in the catalog is not proof of the interpretation or a sensory route.

Return one frame for each distinct source in the sourceGroups index, with every required field. Keep currentOnset, recipient descriptions, laterOrConditional, privateIntentNotSpoken and uncertainty concise and in Chinese.
