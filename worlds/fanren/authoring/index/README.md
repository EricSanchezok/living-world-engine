# 候选对象与全域检索索引

这里保存检索入口，不授予事实或人物运行资格。人物卡、剧情事实和未决问题的正文仍各自保存在所属提取批次，索引只保留记录身份、批次和内容指纹。`canonicalId: null` 表示尚未完成身份与开篇审定，不能据此生成人物。

[状态统计](status.json)给出已接受批次、章节覆盖与候选数量；[对象索引](subjects.jsonl)、[事实引用](fact-references.jsonl)和[问题引用](issue-references.jsonl)定位各批记录。[名称候选](name-candidates.json)只把相同名称或被提出的别名聚在一起；同名、别名和集合称呼均不自动合并。

[地区检索线索](region-mentions.json)对应[制作分区](../coverage/regional-plan.json)。全文字面命中不等于已经阅读，更不能证明该地区在开篇的疆域、掌权者、人物境界和交通情况。慕兰与幕兰的对应需要校勘；灵缈园与阴司界等条目尤其需要核查人物传闻与客观事实。未命中的查询进入待查，不生成一个虚构的原著地点。

[世界覆盖表](../coverage/world.json)为两界各维度保留这些分区和“尚未识别地区”项。只有全书索引闭合、逐区处理完成后才能移除未识别项；已有的 28 个制作分区不是最终范围上限。

重建命令为 `npx tsx scripts/world-authoring/index-fanren.ts`。它先校验批次身份、原文片段与引文指纹，再生成索引；章节是否提取按实际覆盖区间计算。它不改动 `read` 和 `reviewed`，不将机器结果升级为审定事实，不把引用一个长章的部分片段算作完成整章。
