# 血天大陆与天鼎宫

血鹤城、齐云诸国、万月山脉、落潮草原和天马城在共同开篇存续。血夜有真实周期，城制、竞技、幻术教学和路线调查均带真实人物、文书、物件和有限预算。血骨门萧冥尚不是血鹤城守城者，现任守城者明确原创。

冰魄已经受困数万年，但尚未进大乘；她在中枢研究旧传承并主动谋划脱困。血灵、血魂、血魄是同一尚封存的魂，未提前生成游走的女修。翁只知道旧交和封存物，不知道秘密坐标。虚天鼎唯一仍在人界，灵界另一钥匙鼎保持独立，后期称名冲突可追溯。

天鼎宫古物与封印真实存在，未来取宝、尸变、阵损与战斗没有强制时间表。原文未说明的古宝用途保留待研究，不能自动兑换成万能能力。
