# 风元大陆西北诸族

本区将共同大陆、人妖域外边境、木族、灵族、夜叉和影族接入；木族与木属性灵族分开。原著地点与制度保留来源，缺少开篇街道与普通居民的部分为明确原创。跨大陆角蚩、海王使团属于后来行动，不据此认定在T0驻扎西北。

黑枭的隐蔽大乘、李蓉早年的莫门关系、雷罗尚未被紫影占据分别落实。大长老姓氏异写只保留一个职务主体；没有把后期黑灵花失窃、木猿军群、神血追捕与囚仙状态搬到开篇。

幼枝养护、器灵自修、影族路标、夜叉修刃欠款均有实际人物与资源。人物不共享全族知识，黑枭实力隐瞒及灵王仙界旧历分别限制知情范围。当前机器候选队列为空，后续提取增量仍须逐项核对。

李蓉的三千年前失踪公告回溯保留；本人在蛮荒石庵继续修行，精确居所、药圃与未寄家书为明确原创。莫简离与圣岛知道失联，不知道石庵坐标。
