## 本组实际内容

绿波洞藏书室加入门禁、逐册封护及有限的五册传本；李化元的三阳之体和真阳诀来自本人自述，不拿功法代替灵根检测。天知阁有实际书本、当班管书者及借阅限制，洞玄解提供对应远传护压知识，不包含古阵修法或秘密遗迹位置。

燕堡飞云阁、天鹤居与风悦客栈有当期人员、困阵能耗、茶粮、空房和房钥。燕子均、燕文、燕奇的开篇年龄与较低修为明确补写，未提前签生死咒或决定弃城。燕家堡是燕翎堡的连续称法，地点与家族组织保持分开。

越京四城区、皇城、秦宅及家业接入地图。秦言、兄弟、长二子、元配、门房秦贵和少年学役秦平有相互认识及实际职责。铜料仓、公银和食粮与私人物品分开；旧保护誓言由李化元和秦言分别知道，保护仍须消息与行动。现有铜料80份、公银600两及生活年龄属于明确原创初值，不冒充后期全国四分之一铜矿份额。

旧灵矿拥有开凿中的矿道、有限原矿、公料库、工具与两个当期工作人员。通钟乳穴的岩壁尚未打通，发现空腔不等完成移动。古阵破角、五色骸骨与蓝令各是一件实物；大挪移令用途需观察和知识识别，古阵未修复不能传送。后期母蛛的出生时点未证，保留资料主体而未复制当时战斗遭遇；远端配对与后续修阵场景继续随剩余正文核对。

吴道人当前有烈阳诀旧册、早期弄焰手记与消耗灯油的练习生活，不提前进入馨王府或预发死亡记忆。秦府保护、黑煞教口供、灵徽征调、矿洞伤亡、韩立拜师与古阵修复均保留其后期时间和实际知情层。口供称李破云为教主不能直接当作客观身份；吴道人尚未监视就被杀的实因与韩立猜测分开。

前三组已审成果继续保留：岳麓服务、三十六地火室、坊市经营与租兽具有实际资源；37 位既有人物灵根预定，雷万鹤仅依据韩对异根雷法的判断作有界回溯。林长老跨章显名合并；叶管事所属家族仍不凭姓氏合并到秦叶岭叶家。神风舟的旧本区资料归入内星海唯一主体。
