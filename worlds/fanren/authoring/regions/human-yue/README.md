## 第三组的实际内容

巫钧山、岳麓殿的藏书与材料、外内传送端、三十六个地火室及各自牌钥和有限火星砂，接入守阵、读书、复制和租室的真实许可与库存。两名守卫、阅览与地火执事是明确原创当期人员，不能被当成韩立后来遇到的全部原著人员。阅览及传送的原文价格与补写的当前火室租价、能耗分别记在声明里。

黄枫坊市七处铺面有经营者、独立商号、有限货柜与结算规则，铺面仍归黄枫；两间客房和钥匙实际存在。奇兽山当前两只低阶土兽、饲料与租借责任真实建档。店家的能力、货类及当期数额都明确标为原创，不预发天雷子、金蚨子母刃或韩立后来的私人装备。

37 位既有人物的客观灵根固定，检测只能揭示已有资质。菡云芝保持含木、燕如嫣保持单属性天灵根，墨彩环无根由后文回溯；雷万鹤依据后文韩对雷属性异根功法的判断作有界回溯，不冒充直接验灵；其余未说明的元素明确原创。已检测者知道自身资质，未检验的幼童与凡俗人物不预知结果。没有因补资质而增加修为、功法或后期记忆。

血禁原文未揭示的塔内与金箱内容改为有限、封闭的原创实物，不保留“待核定内容”的运行占位，也不随机产生原著独有宝物。外层、环山迷雾和第三层古禁的进入条件仍分开。

原文规则保留知识层次：马说主药无种子不能覆盖幼苗可在外界存活一两年的后证；三月服丹吸收不是瞬间成功；青元剑诀四层已有护盾实绩，不能误设必须六层；血禁历史伤亡比例不强制未来死亡。交易区分展示、承诺与实际交割，角色秘密不自动传播到全派。

本单元通过严格候选与来源锚点核验、30 区装配和世界格式构建。API 调用为零；这不能替代最终世界与游玩验收。余 859 条继续按后续连续场景审读。
