# 镜州地方区域审稿包

本区以韩立仍在村中、三叔尚未提出安排的那一夜为共同开篇。当前可拼装的是地方生活与主要人物网络，不能据此宣称镜州所有人口、全书候选事实或全人界已经完成。

## 文件与实质范围

- `module.json`：165 个新增实体，53 名可行动人物，311 条新增事实；既有七玄门、野狼帮仅按 `expected: null` 安置到实际总堂，没有新造同名门派。
- `claims.json`：84 条分层断言，含正文、角色说法、有据回溯、原创和数值标定。每个新实体、事实、规则及位移都有出处键。
- `review.json`：绑定模块与断言的内容指纹；`scope: full` 只代表该区域文件整体审定，不是全世界发布批准。
- `subjects.json`、`entity-table.md`：稳定身份、历史人物和明确排除的未来躯壳，及实际位置表。
- `source-reading.json`：25 个直接引用章节的原文指纹与二读内容。原文只留忽略缓存，不存进仓库。
- `candidate-dispositions.json`：611 条章节提取候选全部逐条绑定处置，348 条纠偏、263 条后期资料，0 待审；`candidate-source-reading.json` 记录实际阅读范围，不冒称109章均全文通读。
- `runtime-source-second-reading.json`：新增运行声明的61个精确原文切片二读记录；既有审读不重复调用模型。

## 原文核对后的开篇处理

青牛街、唯一客栈、酒楼后院、彩霞山、落日峰、十三哨、清客院、炼骨崖、神手谷、赤水峰和内外门八堂、长老会均有出处。支路、村镇门牌、值夜安排、库房金额、家庭生活和普通雇员是明确原创。十三哨的数目有出处，顺序编号和每一处形制没有伪称原著。

第六章门人转述王陆，后期叙事出现王绝楚。运行中只设一个名为王绝楚的在任门主；姓名冲突仍可检查，没有编造更名、继任或两个同时在任的门主。

墨大夫异常衰老不等于真实六十岁。他的供奉、救门主经历和神手谷可以回溯；墨与余的隐秘合作发生在入七玄门前。余有真实元神实体及有限能力，但只与墨相互认识，不向旁人自动显现。没有给两人预填韩立姓名、师徒关系、夺舍目标、后期死亡或书中结局。

厉飞雨的介绍明确回述“四年前上山”、先做记名弟子、两年基本训练后拜普通护法。因与韩立并非同一次考核，T0 精确日期无法确定。本区选择尚未入门的生活作为明确原创基线，不冒充唯一原著答案。金冬宝、王大胖等同代少年同样没有得到四年后的门派技能。后文可证的师承未被否认，只是没有把尚无法证明已经成立的关系提前。每人有真实家人、双向认识和可行走住处。

王样的死发生在四年后讲述的近期婚约变故，因此开篇活着；童年婚约与后期改许、死亡分开。女孩拥有独立行动与意愿，婚约不是所有权。张袖儿为李长老外甥女，但没有提前和厉飞雨相恋。马荣尚未被强定已有师承。资深长老及吴副门主的职务延续属于显式回溯加原创配置，未提前中毒、谈判或死亡。

七玄门门规和双方冲突是有条件的社会制度。未来战争、军弩、雇仙师、强制下山历练、韩立催生药物、张铁炼尸及曲魂都不按章节自动发生。

## 验证记录与边界

- 区域拼装、全部引用原文指纹检查、世界合同构建已通过。更新后的全30区装配为4135实体、711行动主体（仅当时装配快照，不代表全世界内容审定完成），出身初始化实体另计。
- `scripts/world-authoring/fanren-human-local.test.ts` 三项测试通过：真实 ZIP 导入、韩立接管唯一身份、原创药童入场、亲属与认识、墨/余初始认知隔离、钱粮、连续路线及重放一致性。
- 首次测试给韩立传入了改名和动机，按入口合同被拒绝；测试已改为保留既有人物姓名、外观和性格。没有改引擎来绕过限制。
- 本区尚未实玩走入神手谷；寄居元神在靠近后的感知裁定，需要真实模型游玩验证，静态检查不能代替。
- 墨居仁在岚州的妻妾、子女、惊蛟会及余氏家族需要相邻区域接入后补齐互知。这里不以只认识地方人假装其整个人生完整。
- 金光上人、升仙令、秦氏来历由人界修仙区域统一建档；本区不重复创造人物或物品。
- 原文三四千门人由社会实体及规模事实表达；本区没有把 53 位行动者称作全部人口。未具名后期岗位不自动回填，打铁职业已有真实原创铁匠、炉具和有限铁炭。其他帮派与后期合称人物在候选处置表中有明确时间或归属处置。

后续可安全并行的分工是：人界岚州/墨家负责墨的跨区家庭，太南及黄枫谷负责金光上人与升仙令，通用修炼规则负责功法与术法条件；本区负责地方组织、社会生活和相互认识。所有跨区关系须最终统一核对，不能各区各造一份同名人物。

五里沟为后文明确补证的韩立家乡，复用原村身份；松溪坳仍是独立原创村。七玄殿、六偏殿与旧石乳洞分别落地，二号机关具有实际关联结构、锁钥、保管人和有限维修料；机关后果须通过行动裁定。三位普通大夫相互认识并认识墨大夫，医舍有有限药柜与夹板。铁枪会、断水门有独立管事与公库，不因后期一次受胁迫就永久服从野狼帮。
