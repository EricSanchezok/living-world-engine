# 小灵天及测界设施

本区域补上原制作清单遗漏的小灵天，和广寒界保持独立。开篇与全世界同一时刻，南宫婉仍在既有人界身份中；原著后来的访客、尸体、晶核、征服与迁民不初始化。

[事实档案](claims.json)区分正文机制、人物说法、回溯与原创。[来源阅读](source-reading.json)记录 12 章全文阅读和独立场景片段，片段不计全章。211 条路由候选已经逐项处理：7 采用、90 修正、76 仅属后期、38 项有明确原文不确定性边界；没有用转交或缺证冒充完成。

[当前模块](module.json)含 84 个实体、18 位原创人物：人族与五个已命名异族的生活、商路、技艺、私人及共有财产、旧识和利益诉求均有实际状态。这是具体模拟人口，不是全界人口上限；数族分区、群体传闻和历史人口也不能自动生成无数可调用 NPC。

[本地验证](local-validation.json)通过真实 ZIP 导入和出身创建，检查双向旧识、定金/尾款、共有断枝、工具归属、周期边界与未来信息隔离；没有调用模型。全域资料闭合和必要真实游玩仍由总验收负责，本区域通过不代表完整世界已发布。
