# 魔界关联世界

本区1,803项候选均已按正文证据审定：1,753项直接阅读证据段与相关上下文，50项复用相同正文指纹及严格审定记录。没有再次调用模型。24项原文未定的身份或细节保留边界，不冒充确定事实；具体处置见 `candidate-dispositions.json`。

当前包含266个实体、45个可行动主体。魔界古史、跨界条件、城镇矿场、幻夜诸家、青翼族、蓝瀑湖、苦灵岛、螟母封印、镇魔锁三魂和泣灵秘藏相互连接。火云矿有可进入矿道、有限在矿资源及雇员；古藏有四件唯一钥砖、分层禁制和有限器物。六极分体、蟹道人记忆、掌天瓶灵均保留各自控制与认知边界。

生活内容包括血牙米试种、货场验货、器修交货、矿道支护结薪、坐骑租用、公物借还和旧图勘察。个人私囊、家族公库、未赚工钱与已赚债务分别存在。普通居民、精确开篇所在地、资源数值与运行消耗属于明确原创；后期叛乱、交易、虫母战和韩立取宝不强制发生。

`claims.json`保存来源和时态，`subjects.json`保存统一身份，`candidate-source-reading.json`记录实际阅读区间，`runtime-source-second-reading.json`记录运行设定二读及本地装配结果。段落审读不等于整章通读。本区完成不能替代其他地区、全量导入和最终真实游玩验收；仙界仍只保存解释两界所需的历史与信息，不设可探索地图。
