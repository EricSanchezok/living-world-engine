# 妖族七地

本区将七地制度、五具名妖王、玄鹰族、九仙山及妖族落日城接入可通行区域。所读正文没有确定第七族名称，苍泽辖地、泽闻舟等属于清楚标注的原创生活层。不同修为、法体、族属、公产、个人资产和角色认知分别存在于运行状态。

敖啸和古事中的天奎有较强开篇存活依据；其他王者的开篇在位与合体层级属于显式回溯推定。玲珑原体及雪玲、珑梦只在 subjects 预留跨区身份，不在妖地重复生成。后期黛儿任务、七星月体觉醒、魔劫损害和拍卖物品不前置。

可行动内容包括药材受潮的验货与赔付、伏渠地道疏水与有限矿料报酬、水火配给与旁渠工程。各方有实际资源、知情边界和拒绝权。空机器候选队列只表示当前提取批次未覆盖本区，后续须对增量逐项处理。
