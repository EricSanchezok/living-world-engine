## 来源与开篇处理

`claims.json` 将长期地理、人物说法、回溯、原创生活与数值标定分开。`source-reading.json` 记录实际阅读与二读发现；`subjects.json` 包含当前实体以及不应提前实例化的未来人物、商号、物品和同名城市。

天元境的天元城与现有天渊城保留不同实体。玄武城建在骖灵古龟之上，天灵城依擎天灵树而建，三处阵眼属于长期地理。巨树直通仙界保留为传说。虞阳城明确已有百万年历史；其圣塔与炼体、灵具行业有据回溯。安远城、青罗沙漠、落日人城、落日之墓人族入口与远途商路已经接入，但道路存在不构成瞬移。

黄粱灵君的万年居所支持开篇存活回溯；开篇炼虚初期并非逐年断代得到的事实，而是明确推定。其具体当下活动、技能、家底与禁制器具为原创。其余 28 名当下人物全部明确原创，不冒用以后才出现的张奎、方夫人、香儿、柳河等角色状态。天东商号与隆兴拍卖行未证明开篇已成立，不生成同规模现存机构。皇位制度已有来源，具体开篇在位者尚待更广章节核对。

- **磐石炼体院：**无灵根教习有真实炼体技能、`force=4`、`cultivation=0`、零法力；学徒和医者相互认识。基础课需先检查伤势，消耗真实药包，分配六枚灵石费用并经过训练时间；第一次目标是掌握动作，进阶需要后续条件。
- **归衡灵具修造院：**匠人具备炼体、阵法与神念基础。手套须真实装入一枚低阶灵石，才能配合提吊架完成一次额定升降；耗尽扣库存。货场待修设备有可拆检故障、材料需求和四十枚实预算。合格协作者可获得其中十二枚及抄图许可，不能提前领取。
- **玉阙阁勘界：**已有灵地登记、听泉居用记录、复勘单与一百八十枚预算。调查须到南麓清理刻文、测距、对照图；脚印不会直接告诉玩家谁留下。真实园工知道自己搬过三盆幼苗，可被询问。合格报告可得到八十枚灵石，不保证不查证也能领奖。
- **两种灵界出身接入：**青禾仓院连接交易街、货场、引路人和验货中介；听泉连接玉阙阁、修造院和城内公共道路。新增人物只认识地点和公开业务，不预先知道玩家身份、私账、阵片争议或货差答案。
- **长途与学习：**三境行旅公所提供有库存、有回函的逐段交通；玄武接引港、天灵枝台园、天元驿递、虞阳圣塔和落日材料铺均有实际人员与物资。具体远途行程需要另议与执行，不把军用传送改成免费公共出口。

## 语义审查要点

人物的当前灵根在世界中预先确定，本人拥有相应检测认识，旁人须实际检测或取得可信陈述。无灵根不会阻断炼体，但听说境外生根灵药也不等于已知可靠药名和地点。灵压盘仅辨外露气息，无法读取隐藏库存与秘密。

修匠在拆盖前不知道腐蚀的具体位置；有手艺不等于预知本次故障。园工的见闻与现场刻文、盆印分别保留。日常合同没有默认血咒惩罚。三皇七妖对兽潮的限制作为社会协议保留，不能当成违反不了的自然定律。当前没有定时重演兽潮、战争、韩立飞升或未来拜师。
