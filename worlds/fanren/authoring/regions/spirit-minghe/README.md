# 冥河圣地与蜉蝣往来

本区包含冥河阴水、枯木林、阴骨山脉神池、魔坟、青元子与金焰候居所，以及蜉蝣外部接引与育虫社区。沿用飞灵地渊第七层，但隐藏入口尚未被当地妖王发现。空间起源的罗睺说为人物猜测，未与人界阴冥合并。

青元子为唯一融合主体，金焰候、虚灵及外部长期修士按古事和明确推定回溯。虚灵未提前拥有成熟噬金虫，青元子未提前取得韩立竹叶和未来雷器。元瑶妍丽没有在此建立开篇师承。

可交互生活包括阴气节点差异调查与有限材料修补、已付定金的虫粮订单、饲料误签核对和限时送材接引。稀有物件各有真实归属和库存；神乳不保证突破，借宝不代表无条件赠予。

未能断代的花长老、后期取得器物与未知圣灵逐项列于 subjects，不能把这些索引当作已经造好的开篇人物。当前空机器队列不代表全书增量核对完成。
