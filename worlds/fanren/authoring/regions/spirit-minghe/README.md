# 冥河圣地与隐修者

本区保留蜉蝣圣地、内岸与阴骨山、不同水域、青元子洞府、金焰岛和旧识居所。跨界须同时满足定位、主持、阴水防护与当前窗口；界内行路不冒用跨界费用。当前维护窗口是已提前筹备的一次机会，临时值守须撤回，不能由此推出日常商路。

青元子和姜姓老者为同一融合主体。黑风阁有真实可进入的内室，使用须展开并维持；天木镜仍由木青持有。集乳淬晶砖里储存的是现有神乳，取出只发生转移。药材、酒、灵虫与阴物群使用有限数量，分离和损毁必须扣减原群。

开篇生活包含补料交接、药园合同、虫粮误签、节点检修与私用灯罩维修，已有付款、物件和认识双方。后期四妖远征、借宝取乳、元瑶拜师与认义父、妍丽后来的师承、渡劫袭击等仅入作者档案，不成为必走剧情。

416 条固定区域候选已严格处置：358 条依原文直接核对，58 条复用同候选与源指纹的既有审定。冥河是否源自另一头罗睺、黑冥雾海的成因等六条保留明确不确定性，不合并人界阴冥或开放捷径。正文人物的说法、反悔和不同阶段估计分别保留，不以百科式摘要覆盖。
