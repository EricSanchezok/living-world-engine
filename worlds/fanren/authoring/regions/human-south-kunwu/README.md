# 南疆与封印中的昆吾

共同开篇在韩立尚未出村时。南疆的家庭、药市、炉匠与门派有自己的生活；昆吾仍被古禁制整体封住，叶家的长期计划处于推定的研究准备阶段。未来破封、战斗、死亡与宝物归属都未发生。

本区依据逐章正文和逐项证据写实阴阳窟、四囚妖、门派与古器、昆吾分路建筑、九层倒塔、八层两囚室和九层真魔气封印。玲珑原体只有一个活动融合心智；雪玲在虚天鼎玉如意，元刹本尊在古魔界，没有第二个同名身体或无条件跨界共享记忆。逆星盘本体由灵界狼族保管，双印投影不是复制实盘。

资源、器物保管、师承家庭和门规均进入实际状态。常人没有自动补根，普通生活可以持续；探索遗迹仍需信息、准备、真实技能和可承担的代价。数值、未具名普通人口与精确T0居所为显式补写，不能宣称原文精确给出。
