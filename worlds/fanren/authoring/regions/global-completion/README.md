# 全域差集补充

本模块补充地区队列差集中确认遗漏的共通规则。292 条原候选的逐项处置见 [`global-root-difference-dispositions.json`](../../reviews/global-root-difference-dispositions.json)，对应封存队列见 [`global-root-difference-queue.json`](../../reviews/global-root-difference-queue.json)。

10 条声明保留原文章节和字符位置；其中 9 条进入运行规则，涉及社会称谓、隐私和地方风气、持续符术耗法、低阶术法边界、魂尸术、技艺与材料、妖兽分类、便携阵具和记忆修改。另 1 条仅修正后期资料提取中的否定、主体及价格指代错误。

已有地区和基础规则继续复用。此模块不新增人物、不提前授予韩立法术、不生成后期物品，不以候选完成计数代替完整世界封板或真实游玩验收。
