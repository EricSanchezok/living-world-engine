# 飞灵与地渊

本区覆盖飞灵七十二主支的共同机构、已见具名支族地域、天鹏圣城与沿海、地渊七层、五位妖王居所和越隆炼场。未具名族支保留社会规模，不伪造原著名称。天鹏圣主仍在、朱姓妖王仍活着、首次冥河探索尚未发生是有据回溯与明确开篇补写，不是后期回述已给出精确年代。

圣城竞技广场与玉皇顶较技场分开；银门后仍须越过黑地和万里行程才到巨渊。层间通道、木青固定传送与冥河跨界各有条件。飞灵赤融族地与风元赤融山脉使用不同地点，长途商路不代表同一领属。

当前人物具有独立动机、真实资产和对应认知。生活机会包括旧图核路、翼伤代送、实际凝甲课、地血试作与越隆观炉；报酬从持有人库存支付，族宝与私产分开。兽群、果实、真血、舍利和炼晶材料都有有限数量。地血双体、木青树身保持同一主体；九头骨鸟与越隆是不同生物。
