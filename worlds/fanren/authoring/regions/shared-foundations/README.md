# 两界共用修炼规则

本模块将已有修炼体系、资源物性和认知边界写入运行法则。它不替代各地区的具体传承、材料、职位或人物能力，也不向人物自动公开这些知识。

本轮逐项对照并二读引用前后文，形成三十四条规则。其中原有内容包括境界、灵根分类、寿元范围、灵石用途、实际兑换、突破条件、五行合一、替代灵根、灵界天劫、炼虚寿元、飞升气息、神识边界、储物、炼丹、炼器、制符、符宝、本命法宝、传送、夺舍、还魂、元婴出窍、两界天象、运行历法与隐灵根；补充体术、分魂和分身、交战条件、心魔、誓约、族群与化形、阵法维护、跨界环境和资源培养。每条规则分别绑定断言与原文位置，分类保留人物讲述、叙述事实和回溯推定的区别。

三处限制直接影响游戏：早期人物说筑基丹“必须”时，不能据此删除其他已成立的途径；常见寿命范围不能变成统一死亡日期；有神识不等于自动听取传音和读取隐秘。丹灵根的适用前提也不能推广为无灵根者在全书里绝无其他机会。

本轮已审定全部 6,976 条候选：4,703 条逐段裁定，2,273 条精确复用同候选、同版本的既审地区结论。没有未处理候选；38 条原文不能唯一确定的边界已明确裁定其适用范围。已通过的条目没有重新调用模型。规则中的人物说法、具体后事和开篇可回溯边界分别记录，不能把对后期事件的研究视为开篇已经发生。

原文在忽略缓存中；`claims.json` 保存定位与内容指纹，`module.json` 保存可拼装法则。`rule-source-review.json` 保留规则到已审定条目的编辑追溯链。后期个案支持的通用边界直接绑定原文，并单独解释回溯理由；后期事件本身不成为开篇状态依赖。当前规则审定不能替代地区完成、九种身份接入和真实游玩验收。

历法将灵界一昼夜取四个人界昼夜，并明确标为运行标定；原著只说三倍以上。年数和修士岁龄保持共同人界年口径，灵界合约的本地日单独换算。此标定须随所在地时长解释与当前光线一起接入，并通过跨日游玩后才能认为运行完成。
