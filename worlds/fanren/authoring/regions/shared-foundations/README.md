# 两界共用修炼规则

本模块将已有修炼体系、资源物性和认知边界写入运行法则。它不替代各地区的具体传承、材料、职位或人物能力，也不向人物自动公开这些知识。

本轮逐项对照并二读引用前后文，形成二十四条规则：境界、灵根分类、寿元范围、灵石用途、实际兑换、突破条件、五行合一、替代灵根、灵界天劫、炼虚寿元、飞升气息、神识边界、储物、炼丹、炼器、制符、符宝、本命法宝、传送、夺舍、还魂、元婴出窍、两界天象与运行历法。每条规则分别绑定断言与原文位置，分类保留人物讲述、叙述事实和回溯推定的区别。

三处限制直接影响游戏：早期人物说筑基丹“必须”时，不能据此删除其他已成立的途径；常见寿命范围不能变成统一死亡日期；有神识不等于自动听取传音和读取隐秘。丹灵根的适用前提也不能推广为无灵根者在全书里绝无其他机会。

本模块仍在展开。待核项目包括灵界灵具与炼体、无灵根者改变资质的传闻及实际例外、功法层数与境界的对应、具体丹药药性与材料、不同法宝灵宝的使用条件、阵法破禁与反制、灵兽与族群差异、界面灵气和跨界通行。待办未处理完前，不把模块或全局规则标记为完成。

原文在忽略缓存中；`claims.json` 保存定位与内容指纹，`module.json` 保存可拼装法则。文件审定只对当前二十四条内容有效，不能扩大为所有修炼规则均已完成的声明。

历法将灵界一昼夜取四个人界昼夜，并明确标为运行标定；原著只说三倍以上。年数和修士岁龄保持共同人界年口径，灵界合约的本地日单独换算。此标定须随所在地时长解释与当前光线一起接入，并通过跨日游玩后才能认为运行完成。
