# 内星海与海上生活

本区域将魁星等西南三岛、天星城、圣山及星宫、妙音门和小寰岛接入同一开篇世界。双圣元婴、三岛主结丹、金青筑基的回溯理由与精确数值标定分开存档。凌啸风／凌天雷共用一个实体；凌玉灵等无法确定出生时点者先建身份索引，不复制成年后期人物。

当前生活包括海船护航和海况选择、真实洞府租居与修补、小寰护阵及成年女儿出岛愿望、妙音门普通贸易、无名小宗仍拥有天雷竹。普通人物有配偶、师徒、雇佣、财产和独立目标，能拒绝、协商、出行，也能承担实际危险。稀有竹株不保证交给任何人。

当前属于编写与复核阶段：来源候选增量、区域人物索引闭合、跨区航路、古阵与外海接入仍须继续完成，未声称全域制作结束。
