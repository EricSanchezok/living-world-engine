# 雷鸣大陆与天云诸族

以云城、绿光、金甲、横水、伏蛟及魔金山脉连接雷鸣势力。古老高阶人物与史料明确支持的旧事回溯；无生年证据的后期低阶人物进入身份索引，不直接复制成年职业。

当前可行动生活包括两种传承的择师、不同工艺的论辩、百年租洞与研究自主、广寒旧拓本的真假消息、跨洲远行审批和有限魔金探索。每条线均有真实角色、财产、文书与认知边界；任何一方可以拒绝、协商或改变主意。

魔金的宝花、三魔、黑渊鳄、魔猿与芝仙有独立主体。三片玄天如意刃只在当前三位保管者处，后期偷窃未发生；宝花仍负旧伤，黑鳄未提前升圣，芝仙未被捕获或变成韩立化身。

十三族中六族名称来自当前直接阅读，其余七席只作未具名社会组织，不创造伪原著族名。机器候选队列的后续增量仍须逐项核对，不能以当前空队列宣称全书已覆盖。
