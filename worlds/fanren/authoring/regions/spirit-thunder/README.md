# 雷鸣大陆与天云

本区包含天云十三族、云城及八云山、角蚩边防与古器供奉、魔金、火瑚海岛和极北生态。云族替换原未名第七席，联盟总数保持十三。火阳常驻火云岛；另两支当前近邻岛住区是明确补写，没有把火阳领地介绍扩成全族唯一居所。

火瑚古阵两端失联，海外阵核仍在海兽腹内。取回阵核只改变实际占有，修复还须材料、知识与两端校准。万古另有受限危急阵和可耗用传讯符；它们与伏蛟跨洲阵分开。云城的择师、辩论、租洞和消息交易保持已有真实条件，新接入航图合写、近岸采集和古钟观测等可拒绝事项。

图、狞开篇炼虚，后期灌体不提前授予。罗盘使用有目标、遮蔽、距离和三本地日冷却条件。狼蜥群、归阵符、成药、供物和行旅粮均有限；分离、死亡与消耗须扣旧量。迷天神钟本体与后期临时圣器分开，三供位复用海域唯一真灵，不制造重复主体或预设背盟。
