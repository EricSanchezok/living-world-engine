# 大晋区域编写记录

当前交付是已逐条核对的区域运行增量：大晋、辽州舜江、陇州、晋京、华云州、太一门与魔陀山，以及相应的生活关系。`claims.json` 分开记录正文、人物说法、回溯和原创数值；`source-reading.json` 记录实际全文阅读范围。这个增量通过审校，不等于区域候选队列已全部处理。

大晋是一百零八州。晋京千里禁飞禁斗是地方规约，强宗修士曾违犯，不能写成绝对禁制。朝廷、宗门与世家的力量关系涉及资源和约定，官职不直接转化为修为或物权。几位化神彼此克制的禁约也由现实力量维护。

向之礼、风老怪、呼庆雷和太一门白姓隐修各有唯一实体；向之礼尚不认识韩立。共同开篇的确切修为、位置和私人库存明确为回溯标定。后期白姓修士服食火精枣、叶家破封、阴罗宗追杀、魔宫纳妾都没有成为既定事件。两名在后期叙述中已经兵解的未具名化神，死亡距开篇的定位仍独立待核，不能直接删成开篇死者。

原创江埠开场包含真实托运物权、十六箱库存与十八箱账面记录，以及船主、记账人、护航散修和收货商之间的信息差。鉴物、沿海验货、门房、符箓材料与官府巡查各有实际人物和有限资产。人物不因知道宗门名称而知道其全部秘密。

仍需完成的区域工作是全部候选的逐项采用、修正、后期/历史归档，尚未展开的州域和支线人物，以及全域交通与实际运行验收。它们不由本模块 `review.scope=full` 代替。

本地候选收尾已完成 138/1252 项，1114 项明确待审。已采用的地理、朝廷物权和化神关系逐条映射到当前断言；68 项复用北域、万妖谷已审定的同一候选与报告指纹，未因同章或同名而自动采用。`candidate-worklist.json` 保留每项来源、复用记录和剩余审定问题；剩余候选是事实核对工作，不等于应增造 1114 名人物。
