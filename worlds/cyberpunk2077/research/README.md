# 夜之城世界调研底稿

调研日期：2026-10-17。范围：《Cyberpunk 2077》本体与《Phantom Liberty》的世界设定；《Edgerunners》及桌面角色扮演资料仅在注明年代、适用范围后补充。本文是持续维护的资料底稿；已用于可运行包，并按当前人物关系复核，不代表所有支线、分支、对白和中文译名已经完成逐条实机审计。

## 创作目标

世界的历史、原作角色、既有关系与技术边界忠实于原作；原创空间集中在玩家身份、私人关系、职业处境、有限资源和开局事件。出身可以富有、专业、有组织背景，也可以处于底层；不能把所有身份都做成同一位身无分文的新手佣兵。

夜之城六大城区、恶土与狗镇都进入研究范围。按片区完成证据与可玩内容是编写顺序，不是把整个世界缩成沃森区。当前实例只有一个街头小子生平的 V，可接管但不是所有玩家的身份模板；当前运行切片见[作者参考](../authoring/README.md)。

## 证据约定

- **原作·已核**：本轮读到的官方材料或具体游戏任务证据能支持这一限定表述；不表示已经遍历全部版本。
- **二级·初核**：攻略、社区资料提供可定位线索，正式定稿前仍应对游戏任务、数据库或官方设定书复核。
- **待核**：暂作搜集目标，不能自动转成初始化事实。
- **设计提案**：为了让世界可运行提出的解释、模型或原创内容，不冒充官方规则。

研究范围和当前实现的收口矩阵见[待核问题](gaps.md)；尚未取得的全书与全游戏名录属于证据覆盖限制，不能写成当前十二种开场仍未实现。来源编号链接到 [sources.md](sources.md)。PDF 页码使用 PDF 文件的物理页序，从 1 开始。论坛只把署名 CD PROJEKT RED 工作人员的首帖作为官方证据，下面的玩家回复另算。网页、攻略和官方简介都可能描述后期状态；证据可信度与是否适用于开局是两个不同问题。

## 当前结论

1. 原作的魅力来自分层社会：公司、帮派、家庭、职业圈、中间人与情报机构之间的具体依赖。单纯换成霓虹背景的打怪升级会丢掉主要内容。
2. 最有价值的出身差异是“已经站在不同关系中”：资产继承人能接触公司程序，车队组织者能移动人和货，超梦技师能分析证据，各自也承担不同责任。详见[出身设计依据](origins.md)与实际[角色目录](../roles.md)。
3. 官方人物简介会跨越多个剧情阶段；应先制作时间切片，再写角色。详见[时间边界](timeline.md)。
4. 电子游戏 2.0 的义体容量、桌游的人性损失与世界中的精神失常不能直接混成一个公式；地图中的快速旅行、等级缩放和任务解锁也不能变成宇宙定律。详见[规则](rules.md)。
5. 出身创建路径不能仅凭关系文案建立双向熟人、资产和契约；运行包使用完整预置角色与既有接管能力，详见[作者参考](../authoring/README.md)、[验证记录](../verification.md)及[十二出身真实模型验收](../live-verification.md)。

## 资料获取与复核

在仓库根目录执行：

```sh
python3 worlds/cyberpunk2077/research/acquire.py
python3 worlds/cyberpunk2077/research/acquire.py --ids P03 P07
python3 worlds/cyberpunk2077/research/verify_research.py
```

下载器只请求 [sources.json](sources.json) 中启用缓存的公开来源，每份最多 64 MiB，并记录最终 URL、UTC 获取时间、字节数及 SHA-256。PDF 原件在 `.cache/raw/`，提取文本在 `.cache/text/`；需要系统中的 `pdftotext`，页数记录使用 `pdfinfo`。机器记录在 [cache-manifest.json](cache-manifest.json)。后续获取可能因网站变化失败，失败记录不代表已读。

本轮下载了五份官方公开 PDF，包括 83 页的 Ultimate Edition Game Booklet、CEMK 宣传预览、Cyberware Enhancements、Karaoke Night 与 Night City Atlas。最后一份明确是 **2045 年地图**，只能作历史对照。付费版《The World of Cyberpunk 2077》和完整 CEMK 未取得正文；官方服装参考包超过单文件上限，保留链接、未宣称读过。S06、S20 的直接请求失败，但通过网页工具取得了正文或指定节选；S21/S22 只取得检索索引返回的段落。三种获取范围均记录在目录中，`extracted-via-tool` 不伪装成原始 HTML 下载。

本轮复核补齐了 Reed 的日常工作场所、旧同僚的不同知情和罗格/克里各自对强尼的历史关系；精确改动依据见[收口矩阵](gaps.md)。已细读的人物、地点与规则证据集中在来源清单的“本轮阅读定位”。其他材料即使缓存成功，也只表示已经获取，不等于完成核查。源站版权页和导航仍可能留在可搜索文本里，使用前按章节定位。

## 维护方式

一个事实只在对应主题文件维护，来源与缓存状态只在目录及清单维护。新增原作事实必须带来源、时间范围、知情者和分支条件；新增原创事实必须明示原创。下一轮优先补齐[待核问题](gaps.md)，不要用更多无定位的长摘要掩盖证据缺口。
