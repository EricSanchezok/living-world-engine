## 仍不能声称完成的原作资料覆盖

| 范围 | 目前证据边界 | 什么时候需要继续补 |
|---|---|---|
| 全部原始游戏数据库与分支 | 没有读取用户安装游戏的完整数据库、分支存档或完整录制；二级转录不能改称本地实机证据 | 新剧情依赖精确对白、时点或互斥分支时，补对应任务与版本的原始证据 |
| 完整官方设定书 | P15 只是《The World of Cyberpunk 2077》商品目录，未取得全书 | 引入新的城市制度、企业内部层级或技术历史时，按具体主张取证 |
| 完整 CEMK | P04/P05 为介绍，P06 是八页预览；公开补充不替代完整付费规则 | 真正采用该桌游行动经济、价格或义体数值前，先取得所需合法规则正文 |
| 全城同一分钟快照 | 时间锚点已定；赖宣的载体、罗伊斯掌权和布里克被囚等并发状态采用明确作者安排 | 若制作原版任务顺序的严格复现，需进一步核查相对《The Rescue》的精确顺序 |
| 黑墙与数字身份全模型 | S12/S15/S16/S17 正文未取得；S18 只支撑具体任务中有限行为，未实现完整 Relic 激活与人格迁移 | 玩家要实际跨黑墙、迁移数字人格或操作相关原型时，需独立规则与对应证据 |
| 医疗价格与完整义体体系 | 当前有有限职业资源和使用边界，不声称复刻官方保单收费、响应保证或精神失常统一公式 | 新增商业急救调度、完整义体安装经济或精神状态专门机制时再补，不借用 RED 数值冒充 2077 |
| 全部人物、建筑与组织 | 当前核心关系簇与职业开场不等于全游戏演员表或精确导航网格 | 按新增玩法进入[人物队列](characters.md#按玩法需要扩展的覆盖队列)与[地点队列](locations.md)，同时补目标、关系、资源和可行动条件 |
| 所有补丁与中文译名 | P10/P11 为 2.0，P03 为 2023 手册；没有宣称 2.0 是最新，也未做所有中文版本逐词校对 | 采用特定版本数值或正式本地化名称前核对目标游戏版本；对象 ID 继续去重 |

这些资料边界不要求用更多未读书名或没有行为的 NPC 填满世界。当前开场能否继续、资源是否可用、关系是否回应由运行证据回答；原作全部任务是否复刻是另一项范围更大的工作。

## 来源冲突与误读处理

| 风险 | 当前处理 |
|---|---|
| 官网人物简介带有杰克死亡、V 脑内 Relic 等后期叙述 | 按生效阶段拆开，不整段初始化 |
| P03 p44 同时概述竹村旧身份与后期落难 | 采用保镖身份，不提前停用义体或建立与 V 的信任 |
| P03 p48 将 Reed 的潜伏概括为狗镇，游戏具体工作场所在市中心 | 用 S20 的具名开发者解释及 S21 的具体酒吧定位区分潜伏网络与日常工作，不添加供全体角色使用的秘密通道 |
| P03 p49 对汉森统治年数的修辞与统一战争年份不宜机械对齐 | 采用留下并建立统治的因果，不据修辞补精确日期 |
| Night City Atlas 是较新发布的官方 PDF | 仍只描述 2045，不覆盖 2077 地图 |
| 论坛官方首帖下有矛盾的玩家讨论 | 只有工作人员首帖视为官方；具体地理另查 |
| 攻略混有善恶评价、等级、奖励、扫描拾取步骤 | 只采可以定位的事件与关系，不当世界物理或经济法则 |
| 来源正文有早期到结局的混合段落 | 阅读定位限定适用章节；获得全文不等于采用全文 |
| Wiki 摘录或检索索引能读，但直接请求失败 | 明确标作工具段落，保留失败原因；不假称成功下载原始页面 |

## 获取边界

C01–C19 的官方服装 PDF 首次获取超出 64 MiB 单文件上限，未保留部分文件，现仅保留链接。S12–S17 的正文仍未取得。S06、S20 为网页工具正文或节选；S21/S22 是检索工具实际返回的索引段落。具体状态、字节数、哈希、读取范围以[来源清单](sources.md)、[机器目录](sources.json)和[缓存记录](cache-manifest.json)为准。

本轮新增材料没有取得任何完整付费书。公开材料能支持的修正已经进入当前包；无法取得的内容保留为证据限制，不下载来源不明的付费书扫描件，也不拿其标题替具体事实背书。
