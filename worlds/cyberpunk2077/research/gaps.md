# 证据缺口与下一轮核查

## 优先级最高

| 项目 | 现在缺什么 | 补齐后怎样用 |
|---|---|---|
| 原始游戏证据 | 未读取用户安装游戏的数据库、分支存档或完整任务录制 | 逐条确认 T0 的位置、领导权、知情者和关键关系，而非把攻略整段当真 |
| 完整官方设定书 | P15 是《The World of Cyberpunk 2077》商品目录；未取得全书 | 补城市历史、社会制度、技术与公司细节；不得声称已经覆盖其全文 |
| 完整 CEMK | P04/P05 是目录与介绍，P06 只是八页宣传预览 | 若需桌面机制，先取得完整规则再决定转译；不从宣传材料编造公式 |
| 开局时点 | 《The Rescue》前的更精确事件先后，部分人物住处与行程 | 锁定一份无矛盾的原始世界切片 |
| V 的存在形式 | 自创玩家世界中 V 的身世预设、是否可接管以及 V 序章另起时间线 | 确保没有三个不同 V、两个同身份主体或互相冲突的过去 |
| 黑墙与数字身份 | S12/S15/S16/S17 正文获取失败；S18 只能支撑具体任务中的有限行为 | 补原作数据库、任务对白与官方书，明确 Blackwall、Alt、NetWatch、Relic 的能力边界 |
| 医疗与义体状态 | 创伤小组合同与费用、药物/治疗、精神失常叙述的具体证据 | 为医疗出身与义体规则提供可信限制，不用网络常见说法替代 |
| 出身运行能力 | 关系文案不等于双向关系；资产、合同和私人认知需实入口验证 | 决定是否仅靠脚本预置即可，还是需要通用初始化能力 |

## 覆盖缺口

人物：核心表不是完整名录；[人物队列](characters.md#第二轮必须补齐的人物)列出阿德卡多、莫克斯、太平洲、公司外围、市政、AI 与动画角色。每个进入下一版的角色都要补正式语气、个人目标、技能、资产与认知，不能只增加名字。

地点：尚未逐门逐层走查，不提供伪精确距离与行走时间。太平洲子区、狗镇内部边界、重要酒吧与旅店、公司设施、H10、城外营地和各阶段搬迁仍需地图与任务证据。

势力：目前有公司与街头网络的骨架，缺内部组织层级、具体供应链、私人安保与市政的权限、媒体及日常服务组织。首领、人数、预算和装备不得靠常识补成“正典”。

版本：P10/P11 是 2.0 的官方变更材料，P03 是 2023 手册；未完成所有后续补丁审计。选定数值规则时再核对目标版本，不宣称 2.0 是最新。

中文名：采用常见译名与英文检索名并列；正式剧本应以目标简体中文版本作统一校对，特别是帮派分类、物品、任务、能力名称。

## 本轮遇到的来源冲突与误读风险

| 现象 | 处理 |
|---|---|
| P01 的人物简介描述 V 头中的 Relic 和杰克已发生的命运 | 仅作该阶段证据；开局按更早时间切片还原 |
| P03 p44 同时概述竹村的旧身份与后续落难 | 拆成不同生效区间，不把整段当一张初始化卡 |
| P03 p49 对汉森统治时长的概括，和同册其他统一战争时间提示不宜机械对齐 | 先采“统一战争后留下并建立统治”的因果；精确年数另核，不据修辞补日期 |
| Night City Atlas 是较新发布的官方 PDF | 仍然只描述 2045；官方与新发布日期都不能消除年代差异 |
| 论坛官方首帖下存在相互矛盾的玩家地理讨论 | 只把工作人员首帖当官方来源；丽姿位置用 S03 地图和任务另查 |
| S04 等早期攻略混有笼统善恶评价、等级/伤害表或街区表述问题 | 只作初核线索；不采纳“某帮和平所以不会伤害外人”、元素抗性或把相邻街区合并的说法 |
| S05 暗示可直接加入并攀升帮派等级 | 不据此声称原版游戏提供该系统；我们要做组织生活须明确是开放世界设计 |
| S06 标题 URL 仍含旧版六个中间人，正文已更新为七个 | 以获取文本为准；仅核姓名和区域，奖励表有明显模板错误，不进入经济模型 |
| S10/S11 关于扫描与拾取物品的表述可能混同攻略操作建议和世界因果 | 不据此设置“先在超梦扫描才会让现实物品出现”的世界规则 |
| 官网、攻略、书籍有不同拼写与译名 | 用稳定对象 ID 合并，保留检索别名，不制造重复实体 |

## 获取状态

C01–C19：官方服装参考 PDF 的首次获取均超过 64 MiB 上限，未保留部分文件，之后关闭自动缓存。它们是外观参考链接，不是已读的人物证据。未来按需要单独取得某个高分辨率包即可，无需为文本剧本一次下载全部。

S12–S17：Wiki 正文直接请求失败；其中部分页面也尝试了网页提取/浏览工具，仍未取得可读正文。保留 URL 供人工或后续合法访问；不伪造其内容与证据状态。

S06：直接下载失败，网页提取工具获得了正文，已保存文本及哈希；保留直接获取错误信息以便理解两种路径差异。其余获取记录、大小和哈希以 [cache-manifest.json](cache-manifest.json) 为准。

公开材料只能支持有限范围的核查。需要付费材料时可继续依赖已公开的一手资料与游戏证据推进；不会用未取得的书名替具体主张背书，也不下载来源不明的完整付费书扫描件。
