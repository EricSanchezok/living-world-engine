# 《赛博朋克 2077》世界作者工程

《夜之城众生》是可导入 Living World Engine 的中文同人开放世界。运行数据位于 [world/](world/script.yaml)，采用现有 schema v17 与角色接管入口，包含百人规模的城市生活网络。它是夜之城的可玩首版，不是全部原作任务、对白、室内地图和分支的逐项复刻。

目标是忠实保留夜之城的背景、人物经历、社会结构和既有关系，同时让玩家选择多种原创身份、资源条件与开场机遇。原作人物有自己的生活；玩家可以进入他们的故事，也可以形成新的故事。原作后续剧情是可供研究的因果样本，不是必须执行的未来。

游玩从[导入与接管指南](play.md)开始，选择[十二种身份](roles.md)之一，或接管世界中的 V 等现有人物。未被接管的人物仍有自己的目标和模型控制策略。每种原创身份均有住所、实际现金、设备或使用权、三名双向熟人、业务文件和正在发生的开场处境。

[制作边界](authoring/README.md)解释原作依据、时间安排、原创补充与数值标定；[覆盖清单](authoring/coverage.json)由构建器生成，记录实体、人物、关系和内容摘要。维护者修改 authoring 下的源文件后运行 `node worlds/cyberpunk2077/authoring/build.mjs`，不要手改生成的 world、角色表和 JSON 清单。当前状态见 [1.1.0 验收与收尾](live-verification-1.1.md)：已用离线回归和 4 次针对性调用验证授权修复与实际试听，十二条完整职业轨迹未重跑。另保留[首版记录](verification.md)与 [1.0.1 实模历史记录](live-verification.md)。

研究资料从[调研总览](research/README.md)进入，证据缺口集中在[待核问题](research/gaps.md)。未核实的地图精度、支线人物和后期分支不能因运行包存在而视为已经完成。

原始 PDF、网页快照、可搜索文本保存在本工作树的 `research/.cache/`，已加入 Git 忽略。仓库保存中文研究笔记、来源地址、获取记录和校验摘要，不把下载的原作资料重新分发为项目素材。克隆仓库后可按[资料获取说明](research/README.md#资料获取与复核)重新获取公开材料。
