# 《赛博朋克 2077》世界作者工程

状态：前期调研与出身设计草案，2026-10-17。这里还没有可导入的 `world/`，也没有修改引擎或安装新世界。

目标是忠实保留夜之城的背景、人物经历、社会结构和既有关系，同时让玩家选择多种原创身份、资源条件与开场机遇。原作人物有自己的生活；玩家可以进入他们的故事，也可以形成新的故事。原作后续剧情是可供研究的因果样本，不是必须执行的未来。

从[调研总览](research/README.md)开始。具体材料分为[时间与正典边界](research/timeline.md)、[人物与关系](research/characters.md)、[地点](research/locations.md)、[势力](research/factions.md)、[世界规则](research/rules.md)、[十二种原创出身](research/origins.md)、[编写路线](research/authoring-plan.md)和[待核问题](research/gaps.md)。

原始 PDF、网页快照、可搜索文本保存在本工作树的 `research/.cache/`，已加入 Git 忽略。仓库保存中文研究笔记、来源地址、获取记录和校验摘要，不把下载的原作资料重新分发为项目素材。克隆仓库后可按[资料获取说明](research/README.md#资料获取与复核)重新获取公开材料。

《Cyberpunk》及相关人物、世界、图像归各自权利人所有。本目录是非官方研究与作者准备材料；没有把第三方参考资料声明为本仓库原创或可自由再许可的资产。
