# 夜之城运行内容参考

本页定义世界作者数据的范围与依据。游玩步骤另见[进入指南](../play.md)。

## 时间、原作与原创

共同时间锚点是 2077 年，V 与杰克一起接活半年后、《救人》触发前；V 采用街头小子生平。原作背景以[来源目录](../research/sources.md)、[人物资料](../research/characters.md)和[时间边界](../research/timeline.md)为依据。原作后续行动和分支结局不作为未来定时脚本执行。

这不是官方给出的全城同一分钟快照。远方人物的日常位置、赖宣已经持有载体、罗伊斯掌权和布里克被囚等并发条件采用明确的作者时间安排；其依据来自相应任务的已知状态，但不能据此宣称已核实事件相对《救人》的精确小时。补充场所的内部布局、路程尺度、NPC 当日目标也属于作者安排。

原作人物有身份、性格、目标、能力、职业资源和部分核心双向关系；具体初始数值、普通装备和现金属于本剧本标定，不是原版掉落表或经济统计。各职业接触原作人物的额外联系、原创组织成员、十二种出身及其家庭、事业和合同均为原创。职业联系不给予无限权限或原作人物的自动好感。

强尼的数字印迹与 Alt 相关数字存在是具体的数字实体；当前没有把它们当成可在街头自由走动的肉身 Agent。Relic 的激活、完整人格迁移过程和后期任务链未纳入本版运行验收。当前的原作人物覆盖不等于原作完整演职员表，境外节点是远景而非日本或 NUSA 全境地图。

## 数据与构建

| 文件 | 责任 |
|---|---|
| [city.mjs](city.mjs) | 城区、空间层级、组织及通道 |
| [cast.mjs](cast.mjs) | 原作人物、关键关系、数字实体与认知边界 |
| [origins.mjs](origins.mjs) | 十二名可接管角色及联系人、资金、财物、合同、开场 |
| [services.mjs](services.mjs) | 原创居民、商户库存、职业渠道与常备设备 |
| [accounts.mjs](accounts.mjs) | 共同账户的普通支付程序、具体授权范围及登记收款人 |
| [rules.mjs](rules.mjs) | 世界法律、资源、能力、时间、预约和裁决标定 |
| [model.mjs](model.mjs) | 普通 schema 数据的构建助手，不是运行时插件 |
| [build.mjs](build.mjs) | 确定性生成 YAML、目录、角色指南及导入 ZIP |
| [provenance.json](provenance.json) | 实体与关系的来源编号，以及原创位置/数值标签 |
| [playable-roles.json](playable-roles.json) | 出身与实际资源、联系人、文件的引用目录 |
| [coverage.json](coverage.json) | 自动统计与生成内容摘要 |

来源编号用于作者审校，运行包不嵌入整篇资料。provenance 的粒度是实体及核心关系；每个人物的所有修辞、目标和数值不因此变成来源支持的正典。重要修改应回查资料主题文件，不能只比较生成文件行数。

世界与人物使用各自的模型绑定：`worldProfiles` 指定世界裁决，`profiles` 指定人物私有决策、创作及回退。具体选择和真实模型验证集中在[在线验收记录](../live-verification.md)，不以修改人物权限或强制结果弥补模型误判。诊断人员能够通过实际观察获知的故障使用受限受众，而不是无人可见的永久私密事实；允许观察不等于初始就知道原因。

## 行动与资源

资产以实际实体、放置、数量、所属或授权事实存在。角色拥有对相应对象的私人认知；三个主要联系人也保存与角色既有经历和不同诉求。合同条款和未公开记录限定给当事人。共同账户、单独产权、岗位采购、材料库存及租赁车辆遵循各自的授权条件，不因接管而合并为私人财富。

六个共同或业务账户通过现场语音终端受理明确的申请，并由持有余额的服务 Agent 执行转账。它们是有边界的原创业务软件，不计作人类居民或原作人物，不代表机构全知人格。账户授权规则与收款人目录决定能够办理的交易；复杂授权仍需实际相关人表达同意。角色直接对终端说出收款人、用途和金额，例如 O02 可以说：“请项目账户向艾达支付 6000 欧元首批控制器采购款。”操作其他测试设备或编写未送出的申请不会通知账户。

程序校验 schema、引用、数量和提交一致性；产权用途、专业边界与具体行动的合理性仍依赖模型遵守已有世界法律及事实。不得把这些语义约束宣传成所有叙事可能都已被确定性程序证明。当前首次验收关闭自由场景补全，既有人物、地点和资源依旧可以互动及演化。

可转移与消耗的物资数量登记在实际保管人名下，storage-* 事实记录医药包、货柜、车辆或商铺等实物位置；不再把同一数量重复放进容器余额。保管不等于产权，也不表示出门时把仓库全部装进了口袋。物资交接与消费仍须现场可达，并按用途和授权裁定。

预约会唤醒当事人重新考虑事务，不直接结算合同或触发灾难。开场机会不是强制任务；未来由行动及其后果产生。所有可接管角色都是同一世界中原有的唯一人物，其他身份保持独立存在。

## 验证范围

运行包覆盖各大城区、狗镇与恶土的可玩节点，采用抽象空间而非游戏精确导航网格。完整支线、所有室内建筑、每个具名人物、关系的所有分支和大规模长时间在线表现仍需逐项扩充与验收；具体材料缺口以[研究清单](../research/gaps.md)为准。软件路径的验收与原作逐句忠实性审校是不同工作，见[验证记录](../verification.md)。
